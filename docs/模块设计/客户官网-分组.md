## 1. 职责与边界

版式照模板价格页，但本站不是订阅：月付年付切换换成版本切换，月费换成分组倍率。全部为占位数据。

## 2. 结构与数据流

- 页首（版本切换 + 版本指标）→ 四张分组卡（通用、生图、Claude 专线（重点卡）、高速通道 / 企业版为专属定制）→ 倍率说明（公式 + 当前版本各分组的计算示例）→ 三个版本 14 项特权对比表（当前版本整列高亮）→ 常见问题 5 条 → 厂商标志。
- 倍率：个人版 1.0 / 1.0 / 1.2 / 1.5；专业版 1.4 / 1.3 / 1.6 / 2.0；企业版 2.0 / 1.8 / 2.2 / 定制。模型页、价格页的版本价格取每个版本的「通用」（文本）和「生图」（生图）分组倍率。
- 特权对比的可用率、渠道、倍率、限额从版本与分组数据推出，不另写一份。

## 3. 关键决策

- 版本决定渠道质量与可用率目标，分组决定可用模型与倍率；与后端现有「分组倍率」概念一致，后续可直接对接。
- 企业版第四个分组是专属定制，倍率显示「定制」，按钮是联系销售。

## 4. 当前实现

- 页首：版本切换 + 版本指标。
- 分组卡：四张等高卡，第三张 Claude 专线为深蓝渐变重点卡；倍率大字、说明、特权对勾列表（范围、渠道、可用率目标、限额、工单时限，再接分组独有特权），按钮靠底；企业版第四张为专属定制，倍率显示「定制」，按钮为联系销售。
- 倍率说明：公式卡 + 当前版本各分组的计算示例（基础价 × 倍率 = 实际价格）。
- 特权对比：14 行，当前版本整列高亮，对勾 / 横线附读屏文字。
- 常见问题 5 条；底部厂商标志轮换。

## 5. 验证方式

- 单测 `tests/groups.test.ts`：分组数量与顺序、倍率、重点卡、默认分组、对比表推导值。
- 交互检查表见页面规格末尾。

## 6. 待扩展项

- 分组与倍率改读后端分组配置；组织可用分组按平台授权显示。
