# 官网与定价页模块设计

模块定位：面向企业采购的对外站点。首页讲清定位与差异，定价页答清价格与计费口径，把访客送进注册或销售邮件。

## 1. 职责与边界

本模块负责：

- 对外首页：定位、平台能力、组织管控、技术规格、接入流程、服务保障、应用场景。
- 定价页：个人版与企业版的价格、能力对照表、计费规则、常见问题。
- 官网共用外壳：顶栏、页脚、配色与排版底座，供首页、定价页和状态页共用。

本模块暂不负责：

- 模型单价展示。那是已有的模型广场，本模块只负责链过去。
- 服务状态展示，见[对外服务状态](./对外服务状态.md)。
- 控制台内部页面的观感，见[界面设计规范](./界面设计规范.md)。

## 2. 为什么重做

改造前的首页是面向个人用户的：痛点罗列、与官方订阅的对比表、第三方模型厂商的彩色标识、终端打字动画，首屏按钮直接推注册。

这套打法对企业采购不成立。企业客户第一个问题是多少钱，第二个问题是这家公司靠不靠谱，第三个才是功能。而挂第三方厂商标识等于宣称一种并不存在的合作关系，「更多模型即将支持」则是在给没有日期的东西许诺。

## 3. 转化路径

```
首页 ──【立即体验】──→ 定价页 ┬─ 个人版：公示倍率 → 自助注册
                              └─ 企业版：按用量核定 → 销售邮件
     ──【模型价格】────→ 模型广场（已有）
```

首屏第一个按钮指向定价页而不是注册页。企业客户先看价格再决定要不要接，把注册挡在价格前面会直接流失。

## 4. 首页结构

| 区块 | 作用 |
|---|---|
| 首屏 | 深蓝底，定位三段式 + 一段说明 + 控制台示意 |
| 定价入口 | 个人版倍率、企业版核定、模型价格三张卡 |
| 平台能力 | 六格共边框网格 |
| 组织管控 | 左侧配额示意图 + 右侧四条说明 |
| 技术规格 | 九行参数表 |
| 接入流程 | 三步 + 请求示例与同步记录字段 |
| 服务保障 | 四行条款表 |
| 应用场景 | 四张卡，当前为占位 |
| 收尾 | 深蓝底，呼应首屏 |

区块形式刻意不统一：并列可扫的用卡片，规格数据用表格，有先后的用编号清单。全用卡片会读成模板，全用细线清单会显得单薄。

手机端顶栏只保留品牌、语言、主题和菜单入口，其余导航收进展开菜单，避免站点名和操作互相挤压。定价对照在桌面继续使用三列表格，手机端按单项改为“能力名称 + 个人版 + 企业版”的纵向块，读者不需要横向拖动后再找表头。

各区块直接使用标题建立层级，去掉重复的眉标。字号使用固定档位和明确断点，字距统一为零；首屏保留深蓝底，移除与业务无关的装饰网格。

## 5. 能力区只放差异

平台能力区一度写的是协议兼容、密钥管理、权限管控、调用审计。这些是网关的基本盘，任何同类开源项目都有，摆在能力区等于自认没有差异。

现在这几项下沉到技术规格表当参数，能力区只留需要平台侧长期投入才能提供的：组织账户体系、安全防火墙、多模型覆盖、多账号冗余调度、低开销转发、独立部署。

## 6. 数字的来源

首页与定价页上的数字分三类，处理方式不同：

| 数字 | 来源 | 取不到时 |
|---|---|---|
| 模型数、分组数 | 实时读模型广场目录 | 不显示数字，只留文字 |
| 个人版倍率 | 配置常量 | 必填 |
| 可用性、网关延迟 | 配置常量，默认留空 | 只写机制，不出数字 |

可用性和延迟做成配置而不是文案，是为了让「写不写承诺」成为一次显式决定。留空时页面只描述调度与转发机制，不会出现任何没有依据的百分比。

## 7. 文案口径

全站走名词化书面语，不写对话。

| 改造前 | 改造后 |
|---|---|
| 团队共用模型服务，钱和权限还在你手里 | 统一接入 · 组织管控 · 安全防护 |
| 一个网关，管住调用的全过程 | 企业级核心能力 |
| 出问题找得到人 | 服务与数据保障 |
| 钱是怎么算的 | 费用构成与结算方式 |
| 现有代码改一个地址就能切过来 | 仅需变更请求地址，请求与响应结构保持不变 |

判断标准：出现「就能」「不用」「照常」「怎么办」「差在哪」这类口语连接词，就是写成了对话。

## 8. 上线前必须确认的配置

集中在 [landingContent.ts](../../frontend/src/views/landing/landingContent.ts)，留空的项在页面上不渲染，不会显示占位符。

| 配置 | 说明 |
|---|---|
| `SALES_EMAIL` | 企业咨询邮箱，当前是占位地址 |
| `COMPANY_NAME` | 页脚公司全称，留空退回站点名 |
| `ICP_NUMBER` | 备案号，留空则页脚不显示该行 |
| `PERSONAL_RATE` | 个人版倍率，当前 0.5x |
| `SLA_UPTIME` | 可用性承诺，填了即对外承诺 |
| `GATEWAY_LATENCY` | 网关自身开销，不含上游生成时间 |
| `SHOW_SECURITY_FIREWALL` | 安全防火墙是否展示，ACF 未上线 |
| `CASE_STUDIES` | 客户案例，当前为占位 |

这些值编译进前端，改完需要重新构建，不是运行时配置。站点名、Logo 与文档地址仍走后台公开设置，换品牌不用改代码。

- 类型检查与静态检查全过。

## 10. 决策记录

| 决策 | 结论 | 说明 |
|---|---|---|
| 首屏按钮指向哪 | 定价页 | 企业客户先问价格；把注册挡在价格前会流失 |
| 价格摆不摆 | 个人版明码，企业版核定 | 个人版守得住，企业版按规模谈 |
| 第三方厂商标识 | 不用 | 宣称并不存在的合作关系 |
| 能力区写什么 | 只写开源装不出来的 | 写基本盘等于自认无差异 |
| 可用性与延迟 | 做成配置，默认留空 | 避免无依据的承诺被顺手写上线 |
| 客户案例 | 占位只写行业与规模 | 编公司名与效果数字属于伪造背书 |
| 安全防火墙 | 展示，带一行开关 | 业务方要求；ACF 未上线，POC 阶段有演示风险 |
| 品牌名 | 走后台公开设置 | 自部署客户填自己的，不写死 |
| 文案口径 | 名词化书面语 | 官网是规格说明，不是对话 |
| 手机导航 | 顶栏菜单 | 小屏保留四个必要入口，其余导航展开后完整呈现，长站点名自动截断 |
| 手机定价对照 | 逐项纵排 | 每项同时显示个人版与企业版，避免横向滚动造成列对应错误 |
| 区块眉标 | 去掉 | 标题已经能表达层级，重复标签增加机械模板感 |
| 首屏底纹 | 纯深蓝 | 保留企业站的稳重底色，移除通用网格装饰 |
