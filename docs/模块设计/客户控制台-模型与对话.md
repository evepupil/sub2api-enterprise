## 1. 职责与边界

模型页是登录后的价目表：按自己能用的通道看真实的模型与实付价（2026-10-04 起接后端）；对话页让用户不写代码先试模型。对话不调用接口，回复是占位文字逐字显示。

## 2. 结构与数据流

- 模型的取数：浏览器 → 官网接口 `/api/portal/console/models`（带着登录状态，凭证过期自动续期）→ 后端模型广场 `/api/v1/model-plaza`（账号能用的分组，含专属分组与专属倍率；每个分组挂的模型、单价、长上下文分档、高峰与分时段倍率、官方参考价）+ 支付配置里的充值比例。模型广场没在后台打开时当作没有可用模型；充值比例读不到按 1。
- 模型的换算（`src/lib/console/live/models-view.ts`）：所选通道的每个模型 → 一行：实付价 = 后端单价 × 生效倍率（专属倍率优先；生图模型在开了「生图独立倍率」时用生图倍率），按 Token 计费的显示每百万 Token 的「输入 / 输出」，通道开了长上下文分档时多一行加价档；按张、按次计费的显示单价；下面列高峰、分时段的加价；折扣 = 实付 ÷ 官方价。展示名、厂商、类型、协议、上下文、「新」标记按模型名对官网目录，对不上的显示原名、按名字猜厂商、按后端平台推协议、上下文「—」。
- 范围（全部 / 收藏）+ 四个筛选下拉（厂商只列这个通道出现过的）+ 搜索 + 排序 + 通道 + 币种 → 分页宽表格（首列与操作列固定）；文本模型的「试一试」带着模型名跳到对话页。
- 对话：模型（存在网址 `?model=`）与密钥选择 → 显示该通道下的输入输出单价；发送后追加用户消息，助手回复按字逐步显示，可停止；新对话清空。

## 3. 关键决策

- 数据来自后端模型广场，不拿官网目录的价格（2026-10-04 用户确认）：广场的 Token 单价和扣费走同一套计算，显示的就是会扣的钱。前提是后台建好渠道、把模型挂到分组上，并打开模型广场；用户负责生产上的配置。渠道里只挂模型、不填价格时，单价按全局价格表（与现在的扣费一致，本机实测确认）。
- 默认看第一个通道（后端按倍率从低到高排）；控制台可以显示倍率，通道下拉写「名称 ×倍率」。
- 人民币按充值比例换算（付 1 元到账多少美元，生产是 1:1，用户确认），官方价也按同一比例换算，所以两种币种下折扣一样。
- 收藏存在浏览器里（用户确认，换设备不同步）；收藏数只算当前通道里有的模型。
- 按张、按次计费的模型和官方价单位不同，折扣列写「—」。
- 对话页的模型放进网址，方便从模型页带过去；其他状态都在页内。

## 4. 当前实现

- 模型页（真实数据）：范围标签（全部 N / 收藏 N）、四个筛选下拉加搜索、排序标签、通道下拉（账号能用的分组，写倍率）与币种切换（人民币时下面写「按 1 美元 = ¥X 折算」）；表格首列（星标、厂商标志、名称、调用名；目录里没有的模型只写原名、标志处是灰点）与操作列在桌面固定，手机上首列不固定；价格列跟通道与币种变，带长上下文加价档、高峰与分时段说明；折扣列是折扣标加划掉的官方价（不打折时不划线，按张、按次的写「—」）；文本模型「试一试」带着模型名跳到对话页；加载中显示占位块，没有可用模型、出错（带重试）各有空状态。
- 对话页：模型（存在网址里）与密钥选择，旁边是该密钥所在通道与这个模型的单价；示例对话两条；发送后回复逐字出现，可停止（一个字没出就去掉空回复），新对话清空；Enter 发送、Shift + Enter 换行，输入法选字时不发送；输入框用共享多行输入框。
- 模型页 7 个文件（另有真实数据层 4 个文件），对话页 8 个文件；逐字输出的状态集中在一个纯函数里（有单测）。

## 5. 验证方式

- 单测：`tests/console-models-live.test.ts`（模型广场 → 通道：顺序、专属倍率、生图独立倍率、高峰、分档按倍率补价、按次单价、分时段；模型行：目录合并与推断、实付价、长上下文只在通道开分档时显示、折扣、时段说明；筛选排序；人民币按充值比例；收藏）、`tests/console-models-route.test.ts`（没登录 401、读广场与充值比例、广场没开当作没有模型、后端出错）。
- 本机实测（2026-10-04）：测试库建了两个渠道挂 7 个模型，三个分组倍率 0.15 / 0.3 / 1，高性能通道设了高峰 20:00–23:00 ×1.5，打开模型广场。模型广场显示的单价就是全局价格表的官方价（只挂模型不填价不改扣费）。
- 浏览器实测（Edge 无头，开发服务）：标准通道 ×0.15 下 GPT-5.5「$0.75 / $4.5」、超过 272K「$1.5 / $6.75」、折扣 1.5 折、划掉的官方价 $5 / $30；生图「$0.006 / 张」；换高性能通道 ×0.3 后三个 Claude 模型都带高峰说明；切人民币按本机充值比例 0.14 显示「按 1 美元 = ¥7.14 折算」；收藏写进浏览器；手机宽度不横向溢出。
- 交互检查表见页面规格末尾。
