## 1. 职责与边界

模型页是登录后的价目表：按自己的通道看价格；对话页让用户不写代码先试模型。对话不调用接口，回复是占位文字逐字显示。

## 2. 结构与数据流

- 模型：范围（全部 / 收藏）+ 四个筛选下拉 + 搜索 + 排序 + 通道 + 币种 → 官网同一套 `filterModels` → 分页宽表格（首列与操作列固定）；价格按所选通道算，企业通道显示「定制」；文本模型的「试一试」带着模型名跳到对话页。
- 对话：模型（存在网址 `?model=`）与密钥选择 → 显示该通道下的输入输出单价；发送后追加用户消息，助手回复按字逐步显示，可停止；新对话清空。

## 3. 关键决策

- 默认按专用通道（当前用户的默认通道）看价格，和官网价格页同一套计算，数字一致。
- 对话页的模型放进网址，方便从模型页带过去；其他状态都在页内。

## 4. 当前实现

- 模型页：范围标签（全部 30 / 收藏）、四个筛选下拉加搜索、排序标签、通道下拉（默认专用通道）与币种切换；表格首列（星标、厂商标志、名称、调用名）与操作列在桌面固定，手机上首列不固定；价格列跟通道与币种变，企业通道显示「定制」；折扣列是折扣标加划掉的官方价（企业通道只写官方价不划线）；文本模型「试一试」带着模型名跳到对话页。
- 对话页：模型（存在网址里）与密钥选择，旁边是该密钥所在通道与这个模型的单价；示例对话两条；发送后回复逐字出现，可停止（一个字没出就去掉空回复），新对话清空；Enter 发送、Shift + Enter 换行，输入法选字时不发送；输入框用共享多行输入框。
- 模型页 8 个文件、对话页 8 个文件；逐字输出的状态集中在一个纯函数里（有单测）。

## 5. 验证方式

交互检查表见页面规格末尾。
