## 1. 职责与边界

复刻 Aceternity AI SaaS 模板首页的结构和观感，内容换成本站。只展示，不调用接口；数字来自数据层与预览数据文件。

## 2. 结构与数据流

| 区块 | 对应模板 | 内容 |
|---|---|---|
| 首屏 | 首屏 | 生图 API 公告胶囊、两行大标题、副标题（模型数量来自目录）、免费注册与查看价格 |
| 控制台预览 | Acme Dashboard 截图 | 用 JSX 和手写图表画的本站控制台：消费、请求、Token、可用率、调用趋势、模型占比、分组占比、最近请求 |
| 厂商标志 | Trusted by | 8 家模型厂商，四个一组轮换 |
| 能力拼贴 | Packed with features | 文字生成图像、一个接口换模型、按分组调度、协议与工具兼容（地球 + 跑马灯） |
| 特性格 | 4×2 特性格 | 8 条能力，悬停竖条与底色 |
| 模型瀑布流 | 评价瀑布流 | 30 个模型卡三列纵向滚动，按最新排序，个人版美元价格 |
| 号召块 | 深色号召块 | 注册即可开始调用 |

## 3. 关键决策

- 模板里的虚构客户评价和客户标志不用：评价瀑布流换成模型卡，客户标志换成模型厂商。
- 控制台画面用代码画而不是截图：暗色主题能跟着变，数字可以集中替换。
- 首屏只做载入动画，其余区块不做滚动触发的入场动画。

## 4. 当前实现

- 首屏：服务端组件，纯 CSS 载入动画；公告胶囊链接到 `/models?type=image`；副标题模型数量取自目录（30），桌面在语义处换行。
- 控制台预览：侧栏 7 项、顶栏假搜索与版本徽标、4 张数字卡、近 14 天调用折线、模型占比横条、分组占比环形图（专业版、个人版两个分组）、最近请求表，全部手写 SVG 与 JSX，数字取自 `lib/content/console-preview.ts`。
- 厂商标志：共享标志轮换，8 家分两组每 3 秒换一组。
- 能力拼贴：文字生成图像（6 条提示词记录 + 两张 AI 生成的黑白示例图）、一个接口换模型（手机样机 6 个气泡）、按分组调度（三个版本即三个分组，倍率与渠道 + 可点开关）、协议与工具（地球 + 3 行跑马灯胶囊）。
- 特性格：8 格悬停竖条与渐变底色；模型瀑布流：30 张模型卡三列纵向滚动、悬停暂停、个人版价格与折扣（1.5折）；号召块：深蓝渐变加颗粒、白色主按钮。
