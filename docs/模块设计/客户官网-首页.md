## 1. 职责与边界

复刻 Aceternity AI SaaS 模板首页的结构和观感，内容换成本站。只展示；首屏的模型数和模型瀑布流 2026-10-05 起来自后台（见[客户官网-模型与价格](./客户官网-模型与价格.md)），控制台画面是截图。

## 2. 结构与数据流

| 区块 | 对应模板 | 内容 |
|---|---|---|
| 首屏 | 首屏 | 生图 API 公告胶囊、两行大标题、副标题（模型数量来自后台，读不到时不写数字）、免费注册与查看价格 |
| 控制台预览 | Acme Dashboard 截图 | 本站控制台「用量」页的真实截图（占位数据）：按语言、明暗主题、桌面与手机各一张 |
| 厂商标志 | Trusted by | 8 家模型厂商，四个一组轮换 |
| 能力拼贴 | Packed with features | 文字生成图像、一个接口换模型、三种通道、协议与工具兼容（地球 + 跑马灯） |
| 特性格 | 4×2 特性格 | 8 条能力，悬停竖条与底色 |
| 模型瀑布流 | 评价瀑布流 | 后台共享通道的模型卡三列纵向滚动，按最新排序，美元价格；读不到时整块不显示 |
| 号召块 | 深色号召块 | 注册即可开始调用 |

## 3. 关键决策

- 模板里的虚构客户评价和客户标志不用：评价瀑布流换成模型卡，客户标志换成模型厂商。
- 控制台画面改用控制台的真实截图（用户要求，原来手画的画面和实际控制台对不上）：中英文 × 浅色深色 × 桌面手机共 8 张 WebP，页面只下载当前显示的那张；手机上用手机版截图，桌面截图缩到手机宽度字太小。截图里的账号换成占位人名，测试账号不出现在官网上。
- 首屏只做载入动画，其余区块不做滚动触发的入场动画。

## 4. 当前实现

- 首屏：服务端组件，纯 CSS 载入动画；公告胶囊链接到 `/catalog?type=image`；副标题模型数量来自后台（每次打开都用 60 秒缓存里的数据现做），读不到时换成不带数字的一句，桌面在语义处换行。
- 控制台预览：控制台用量页截图（`public/home/console-{语言}-{主题}-{设备}.webp`，桌面 1280×860、手机 375×720，2 倍图，每张 25～95KB），`md` 起用桌面截图；两套主题都懒加载，只下载显示的那套；外框变窄时从左上角裁。截图由本机脚本 `.fleet/tools/shoot-home-preview.mjs` 登录测试账号后拍。
- 厂商标志：共享标志轮换，8 家分两组每 3 秒换一组。
- 能力拼贴：文字生成图像（6 条提示词记录 + 两张 AI 生成的黑白示例图）、一个接口换模型（手机样机 6 个气泡）、三种通道（每种通道一行：通道名 + 一句话定位 + 可点开关，不显示倍率与可用率承诺）、协议与工具（地球 + 3 行跑马灯胶囊）。
- 特性格：8 格悬停竖条与渐变底色；模型瀑布流：后台共享通道的模型卡三列纵向滚动、悬停暂停，卡上是厂商与上下文、建了监测项的对话延迟与端点 PING、实付价与折扣（模型少于 12 个时每列放全部并重复，不露空档）；号召块：深蓝渐变加颗粒、白色主按钮。
