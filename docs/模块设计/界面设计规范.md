# 界面设计规范模块设计

模块定位：给控制台定一套统一的视觉基准，并把这套基准落到共享组件里，让各页面改样式有依据、不再各写一套。

## 1. 职责与边界

本模块负责：

- 定义颜色、圆角、高度、字号、投影这几档取值，并让它们只有一个出处。
- 把这套取值落进共享的语义类和共享组件，改一处带动全部引用页面。
- 提供一个示范页作为参照基准，改样式先在示范页定样，再往页面铺。

本模块暂不负责：

- 页面的信息结构和业务流程，只管观感。
- 官网首屏改造，那是本里程碑的另一个模块。
- 图表的分类配色，那是数据语义，单独维护在[图表配色](../../frontend/src/constants/chartColors.ts)。

## 2. 为什么要先定基准

改造前的状态：有一层语义类，但被各页面直接堆砌的原子类大面积绕过。

- 按钮、输入框、卡片这三样的语义类用得很广，改一处能带动全站。
- 表格的语义类一次都没被用过；统计卡和弹窗外壳各只有两三处。表格和弹窗实际走的是共享组件，而那批组件是纯原子类手写的，不受语义类影响。
- 同一份图表配色在五个文件里各抄了一遍。

所以这一版的做法是两头一起动：语义类负责已经在用的那部分，共享组件负责被绕过的那部分。

## 3. 颜色

### 3.1 主色：深海蓝

整条刻度按同一个色相往两头推，不是只定一格。比常见的默认蓝压深、降饱和。

| 档位 | 取值 | 用途 |
|---|---|---|
| 600 | `#1b4ba8` | 操作色，按钮底、当前项、进度条 |
| 700 | `#163c88` | 悬停；浅底上的强调文字 |
| 800 | `#12306e` | 按下 |
| 400 | `#5080e2` | 深色底上的强调文字 |
| 50 / 100 | `#f2f6fd` / `#e1e9fa` | 徽章底、当前项底 |

主色出现的地方要少。一屏只给一个主操作按钮，状态表达交给状态色，身份标识才用主色徽章。

### 3.2 中性色：暖调

灰阶整体不带蓝。冷蓝灰是后台模板的标配底色，暖中性更接近挑过颜色的观感——这是「质感」差距的主要来源。

改的是灰阶本身的取值，各页面的写法没动，所以上百处直接写灰色的地方一起跟过来了。深色模式配了一套暖底，接近偏褐的黑。

### 3.3 语义表面色

四组语义色，明暗各一套值，写法不带深色变体，切换主题自动跟随。老代码里的深色变体继续有效，两套并存，逐页收编。

| 语义 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| 页面底 | `#fafaf9` | `#171614` | 整页背景 |
| 卡片面 | `#ffffff` | `#1f1d1b` | 卡片、弹窗、表格 |
| 凹陷区 | `#f5f5f4` | `#12110f` | 表头、悬停、禁用 |
| 浅线条 | `#edebe9` | `#2c2926` | 卡片边框、表格行线 |
| 重线条 | `#d6d3d1` | `#3f3b37` | 输入框、次操作按钮 |
| 标题文字 | `#1c1917` | `#f5f4f2` | 标题、关键数值 |
| 正文 | `#44403c` | `#d4d0cb` | 表格单元格、常规描述 |
| 次要文字 | `#78716c` | `#96918b` | 表头、辅助说明、时间 |
| 占位文字 | `#a8a29e` | `#706b65` | 输入提示、空值 |

### 3.4 状态色

只用在徽章上，收敛到四档：正常、警告、危险、未启用。主色徽章和紫色徽章留给身份标识，不拿来表状态。

## 4. 尺度

### 4.1 圆角

整体收紧，最大到 12。做法是重映射刻度而不是逐个文件改，所以各页面现有的圆角写法自动跟着变紧。

标签 4 · 控件 6 · 卡片 8 · 弹窗 10 · 最大 12。

### 4.2 高度

密度的关键。这几档决定列表页一屏能看多少行。

| 档位 | 高度 | 用途 |
|---|---|---|
| 小号 | 28 | 表格行内操作 |
| 常规 | 34 | 按钮、输入框、下拉、筛选 |
| 大号 | 38 | 表单主操作 |
| 表格行 | 36 | 列表正文行 |
| 表头 | 34 | 列表表头 |
| 侧边栏项 | 36 | 导航 |
| 顶栏 | 56 | 全站 |

触屏设备统一放宽到 40 以上，手机上按不中比密度更要命。

### 4.3 投影

卡片靠一条细边框分层，默认没有投影。一带软阴影就往消费级滑。

投影只留给真正浮在页面之上的东西：下拉和气泡一档，弹窗一档。

概览页的重点卡可以加一层环境光晕——角上一团压得很低的主色渐变，只提供氛围。一页用一两处，铺满就成装饰了。

## 5. 字号

只留四档，跨度拉开。中间档位一多，每一档都不突出，整页就糊。

| 字号 | 用途 |
|---|---|
| 12 | 标签、表头、注解 |
| 14 | 正文、表格、按钮 |
| 18 | 页面标题 |
| 30 | 概览页的数字 |

卡片标题和弹窗标题靠字重拉层级，不另占一个字号档位。

去掉了原来的全大写加宽字间距表头——那是英文排版习惯，中文读不出层级，只是平白添噪。

## 6. 两档密度

同一套颜色和圆角，留白和字号分两档。这是行业里的常规解法，看数的页面和干活的页面诉求本来不同。

**舒展档**用于概览、仪表盘、组织首页：留白给足，数字用 30 当主角，统计卡只放标签、数字、注解三行，不配图标和涨跌箭头。

**紧凑档**用于密钥、使用记录、成员管理这类表格页：行高 36，控件 34，一屏尽量多看几行。

## 7. 落地范围

### 7.1 已经收编

| 对象 | 影响页面数 |
|---|---|
| 弹窗外壳 | 75 |
| 下拉选择 | 54 |
| 分页器 | 31 |
| 数据表格 | 26 |
| 开关 | 25 |
| 空态 | 21 |
| 整页底色、顶栏、表格页外壳 | 全部 |

数据表格的行高从 56 降到 36，虚拟滚动的行高估算跟着改小，否则长列表滚动会跳。

下拉选择的触发器原来是 42 高、12 圆角、2px 光环，和旁边的输入框高度差一截，筛选条一直对不齐，现在改成和输入框完全同款。

分页器的当前页原来是淡底彩字，在一排格子里认不出来，改成实心底白字。

### 7.2 还没收编

- 小共享组件：确认框、输入框封装、加载转圈、帮助气泡、日期区间选择、侧边栏，各有两到十六处硬编码残留。
- 自己手写表格和弹窗的页面：用户侧以密钥用量最脏，管理员侧以系统设置、分组管理、风控最脏。管理员这几页只收表格和弹窗，装饰性的先不动。

## 8. 验证方式

- 类型检查和静态检查全过。
- 前端单测 269 个文件 1979 条全过。这一版只改语义类的内容和组件内部的样式，类名和结构没动，所以断言类名的那批用例不受影响。
- 示范页 `/admin/design` 逐栏人工核对，带浅色深色切换。
- 纯展示层不写单测，观感问题肉眼即可发现。

## 9. 决策记录

| 决策 | 结论 | 说明 |
|---|---|---|
| 圆角怎么收紧 | 重映射刻度 | 各页面写法不动，自动跟着变紧，不用改上百个文件 |
| 中性色冷暖 | 换暖调 | 冷蓝灰是后台模板标配，这是质感差距的主要来源；改灰阶取值让全站一起跟过来 |
| 主色选哪个 | 深海蓝 | 三个候选在示范页同条件对比后定的；默认蓝太常见，读起来像没挑过颜色 |
| 眉标要不要留 | 去掉 | 小圆点加一行小字这个套路现在到处都是，一眼看出是套模板 |
| 密度统一还是分档 | 分两档 | 概览页舒展、列表页紧凑；统一放大会让表格页翻页变多 |
| 明暗哪套优先 | 浅色优先 | 深色仍可切换；浅底做质感难度更高，但符合企业客户白天看报表的场景 |
| 先改页面还是先改组件 | 先改组件 | 按页推进等于把同一个表格改二十多遍 |
| 图表配色跟不跟主色 | 不跟 | 那是分类色，改顺序会让旧截图对不上 |
