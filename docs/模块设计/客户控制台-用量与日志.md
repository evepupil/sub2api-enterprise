## 1. 职责与边界

用量页回答「花了多少、花在哪」，日志页回答「某一次请求发生了什么」。数据来自占位用量记录与请求样本，不接后端。

## 2. 结构与数据流

- 用量：时间范围（默认近 30 天）→ `recordsInRange` → 四张数字卡（Token 与缓存命中、请求与成功率、平均耗时与首字、消费与月折算）；全部时间的每日合计 → 53 周热力图（固定看最近一年）+ 范围内的活跃天数 / 最长连续 / 本期消费 / 最活跃日；明细指标（Token / 请求数 / 费用）× 三个维度 → 三张堆叠柱状图，一天的范围按小时出柱。
- 日志：筛选条件（时间、密钥、模型、状态、类型、流式、请求 ID）→ `filterLogs` → 分页表格；行菜单复制请求 ID、复制为 curl、看详情；详情抽屉列出全部字段与请求示例；导出当前筛选结果为 CSV。

## 3. 关键决策

- 热力图固定显示最近一年，右侧四格跟着范围变：一年视图看习惯，范围统计看本期。
- 明细图超过 5 个系列合并成「其他」，颜色顺序固定，「其他」用灰色。
- 日志只是样本，条数与用量页的合计不一一对应（接后端后由接口分页返回）。

## 4. 当前实现

- 用量页：标题行是时间范围与刷新；四张数字卡（Token 与缓存命中、请求与成功率、平均耗时与首字耗时、消费与月折算）；活动面板里热力图打开时停在最近几周，下面四个小格（超宽屏才与热力图左右并排）；用量明细切换 Token / 请求数 / 费用，三张堆叠柱状图（按模型、按 API 密钥、按通道），悬停或方向键看当天明细，「今天」「昨天」按小时出柱。
- 日志页：筛选栏（时间、密钥、模型、状态、类型、流式、请求 ID 搜索、清除筛选、导出 CSV）；表格 1040 宽在小屏横向滚动，操作列固定，行菜单可复制请求 ID、复制为 curl、看详情；详情抽屉列全部字段与请求示例，关闭后焦点回到打开它的按钮；导出的 CSV 带 UTF-8 标记，Excel 打开中文不乱码；没有结果时显示空状态与清除筛选。
- 刷新按钮用共享组件；用量页 5 个文件、日志页 8 个文件。

## 5. 验证方式

- 单测见框架模块（用量汇总、明细拆分、热力图、日志筛选与导出）。
- 交互检查表见页面规格末尾。

## 6. 待扩展项

- 用量改读后端统计接口，日志改读请求记录接口（服务端分页与筛选）；导出改为服务端生成。
- 日志详情链接到工单（「就这条请求提工单」）。
