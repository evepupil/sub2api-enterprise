### 2.2 字体与字号

- 字族：Geist Sans（中文回落 PingFang SC、微软雅黑）；Geist Mono 只用于模型调用名。数字一律等宽数字（`tabular-nums`）。
- 字号阶梯（px）：12 / 14 / 16 / 18 / 20 / 24 / 30 / 36 / 48 / 60 / 72 / 96。
- 首屏标题：手机 40、`sm` 60、`md` 72、`lg` 96，字重 600，行高 1.0～1.1，字距收紧。
- 页面标题与区块标题：手机 30、`md` 48，字重 500，字距 -0.025em。
- 副标题：首屏 18→20，区块 16，颜色 muted-foreground。
- 正文 16/24，说明 14/20，辅助 12/16。

### 2.3 间距、圆角、阴影

- 间距以 4px 为基准：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 64 / 80 / 112 / 128。
- 容器最宽 1280，左右内边距手机 16、`md` 起 32；区块上下留白手机 80、`md` 112。
- 圆角：6（输入框、菜单项、控制台的所有按钮）/ 16（卡片）/ 24～32（大外框、号召块）/ 全圆（官网的按钮、徽标、开关、头像）。官网按钮和顶部菜单栏一套是胶囊形；控制台的按钮统一 6，和输入框、下拉框一致，和输入控件同排的另外统一高 40。
- 阴影：卡片 `0 1px 1px rgba(0,0,0,.05), 0 4px 6px rgba(34,42,53,.04), 0 24px 68px rgba(47,48,55,.05), 0 2px 3px rgba(0,0,0,.04)`；主按钮内描边高光 `inset 0 ±1px 0 rgba(255,255,255,.25)`；浮动顶栏、首屏胶囊、重点卡各一档；暗色下全部换成 1px 浅色描边。

### 2.4 品牌标志

用户 2026-10-08 从三个方向里选定 A「C 抱 o」（另两个是「终端光标」黑方块里的 C_、「像素 C」4×4 方格拼字；对比图在本机 `.fleet/logo/direction-{a,b,c}.png`）。

- 参考：OpenRouter（两个字母合成一个粗形状，缩到 16 像素仍认得出）、Vercel（只用一个几何体、纯黑白）；同时对照过 Together AI（几个小圆讲「多」，缩小后糊成一团，所以不用细碎形状）、Replicate、Groq、Mistral 和 Aceternity 模板的图标。
- 图形：粗圆环开口成 C，中间实心圆点是 o，也像「一个入口连到中心」。32 网格：圆环中心线半径 10.5、线宽 5.5、开口朝右上下各 40°、圆头端点；圆点圆心 (16,16)、半径 3.6。
- 颜色：只用前景色，亮色主题 `#0a0a0a`、暗色主题 `#fafafa`（跟随文字颜色），不加品牌色。
- 组合：图形 20px + 站名 14px 字重 500（顶栏、页脚、登录注册页、控制台侧栏），间距 8px；图形最小 16px，四周留白不少于图形宽度的 1/4。
- 文件：图形组件 `frontend-portal/src/components/layout/brand-mark.tsx`；浏览器标签图标 `src/app/icon.svg`（同一组路径，跟随系统明暗换黑白）；`src/app/favicon.ico`（16/32/48，白色圆角底黑图形，给老浏览器和搜索引擎）；`src/app/apple-icon.png`（180，黑底白图形，手机加到桌面用）；分享卡片 `public/og.png`（1200×630，浅底淡网格、标志加站名、中英文标语与域名）。两张位图由本机脚本 `.fleet/logo/make_icons.mjs` 从图形生成，改图形后重跑。

## 3. 布局与响应式

- 断点：640 / 768 / 1024 / 1280（Tailwind 默认）。验收宽度：手机 375、桌面 1440。
- 顶栏：`lg`（1024）以下切成品牌 + 主题按钮 + 汉堡菜单，菜单在顶栏下方展开成卡片。
- 网格：首页拼贴 `lg` 六列（4+2 / 3+3）；特性格 1 / 2 / 4 列；模型卡 1 / 2 / 3 列；通道卡 1 / 3 列（大屏以下单列收窄居中）。
- 宽表格（价目表、对比表）放进横向滚动容器，手机上整页不出现横向滚动。
- 控制台外壳：整屏固定高度，只有右侧内容区滚动；顶部公告条 40；侧栏 256（收起 64），浅灰底、右边一条分隔线；内容区标题行最小高 64、底部通栏分隔线；标题行与内容区共用一个居中容器（最宽 1440，账户设置 768）、左右 16 / 24 / 32，宽屏下标题与右侧按钮和卡片左右边对齐；侧栏底部一行是头像菜单与通知铃铛，语言、主题切换在头像菜单里；`lg` 以下侧栏换成左侧抽屉（宽 85%、最宽 288），顶部一条 56 高的手机栏放菜单按钮、品牌、通知与头像（点开同一个头像菜单）。
- 控制台表格：表头浅灰底 12px 灰字，行高约 52，悬停变浅灰；首列或操作列固定时自带不透明底色与 1px 分隔阴影；分页条放在表格底部。

## 5. 空态、加载态、错误态

- 空态：虚线框圆角块，中间灰底圆形图标 + 一句标题 + 「清除筛选」次按钮（模型页）；控制台表格里的空态去掉虚线框，按情况给「清除筛选」或「新建」按钮。
- 控制台加载：数据是同步的占位，刷新、保存、提交按钮转圈 600～1200ms 后恢复；保存成功在按钮旁短暂显示对勾与「已保存」。
- 加载态：页面按默认参数在服务端渲染完整内容，浏览器读取网址参数后直接刷新，不显示骨架或转圈；只有按钮提交时显示转圈。
- 错误态：表单字段下方红字；地球组件无 WebGL 时降级为渐变圆；404 页大号「404」+ 返回首页。页面渲染出错（2026-10-08）：官网页保留顶栏页脚，中间换成和 404 同版式的出错页（圆角块里的警示图标、「页面出错了」、「重试」主按钮 +「返回首页」次按钮，服务端出错时下面小字附错误编号）；登录注册页整屏居中同一出错页；控制台保留外壳，内容区用空状态组件写「这一页出错了」+「重试」，错误编号写在说明里；最外层兜底页自带页面框架，中英文各一句加「重试」。

## 6. 动效

- 缓动统一 `cubic-bezier(0.22, 1, 0.36, 1)`；首屏载入 500ms、元素间隔 80ms；悬停 150～200ms；顶栏浮起 300ms；手机菜单、手风琴 200ms；分段控件选中块弹簧（bounce 0.15、0.4s）。
- 循环动画只有：网格光线（8～13s）、跑马灯（36～50s）、地球自转、标志轮换（3s 一组）。
- 不做滚动触发的入场动画、数字滚动、视差、鼠标跟随。系统开启「减少动态效果」时所有循环动画停住。
- 首屏载入动画用纯 CSS（`animate-fade-up`），不依赖脚本：页面一到就开始淡入，脚本加载慢时首屏也不会空白；标志轮换的第一组同理直接显示。

## 7. 无障碍底线

- 正文对比度 ≥ 4.5:1（见 2.1 标注）；彩色色块（graphic）不承载文字。
- 全站键盘可达：分段控件支持左右方向键，下拉与手风琴用 Radix 自带的键盘行为，手机菜单 Esc 关闭。
- 焦点可见：全局 2px 前景色描边，偏移 2px。
- 图标按钮有 `aria-label`，装饰图形 `aria-hidden`，图表 `role="img"` 加说明。
