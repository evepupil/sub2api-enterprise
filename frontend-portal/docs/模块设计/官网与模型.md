# 官网与模型

模块定位：首页、紧凑模型目录和帮助内容。

对应代码：`frontend-portal/src/app/(public)/`、`src/features/catalog/`、`src/features/help/`、`src/components/effects/`（规划）。

所属里程碑：[M1](../roadmap.md#m1) · 当前状态：未开始 · 最近更新：2026-09-27

依据：[架构设计](../架构设计.md) · [技术设计](../技术设计.md) · [前端设计](../前端设计.md)

本文件为规划归档，实施前按对应里程碑补齐详细契约与验收规格。

## 1. 职责与边界

覆盖页面 1、2、5；首页采用已认可的 A 风格和 Aceternity 效果。模型只展示标志/厂家、代号和四项美元价格；帮助承接文档、常见问题、公告与已有联系入口。

## 2. 结构与数据流

匿名官网读取公开配置和模型广场；登录后的目录按实际可见分组与个人倍率查询。将响应转换成紧凑卡片所需数据，复用同一价格格式与排序。帮助内容先采用审核后的仓库内容或既有接口，来源在实施规格中固定。

## 3. 关键决策

模型目录使用 `/catalog`，为已有模型调用接口保留 `/models`。公开与个人价格缓存分开；遵循公开开关和要求登录配置。官方参考价不代替实际展示价。四价顺序固定，缺失显示横线，零价格仍显示零；条件变化可在价格位显示区间。

## 4. 当前实现

已有公开模型广场和四价字段；匿名可见性受配置与运行模式限制。已核对基础价、倍率和现有展示逻辑，但尚未与实际扣费联调。新官网、目录与帮助均未实现。

## 5. 验证方式

价格单位、个人/分组/分时倍率及缺失/零价编写业务测试；验证匿名与登录数据不串用。实际检查三列紧凑布局、搜索、长型号、接口关闭与失败。首页滚动效果在浏览器验收。

## 6. 待扩展项

按用户要求后续补首页内容，保持当前首版基线。取消的模型详情页、卡片说明和调用示例不恢复。
