# 用量统计

模块定位：客户概览、调用明细与统一日期范围。

对应代码：`src/features/usage/`、`src/lib/time/date-range.ts`、`src/components/console/date-range-control.tsx`、`src/components/charts/`。

所属里程碑：[M3](../roadmap.md#m3) · 当前状态：进行中 · 最近更新：2026-09-28

依据：[架构设计](../架构设计.md) · [实施契约](../../design/customer-console.md) · [页面规格](../../design/console-pages.md)

## 1. 职责与边界

概览包含当前资金、请求/Token/实际消费/平均耗时、模型/分组/接口三类环图及表格、四类 Token 趋势，不含最近调用。明细支持日期、模型、密钥筛选、分页和单条详情；组织统计归 M4。

## 2. 结构与数据流

日期控件生成起止日和时区，汇总与快照并行使用相同参数。查询键包含身份、范围、粒度和筛选，旧范围不能更新当前页。适配层校验金额与各分项；错误与零用量分开。当前资金独立查询，普通成员只读自己的配额。

明细保留密钥名称，不返回完整密钥。ECharts 延迟加载、按容器缩放、使用主题颜色、卸载清理，减少动态偏好关闭动画；图旁有完整可读表格。

## 3. 关键决策

只选日历日期：今天、昨天、近7/14/30天、本周、本月、上月和自定义。近N天含今日，本周从周一开始。按小时仅为选定日期内的趋势聚合，不增加时分选择。

缓存写入与读取分别计数，标准消费与实际扣费分开。余额可以为负，缺失不能猜0；配额只有明确 null 才表示不限。密钥路由参数变化重新挂载对应筛选。

## 4. 当前实现

图表已订阅主题变化，应用新 CSS 颜色后更新现有图表；切换外观保留图例选择，不重新查询统计或重建图表。异步加载完成时使用最新配色，卸载时释放订阅。详见 [主题切换](../../design/theme-switching.md)。

2026-09-28 全站切换 [Proactiv 深色主题](../../design/proactiv-redesign.md)。图表的系列、坐标、分隔线、图例和提示框统一从 CSS 主题读取实际色值，继续保留四项图标统计卡、环图合计与日期范围。账户余额、用量和趋势仍来自真实查询，不使用首页的营销展示数据。

总览、明细、八种预选、自定义日历已接入。三种分布支持按 Token/消费切换；加载、错误、空态独立。美元金额、长模型名和宽表格分别处理。2026-09-28 分布卡的维度切换加选中滑块（控制台节奏 180ms），按钮选中语义不变。

总览按已确认示意图对齐：四张统计卡都带标题图标；日期预选和日期按钮并排，删除重复的统计区标题；分布环图中心显示合计与单位，图表与相邻表格保持紧凑两栏。组织统计复用同一统计卡，避免样式漂移。

普通成员的概览资金区提供本人配额申请入口，按需读取配额条件和历史。组织管理员的组织统计使用独立页面，复用本模块日期、图表、金额和记录详情，见[组织用量](组织用量.md)。

## 5. 验证方式

独立测试覆盖日历、闰年/跨年/夏令时、四类 Token、金额分离、查询范围一致、无密钥泄露、负余额与缺失配额。隔离数据库写入14天样例，真实近7天接口返回42条；汇总、明细与当前资金经正式适配器读取成功。样例不进入业务源码或线上数据。

整批执行格式、类型、测试、构建与 HTTP 路由验证；浏览器图表、日历及手机布局仍交用户验收。
