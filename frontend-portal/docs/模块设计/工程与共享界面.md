# 工程与共享界面

模块定位：独立工程、设计主题、基础控件和官网/控制台外壳。

对应代码：`frontend-portal/src/app/`、`src/components/ui/`、`src/components/layout/`、`src/components/marketing/`、`src/components/effects/`、`src/features/theme/`、`src/styles/`、`src/preview/`、`src/lib/navigation.ts`、`scripts/`。

所属里程碑：[M0](../roadmap.md#m0) · 当前状态：进行中 · 最近更新：2026-09-28

依据：[架构设计](../架构设计.md) · [技术设计](../技术设计.md) · [前端设计](../前端设计.md)

详细接口、令牌和写入边界见 [M0 实施规格](../../DESIGN.md)，预览逐区块及交互规格见 [预览页面规格](../../design/foundation-preview.md)。这两份规格由主控维护，各实现路按同一契约工作。

## 1. 职责与边界

负责独立依赖、严格类型、构建门禁、主题与共享控件。官网与控制台共用基础规则；首页动效与业务页面分别放置。建立内部组件预览验证基础外观与交互；该预览与十四个业务页面分开，不连接客户数据。底座原管理界面继续保留。

## 2. 结构与数据流

先把已确认色彩、字体、字号、间距、圆角、阴影、控件尺寸和断点写成主题，再实现按钮、输入、表格、选择器、日历、弹层与加载/空/错状态，最后拼装官网导航和控制台侧栏。

客户端预览使用同一个入口组件，可由受开关保护的 Next 页面加载，也可打包为单个离线 HTML。离线预览用正式组件与同一份 Tailwind 样式，不额外维护模拟版本。导航纯函数接受个人、组织管理员、成员三种身份，返回入口列表；当前项匹配考虑路径边界，客户守卫已在 M2 接入，后端仍作最终权限核验。

## 3. 关键决策

使用 Next.js 16.3.6、React 19.3.0、TypeScript 5.9.3、Tailwind 4.3.3 与 Radix 组合控件；本地源码采用 shadcn/ui 的组合方式，未宣称每个文件是官方源码复制。依赖和锁文件只归新前端所有，输出不覆盖 Go 内嵌的原管理界面。

基础控件使用 Radix 原语完成弹层和键盘行为；日历使用 DayPicker，只选日期。M2/M3 已加入 TanStack Query、ECharts 和本地二维码库，统一业务查询与图表。默认产品路径不发布样例业务数据；内部 `/design` 需显式预览开关，离线产物只在本机生成。

## 4. 当前实现

已增加 [主题切换](../../design/theme-switching.md)：浅色、深色和跟随系统。未选择时保持深色；官网、账号页和控制台复用一个切换控件，刷新恢复与同源标签页同步由浏览器偏好存储负责。首屏脚本在正文绘制前应用颜色，React 使用稳定的服务端快照；存储失败仍能切换当前页面。系统与存储监听在最后一个消费者离开时释放。

2026-09-28 按用户指定的 [Proactiv 整站规格](../../design/proactiv-redesign.md) 实施深色青蓝主题、悬浮导航、完整页脚和统一控制台外壳；营销共享组件单独放入 `components/marketing/`，动效继续由 `components/effects/` 承担。颜色、尺寸与光效集中在主题令牌，业务页面复用原基础组件；本次虚构营销内容集中管理，不写入实际业务接口。

2026-09-28 新增四个共享动效：边框发光、悬停高亮、选中滑块、输入框光晕，由 Aceternity 免费组件改编，放在 `components/effects/`，样式集中在 `styles/effects.css`，颜色取主色派生值。它们只做装饰，不接管点击、焦点与选中语义；减少动态偏好下停用或直接切换，边框发光与输入框光晕只在有鼠标的设备出现。选中滑块分官网与控制台两种节奏，控制台固定 180ms；按钮组共用一个叠放层，文字始终在滑块上方。主题菜单的选项也加选中滑块，沿用浅灰选中底色。边框发光在指针移出窗口或窗口失去焦点时熄灭。规格见[前端设计 · 共享动效组件](../前端设计.md#共享动效组件)。

已建立独立工程、严格类型、锁文件、生产构建与统一门禁。主题颜色、字号、间距、圆角、尺寸和基础反馈集中定义，十三类基础控件与四组页面外壳已落地。

内部预览包含控件、官网外壳、控制台外壳，可操作选择器、日期范围、预览表单、加载/空/错状态和三种身份导航；所有样例集中存放，不访问业务接口。官网入口固定为 `/catalog` 等页面路径，控制台当前项按最长路径匹配；组织成员导航没有付款和团队管理入口，这只反映界面边界。

Next 内部预览默认关闭，`/design` 需服务端显式开启且设置 noindex。`pnpm preview:offline` 使用相同源码与编译后的主题生成 `.preview/index.html`，约 495 KiB，文件已忽略。正式首页与 M2/M3 客户业务页面已在各模块实现。

已修正禁用子链接先执行回调、导航可变对象共享、日历导航位置、触屏关闭按钮、预览嵌套主内容区与重复留白等问题。普通按钮和子元素都保留禁用/加载的可访问语义。

按用户重新指出的示意图要求，控制台侧栏保持视口高度，主业务菜单与底部账号设置/帮助分开；正式身份标识不再采用昵称或邮箱。2026-09-28 用户反馈侧栏顶部的身份标签常被误当成菜单却点不开，已从桌面侧栏、手机菜单和手机顶栏去掉。主区提供紧凑路径行，统计卡共用图标与数值结构；具体对齐点见[控制台修正规格](../../design/console-alignment.md)。

## 5. 验证方式

主题偏好以状态行为测试验证：恢复、系统变化、标签页同步、存储异常、订阅释放、首次绘制与服务端快照。不为配色和控件外观新增单测；浏览器实际点击另行验收。

本次主题实现通过完整工程门禁，累计 24 个测试文件、994 项测试，Windows 与 Linux 生产构建成功。开发与本地生产预览均通过 16 个入口及引用资源检查，并确认首次主题脚本在正文之前；实际浏览器仍无连接。

Proactiv 改版通过完整 `pnpm check`（23 个文件、979 项业务测试）和 Windows/Linux 生产构建；两处本地入口分别检查 16 个页面，开发资源 61 个、生产资源 42 个全部返回 200。独立检查发现的对比度、手机账户操作和减少动态边框问题已修复并复核通过。浏览器工具未连接，尚未完成实际截图、点击及屏宽验收。

建立统一门禁；检查独立构建、严格类型、静态分析、格式和导航规则测试。导航测试由独立测试路编写，覆盖三类身份和相似路径。纯展示不写单测，实际检查桌面/手机、长文本、空/错/加载、悬停、键盘焦点与弹层遮挡。未经明确要求不启动开发服务。

M0 初轮 `pnpm check` 通过：格式、静态分析、严格类型、31 项导航业务及回归测试、生产构建全部通过；实际源码的离线预览构建通过，并检查内嵌脚本语法、主题工具类与资源自包含。单文件预览不请求业务数据，主题切换沿用当前浏览器的外观偏好。基础控件残余问题与外壳/预览集成均已独立复核通过。

2026-09-28 登录恢复修正后的完整门禁通过，共 23 个测试文件、979 项测试，Windows 生产构建与 Linux 容器构建均成功。开发入口和本地生产预览的健康检查、控制台页面及引用的脚本、样式均返回 200。

浏览器工具返回空连接列表，进一步调用 Edge 打开离线文件返回“Browser is not available: edge”。用户后来明确授权开发服务，现持续提供本机验收入口。因此桌面/手机渲染、点击和键盘行为仍待实际验收，M0 保持进行中；构建和静态评审不替代这部分。

## M2/M3 集成补充

开发输出使用 `.next`，生产输出使用 `.next-build`，各自忽略，构建不覆盖开发运行文件。根布局注入统一账号与查询容器；M4 团队入口已接入，控制台按实际组织身份显示。

开发命令固定使用 Webpack，并绑定 `127.0.0.1`。开发来源由 `config/development-origins.mjs` 统一解析：保留两个本机入口，并接入配置的公开地址和额外开发地址。Next 使用域名检查资源与热更新，接口使用完整 origin 检查写入；同机 Cloudflare Tunnel 可直接转发到回环端口。操作入口见[本地联调说明](../../README.md#本地联调)与[隧道说明](../../README.md#通过-cloudflare-tunnel-访问-dev)。

2026-09-28 本机开发公开地址已配置为 `https://dev.chaosyn.com`，重启开发服务后，通过真实隧道验证首页、登录页、控制台页面、首页八个脚本/样式资源及热更新握手正常。新增域名须先写入本机配置并重启；仅确认首页 HTML 返回 200 不能证明页面可用。详情见[开发隧道验证记录](../进度/2026-09-28-开发隧道.md)。

实际 HTTP 访问发现 React 19 服务端流式子节点不能直接交给按钮的单子元素检查；按当前 Radix 的解包方式处理后，保留禁用事件守卫，首页从连续500恢复为连续200。减少动态偏好的初始快照与服务端保持一致，修正已观察到的首页水合告警。两项属于本轮集成修复，按钮逻辑经独立复核。
