# 工程与共享界面

模块定位：独立工程、设计主题、基础控件和官网/控制台外壳。

对应代码：`frontend-portal/src/app/`、`src/components/ui/`、`src/components/layout/`、`src/styles/`（规划）。

所属里程碑：[M0](../roadmap.md#m0) · 当前状态：未开始 · 最近更新：2026-09-27

依据：[架构设计](../架构设计.md) · [技术设计](../技术设计.md) · [前端设计](../前端设计.md)

本文件为规划归档，实施前按对应里程碑补齐详细契约与验收规格。

## 1. 职责与边界

负责独立依赖、严格类型、构建门禁、主题与共享控件。官网与控制台共用基础规则；首页动效与业务页面分别放置。底座原管理界面继续保留。

## 2. 结构与数据流

先把已确认色彩、字体、字号、间距、圆角、阴影、控件尺寸和断点写成主题，再实现按钮、输入、表格、选择器、日历、弹层与加载/空/错状态，最后拼装官网导航和控制台侧栏。

## 3. 关键决策

使用 Next.js、React、TypeScript、Tailwind 与 shadcn/ui。依赖和锁文件只归新前端所有，正式输出不得覆盖 Go 内嵌的原管理界面。具体版本在建工程时核对兼容并固定。

## 4. 当前实现

新前端当前只有设计文档与独立首页动效样稿。样稿已通过静态检查和构建，尚无真实浏览器验收；正式工程、主题配置与基础组件均未建立。

## 5. 验证方式

建立统一门禁；检查独立构建、严格类型与格式。纯展示不写单测，实际检查桌面/手机、长文本、空/错/加载、悬停、键盘焦点与弹层遮挡。未经明确要求不启动开发服务。

## 6. 待扩展项

品牌资料和内容可以替换；共用规则改动同步主题和文档。实施前细化组件属性、布局规格和验收页面。
