# 组织用量

模块定位：组织总体费用、成员分布与按成员查询。

对应代码：`frontend-portal/src/features/organization-usage/`（规划）；复用既有组织用量接口。

所属里程碑：[M4](../roadmap.md#m4) · 当前状态：未开始 · 最近更新：2026-09-27

依据：[架构设计](../架构设计.md) · [技术设计](../技术设计.md) · [前端设计](../前端设计.md)

本文件为规划归档，实施前按对应里程碑补齐详细契约与验收规格。

## 1. 职责与边界

覆盖页面 15，仅对现有权限允许的组织管理员开放。普通成员在个人总览查看自己的用量，不获得组织全量账单。

## 2. 结构与数据流

复用统一时间控件和图表样式，调用组织用量接口查询组织合计与成员分布；按成员筛选后更新当前范围的数据。缓存包含已确认的组织与账号身份。

## 3. 关键决策

组织费用、成员归属和付款关系沿用底座。精确时间规则与个人统计一致；若组织接口仍只接受日期，在本模块补齐兼容扩展，不能截断用户选择。

## 4. 当前实现

已有组织用量与成员查询能力，本轮未逐条确认其精确时间支持。新页面尚未实现，实施前完成组织查询契约核对。

## 5. 验证方式

检查组织合计与成员分项、普通成员访问拒绝、跨组织隔离、成员状态变化和范围切换；为组织数据转换与时间语义编写核心测试。

## 6. 待扩展项

扩展同一组统计展示时复用 M3 的基础能力；不增加用户未要求的预算分析或企业报表。
