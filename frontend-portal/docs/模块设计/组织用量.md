# 组织用量

模块定位：组织总体费用、成员分布与按成员查询。

对应代码：`src/features/organization-usage/`、`src/app/console/team/usage/`；复用既有日期、图表和组织用量接口。

所属里程碑：[M4](../roadmap.md#m4) · 当前状态：已完成 · 最近更新：2026-09-28

依据：[架构设计](../架构设计.md) · [技术设计](../技术设计.md) · [前端设计](../前端设计.md)

本轮连续实施，接口、页面与验收细节见[团队与交付实施契约](../../design/team-and-delivery.md)。业务规则以当前底座为准。

## 1. 职责与边界

覆盖页面 15，仅对现有权限允许的组织管理员开放。普通成员在个人总览查看自己的用量，不获得组织全量账单。

## 2. 结构与数据流

复用统一日期控件和图表样式，汇总和图表读取相同的日期、时区、趋势粒度与成员范围；记录列表沿用日期和成员条件。缓存包含当前账号、日期和成员，切换筛选回到第一页。

统计请求明确指定组织范围，按成员查询使用底座的成员筛选参数。成员选项取完整组织列表，包含管理员和已停用成员；通过链接进入时保留指定成员，即使选项暂时无法读取，也不会悄悄改成全组织。

## 3. 关键决策

组织费用、成员归属和付款关系沿用底座。查询只选起止日期，与个人统计共享日期预选和时区规则，按现有接口传参；取消精确时分的兼容扩展计划。

底座成员分布固定统计全组织，页面明确标为“全组织成员分布”，只跟随日期范围。其他汇总、模型图、趋势和记录跟随选中成员。分布只含有消费记录的人，不能用它推断组织人数。

明细只保留成员展示信息、密钥名称、模型、四类 Token、标准费用与实际费用等需要的数据；原始密钥和其他人的余额不进入前端展示对象。

## 4. 当前实现

2026-09-28 随 [Proactiv 整站改版](../../design/proactiv-redesign.md) 统一深色摘要、表格和图表；坐标、图例和提示框由共享图表从主题读取颜色。组织汇总、成员分布、日期范围和费用口径仍沿用真实查询。

已实现组织用量页：请求量、Token 总量、实际消费、平均耗时四张汇总卡，成员费用分布与成员表，模型和接口分布、四类 Token 趋势及调用明细。点击成员切换查询范围；明细复用已有详情弹窗。个人账号和普通成员无法进入组织统计。2026-09-28 成员分布卡的 Token/消费切换加选中滑块（控制台节奏 180ms）。同日按控制台质感改版调整：规格见[控制台质感改版](../../design/console-refresh.md)。筛选卡片与可见字段名去掉，日期、成员与粒度收成页头下方的一排胶囊控件并保留重置；「当前统计对象」只供读屏播报；总 Token 卡不再列分项，分项合计写进趋势图例；分布切换改用分段切换组件；金额统一两位小数；成员分布中正在查看的成员行用主色浅底标出，鼠标停在该行上也不会被悬停色盖掉。

汇总卡复用个人总览的带图标统计卡，金额单位和四类 Token 仍沿用既有数据口径；布局修正见[控制台对齐规格](../../design/console-alignment.md)。

空数据、加载、请求失败和无权限分别展示；失败不显示为零消费。历史停用成员仍可查询。按天口径沿用 M3，默认统计时区为上海，部署时需和底座/数据库统计配置保持一致。

## 5. 验证方式

独立测试核对组织范围、成员筛选参数、日期一致性、分页、缺失字段处理和密钥信息剔除。隔离环境使用管理员、成员、个人账号与组织消费样本验证汇总和成员范围；浏览器外观及实际点击结果见[部署与验收](部署与验收.md)。

固定样本实际返回 3 次请求、12 个 Token、标准费用 0.30 USD、实际费用 0.24 USD，覆盖管理员、普通成员和停用历史成员。单成员筛选及分页正确，第二组织样本未进入结果，个人账号无法获取组织范围；详见[首版联调记录](../验收/2026-09-27-首版联调.md)。

## 6. 待扩展项

扩展同一组统计展示时复用 M3 的基础能力；不增加用户未要求的预算分析或企业报表。
