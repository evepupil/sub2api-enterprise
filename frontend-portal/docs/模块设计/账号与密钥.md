# 账号与密钥

模块定位：注册登录、账号设置及客户密钥管理。

对应代码：`frontend-portal/src/features/auth/`、`src/features/keys/`、`src/lib/api/`（规划）；复用既有账号和密钥接口。

所属里程碑：[M2](../roadmap.md#m2) · 当前状态：未开始 · 最近更新：2026-09-27

依据：[架构设计](../架构设计.md) · [技术设计](../技术设计.md) · [前端设计](../前端设计.md)

本文件为规划归档，实施前按对应里程碑补齐详细契约与验收规格。

## 1. 职责与边界

覆盖页面 6、7、8、10、13。保留现有注册限制、创建/加入组织与双重验证规则；密钥设置遵循后端授权、额度和有效期。已启用的登录方式按真实配置接入，不凭代码存在新增产品入口。

## 2. 结构与数据流

浏览器完成登录后保存访问与续期凭证，调用当前账号接口核实身份，再启动私有查询。请求层统一附加凭证，过期时协调续期；退出调用后端撤销并清理本地。密钥操作通过现有客户接口。

## 3. 关键决策

延续后端基于请求头的认证，首版不增设身份服务。私有控制台在浏览器恢复身份后加载，公开服务端页面不读取个人会话。客户前端独立存储命名；同标签与跨标签协调一次性续期，退出或换号后旧结果不得写回。没有续期凭证的降级响应单独处理。

## 4. 当前实现

已核对登录/注册/双重验证返回、请求头认证、续期轮换、服务端退出和用户组织摘要。组织管理员由组织归属字段判断，与平台管理员身份分开。新前端会话和页面未实现。

## 5. 验证方式

测试续期并发、跨标签竞争、换号、退出后迟到响应、401/403和无续期凭证。联调注册邀请、密码恢复链接与双重验证。密钥范围、额度、到期和删除等操作验证后端权限结果；私有信息不得短暂显示给另一身份。

## 6. 待扩展项

实施前核对已启用第三方登录的回调、Cookie 与站点地址，完成回调落地路由；不新增企业身份体系。
