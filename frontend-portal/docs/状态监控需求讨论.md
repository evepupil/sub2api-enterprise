# 官网状态监控需求

状态：已定稿（三项范围） · 最近更新：2026-09-27

所属需求：[独立客户前端需求设计](./需求设计.md#4-功能大类与当前取舍)中的 L 模块。

实施入口：[M1 官网与公开信息](./roadmap.md#m1) · [公开状态模块](./模块设计/公开状态.md)。

官网公开展示，首版实现。功能范围只包含以下三项：

| 功能 | 内容 |
|---|---|
| 可用性 | 展示现有接口给出的近 7 天探测可用率 |
| 速度 | 展示最近一次探测的响应耗时 |
| 历史可用性 | 用状态条展示近期探测结果和实际时间范围，不展示历史速度 |

当前接口每个监测项最多返回 60 个历史点，因此标为“近期可用性记录”；近 7 天可用率展示已有汇总，不从这 60 条重算。首版不要求完整七天历史曲线，也不扩展后端历史接口。无数据时保留缺失状态。
