# 官网素材与动效来源

日期：2026-09-27 · 所属：[M1 官网](../roadmap.md#m1)

| 内容 | 来源与使用方式 |
|---|---|
| 首页 Spotlight 光效 | Aceternity [Spotlight New 源码](https://ui.aceternity.com/registry/spotlight-new.json)，基于前轮本机适配，改为低对比灰色并支持减少动态偏好 |
| 产品预览滚动效果 | Aceternity [Container Scroll 源码](https://ui.aceternity.com/registry/container-scroll-animation.json)，使用滚动进度驱动透视与缩放，缩短空白并保持图片原比例 |
| 控制台界面示意 | 前轮生成的 [统计总览图](./示意图/09-A统计总览修订.png)，复制为官网本地素材；页面明确标“控制台界面示意”，图内数值不代表真实运营数据 |
| 三家厂家标志 | 前轮从公开 `@lobehub/icons-static-svg` 素材包取得的 OpenAI、Anthropic、Google SVG；本地保存，不请求外部图片 |
| 其余厂家 | 名称取目录识别结果，图标使用中性首字母，不猜品牌图片 |

官方免费组件使用说明见 [定价页](https://ui.aceternity.com/pricing) 和 [许可页](https://ui.aceternity.com/licence)。没有购买 Pro，也没有把不明许可标成 MIT。

正式目录价格来自后端公开模型数据；只有本机离线预览使用集中构造样例。正式路由不导入预览样例或参考价格文件。
