# 官网素材与动效来源

日期：2026-09-28 · 所属：[M1 官网](../roadmap.md#m1)

## Proactiv 改版来源

- 视觉参考：[官方模板介绍与预览](https://ui.aceternity.com/template-preview/proactiv-marketing-template)、[实际预览站](https://proactiv-aceternity.vercel.app)。已读取公开结构与官方截图，采用深色、青蓝操作、悬浮导航、产品卡片和完整营销页的组织方式。
- Aceternity [Moving Border](https://ui.aceternity.com/registry/moving-border.json) 用于结尾操作区，适配现有 Motion、严格类型及减少动态偏好；Spotlight 和 Container Scroll 继续复用下表的公开来源，配色切换到统一主题。
- 首页产品面板改为本地 HTML/SVG 展示，旧控制台位图不再作为新版首页内容。Nexus API 标记、虚构客户标记与图形由代码绘制。
- `src/content/marketing.ts` 集中记录首页与账号页的全部营销文案、授权构造的品牌与控制台示意数据。它不向真实账号、账单、目录价格或状态监控提供数据。2026-09-28 企业版改版后不再包含使用场景与客户故事，能力说法的依据见下节。

## 2026-09-28 企业版首页能力说法核实

首页文案参考原前端企业落地页 `frontend/src/i18n/locales/zh/landing.ts`，逐条对照后端代码与文档核实后再写入；新增或修改能力说法前按同样方式核实。

| 首页说法 | 结论与依据 |
|---|---|
| 高可用调度：分组内多上游账号，异常自动切换并临时隔离故障账号 | 成立。`backend/internal/service/openai_account_scheduler.go`（排除失败账号后重选）、`backend/internal/handler/failover_loop.go`（切换与临时隔离） |
| 低延迟转发：流式响应按上游事件逐条转发，不整段缓冲 | 成立。`backend/internal/service/gateway_anthropic_passthrough.go` 按事件边界转发并即时刷新。原稿「只做鉴权路由计量、原样透传不改写」不成立（转发中会解析用量、跨协议转换），不写 |
| 访问控制：密钥额度、有效期、5 小时 / 1 天 / 7 天速率限制、IP 白名单与黑名单、可用分组 | 成立。`src/features/keys/types.ts`、`src/features/keys/validation.ts` |
| 组织隔离、配额分配、分组授权、统一停用 | 成立。`docs/模块设计/成员管理与消费配额.md`、`docs/模块设计/组织分组与密钥权限.md`（仓库根 docs） |
| 接入协议：OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Gemini 原生协议、图像生成 | 成立。`backend/internal/server/routes/gateway.go` |
| 计费精度小数点后 8 位；余额按调用实时扣减，无最低消费 | 成立。`docs/模块设计/成员管理与消费配额.md`；门户有余额充值，原稿「无预付」不成立，不写 |
| 调用记录逐次含成员、密钥、分组、用量、费用与耗时；组织停用后记录仍可查询 | 成立。记录为统计信息，不含调用内容 |
| 独立部署 | 成立。`deploy/` 部署工具链与[部署与验收](../模块设计/部署与验收.md)中的客户环境部署记录 |

不写的说法：请求内容安全检测与原稿「安全防火墙」（按组织策略与密钥泄露识别属于独立的 ACF 产品，且用户要求不写任何读取或检测调用内容的说法）、按成员导出数据（新门户未提供）、调用记录按周期留存与公有云托管（查无依据）、使用场景、客户案例、兼容工具、调用示例与技术规格表（用户要求删除）。页面也不加「界面示意」「数据非实测」之类的说明性标注（用户要求）。

## 2026-09-28 共享动效补充

用户在 Aceternity 组件大全中逐项确认后采用下列四项，均为免费组件；改编规格见[前端设计 · 共享动效组件](../前端设计.md#共享动效组件)。

| 内容 | 来源与改编方式 |
|---|---|
| 首页平台能力卡边框发光 | [Glowing Effect](https://ui.aceternity.com/components/glowing-effect)：保留「指针方向决定光段朝向、平滑转向」的做法；四色渐变改为主色，遮罩改用常见的挖空内容区写法；默认开启，触屏与减少动态下停用 |
| 帮助中心常用任务卡悬停高亮 | [Card Hover Effect](https://ui.aceternity.com/components/card-hover-effect)：只取滑动底色，卡片结构与链接语义保留项目实现；键盘聚焦同样触发；每组独立标识，避免同页多组互相串 |
| 页签与分段切换的选中滑块 | [Tabs](https://ui.aceternity.com/components/tabs) 的 layoutId 滑块做法；组件本身未引入（缺少页签语义与键盘支持，且会同时渲染全部面板） |
| 登录注册输入框光晕 | [Signup Form](https://ui.aceternity.com/components/signup-form) 输入框的跟随光晕；包在现有输入框外，校验、触控高度与焦点样式沿用项目输入框 |

官方免费组件使用说明见 [定价页](https://ui.aceternity.com/pricing) 和 [许可页](https://ui.aceternity.com/licence)。没有购买 Pro，也没有把不明许可标成 MIT。

正式目录价格来自后端公开模型数据；只有本机离线预览使用集中构造样例。正式路由不导入预览样例或参考价格文件。
