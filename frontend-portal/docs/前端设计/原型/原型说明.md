## 查看方式

用 Edge 打开同目录的 [首页动效.html](./首页动效.html)，向下滚动查看产品面板逐渐回正的效果。文件已内嵌脚本、样式、厂家标志与展示图片，无需安装依赖或启动服务。

页面包含首屏灰色光效、随滚动变化的控制台展示和三张紧凑美元价格卡。导航与按钮只跳到当前页面的对应内容；控制台展示是一张样例图，图内操作不具备真实业务功能。

## 组件来源与改动

- [Spotlight New 官方源码](https://ui.aceternity.com/registry/spotlight-new.json)：保留左右光束往复运动，替换为低对比灰色渐变，支持系统减少动态效果偏好。
- [Container Scroll Animation 官方源码](https://ui.aceternity.com/registry/container-scroll-animation.json)：保留滚动进度驱动的透视、缩放与标题位移；缩短展示区域和动画距离，改用浅色边框，补齐严格类型并减少手机透视幅度。
- 将原组件的工具样式适配为共享颜色、间距、字号与尺寸变量，便于独立单文件展示。
- 原始源码 JSON 与适配源码留在本机 `.fleet/prototypes/aceternity-home-20260926/`，其中依赖和构建脚本与正式项目隔离。
- 官方 [定价页](https://ui.aceternity.com/pricing)说明免费组件可用于个人及商业项目；参见 [许可页](https://ui.aceternity.com/licence)。本次使用公开组件，未购买 Pro，未将许可标为 MIT。

## 内容与业务边界

- 名称“模型服务”为临时名称。厂家图标取自公开的 `@lobehub/icons-static-svg` 素材包，仅用于标识厂家。
- 三款模型价格引用本轮核对的仓库基础价格快照，单位为美元/百万 Token；正式价格仍以当前业务配置为准。
- 控制台预览是 [新版总览示意图](../示意图/09-A统计总览修订.png)，账户、金额、用量和图表均为构造样例。
- 文件不连接业务接口；内容安全策略禁止网络连接，所有页面素材内嵌，字体使用本机已有字体。
- 本样稿只验证首页两种动效和 A 风格的搭配。完整首页内容、正式路由、登录、充值和统计交互仍属于后续正式实现；用量已收敛为日期范围，精确时分查询扩展已取消。

## 本机复现

使用 Windows 工具链，在项目根目录运行：

```powershell
Set-Location .fleet/prototypes/aceternity-home-20260926
npm ci
npm run typecheck
npm run format:check
npm run build
```

构建会覆盖同目录的 HTML 交付物，不会启动服务。原型任务 whmw3q 超时后由主控完成并验证。
