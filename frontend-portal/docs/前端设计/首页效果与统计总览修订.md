# 首页效果与统计总览修订

状态：用户已认可当前方向与内容范围，日期查询已按最新取舍简化 · 最近更新：2026-09-27

关联：[需求设计](../需求设计.md) · [页面清单](../页面清单.md) · [视觉规范](../前端设计.md)

## 1. 本轮明确的调整

- 保留 A 灰白黑风格。
- 首页采用 Aceternity UI 的公开组件增加首屏光效和产品展示层次。
- 概览移除最近调用列表，增加请求数、Token、实际消费、平均耗时等区间统计。
- 参考用户提供的界面，使用模型、分组、接口分布的环形图与相邻数值表，展示请求量、Token 和实际消费；另展示 Token 趋势。
- 日期范围提供按天的常用预选与自定义起止日期。统计卡片、分布、表格、趋势使用同一范围。
- 当前余额或配额放在页头，继续表示当前账户状态，不随统计时间范围回退。
- 用户确认“先就这样”，当前信息量保留，后续再补内容；本轮停止扩展页面内容，继续技术设计。

## 2. 首页效果安排

| 部位 | 组件与效果 | 使用方式 |
|---|---|---|
| 首屏背景 | [Spotlight New](https://ui.aceternity.com/components/spotlight-new) | 将默认彩色光斑调整为低对比灰白光效，衬托文字与产品展示 |
| 产品展示 | [Container Scroll Animation](https://ui.aceternity.com/components/container-scroll-animation) | 展示控制台预览，随滚动由轻微透视逐渐回正 |
| 模型与价格 | 已确认的紧凑卡片 | 保留厂家标志与名称、型号和四项美元价格 |

效果集中在首页。文字与操作保持可直接阅读，低动态偏好下提供平稳展示。控制台继续以清晰的统计与操作为主。

官方组件基于 React、Tailwind 和 Motion；官网说明它们可用于支持这些依赖的 React 环境，Next.js 并非必需。后续技术设计将按能直接接入官方组件的方向安排。

官方 [定价页说明](https://ui.aceternity.com/pricing)允许免费组件用于个人及商业项目；Pro 提供额外模板与区块。本次采用公开组件，没有购买 Pro，也没有将其许可擅自标为 MIT。来源与许可参见 [官方许可页](https://ui.aceternity.com/licence)。

## 3. 总览的信息组织

| 区域 | 内容 |
|---|---|
| 账户状态 | 当前余额或配额；付款账号提供充值入口 |
| 时间栏 | 按天预选、当前起止日期、趋势粒度 |
| 汇总 | 总请求数、总 Token、实际消费、平均耗时；Token 可附输入、输出和缓存分项 |
| 模型分布 | 环形图配模型、请求、Token、消费表格，可按 Token 或消费查看占比 |
| 分组分布 | 环形图配分组、请求、Token、消费表格 |
| 接口分布 | 环形图配入站接口、请求、Token、消费表格 |
| Token 趋势 | 输入、输出、缓存写入、缓存读取随时间的变化 |

图表分类可用蓝、青、紫、琥珀、灰蓝等少量颜色区分数据。按钮、导航、背景与表面继续遵循 A 风格。同一分类在同类图表和相邻表格保持一致颜色。

最近调用摘要从概览中移除。逐条调用记录继续由用量明细页面提供。

## 4. 时间选择

预选包含今天、昨天、近 7 天、近 14 天、近 30 天、本周、本月、上月和自定义。近 N 天包含今天，共 N 个日历日；本周按周一至今天计算。

自定义弹层提供日历与起止日期输入，查询包含开始日和结束日。选好后统一应用，所有统计使用相同的日期与时区。根据用户 2026-09-27 的取舍，删除近 24 小时和时分选择，不增加后端参数。图表小时或天的聚合粒度与日期选择分别处理。

实现时需要保证：

- 所有预选都显式传入起止日期与时区，不借用会带入当前时刻的相对周期默认值。
- 起止日包含在查询内，由现有后端使用开始日零点至结束日次日零点的边界。
- 切换范围时旧响应不能覆盖新范围的数据，各统计区块保持同一口径。
- 无数据和加载失败明确处理，不保留成另一时间范围的正常结果。

## 5. 现有统计能力核对

本轮只读核对，未调用生产接口。

| 能力 | 已有入口或证据 | 结论 |
|---|---|---|
| 区间汇总与接口分布 | [用户用量处理](../../../backend/internal/handler/usage_handler.go)，547–562 行；用户接口 `/usage/stats` | 请求、四类 Token、实际费用和平均耗时可复用；返回前会剥离上游成本等内部信息 |
| 模型、分组、趋势 | 同一处理文件 669–786 行；`/usage/dashboard/models`、`/usage/dashboard/snapshot-v2` | 已有用户级数据；快照查询需启用分组统计 |
| 时间范围 | 同一处理文件 210–262 行 | 自定义起止接受日期，按用户时区处理并覆盖结束日，满足当前按天范围需求 |
| 趋势粒度 | [用量查询](../../../backend/internal/repository/usage_log_repo.go)，39–53 行 | 小时格式包含日期，多日也可按小时聚合；前端默认选择日粒度不等于后端只支持同日小时统计 |
| 当前时间选择 | [日期范围组件](../../../frontend/src/components/common/DateRangePicker.vue) | 已有多种预选与自定义日期，可参考其业务规则，新的控件需支持统一且准确的时间范围 |

累计/今日仪表盘汇总与区间统计是不同入口。新总览应使用与当前时间范围一致的统计，不能把累计平均耗时或累计请求数混入区间图表。用户前端继续使用用户级接口，不直接接管理员统计。

本轮取消精确起止时间的扩展计划。前端统一日期、时区与筛选缓存即可使用既有接口；此范围无需后端修改。
