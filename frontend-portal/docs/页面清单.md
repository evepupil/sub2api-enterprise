## 2. 页面组织

- 官网模型列表采用紧凑卡片，只展示厂家标志与名称、模型代号和四项美元价格；接入文档仍由帮助中心承接。
- 充值操作和充值订单放在同一个财务页面；单条订单的查看方式在区块设计时确定。
- 密钥创建与编辑、成员配额调整放在相关管理页面内，具体交互形式在界面设计时确定。
- 组织页面按现有角色权限提供入口。普通组织成员的概览显示自己的配额和用量，付款归属遵循现有规则。
- 平台管理后台继续沿用现有界面，已获用户确认。

## 3. 官网内容

官网共四个页面。视觉采用 A 灰白黑方向；模型卡片进一步收缩为标识与价格，具体尺寸在紧凑版示意图中验证。

### 3.1 首页

对应页面 1，需求 A；模型与价格内容复用需求 C，个人与团队内容依据 E、G。

| 区块 | 内容 |
|---|---|
| 服务定位与入口 | 一句话介绍服务，提供查看模型、开通账号或进入控制台的入口 |
| 产品展示效果 | 使用 Aceternity 的灰白光效与滚动展示呈现控制台预览，承载实际产品内容 |
| 模型与价格概览 | 展示真实可用模型及价格摘要，进入完整模型列表 |
| 使用方式 | 简要说明开户、余额充值、建立密钥和开始调用的流程 |
| 个人与团队使用 | 介绍个人密钥和用量管理，以及已有的组织成员与配额能力 |

### 3.2 模型列表

对应页面 2，需求 C。每张卡片只含厂家标志与名称、模型代号和四项价格，取消独立详情页。

| 区块 | 内容 |
|---|---|
| 查找区 | 模型名称搜索与厂商筛选 |
| 模型卡片 | 厂家标志与名称、模型代号；四价固定按输入、缓存写入、缓存读取、输出排列；采用美元，复用 Sub2API 定价数据 |

桌面示意采用三列小卡片，一屏显示多款模型。价格单位统一标注，卡片中删除能力介绍、计费说明、接入地址、调用示例及相关操作按钮。

### 3.3 服务状态

对应页面 4，需求 L。功能范围保持用户已确认的三项。

| 区块 | 内容 |

| 可用性 | 现有近 7 天探测可用率 |
| 速度 | 最近一次探测的响应耗时 |
| 历史可用性 | 近期最多 60 个探测状态及其实际时间范围 |

## 4. 已确认的控制台内容

用户已确认下面七个页面的内容。具体布局和控件在视觉设计时确定。

| 页面编号 | 页面 | 确认内容 |
|---|---|---|
| 9 | 概览 | 页头余额或配额；请求、Token、实际消费、平均耗时；模型/分组/接口环形图与数值表；Token 趋势；按天预选及自定义日期范围 |
| 10 | 密钥管理 | 密钥列表，创建与编辑，使用范围、额度、有效期，以及每把密钥的消费 |
| 11 | 用量明细 | 按时间、模型和密钥查询调用记录与费用 |
| 12 | 余额与订单 | 当前余额、充值操作、订单状态和到账记录 |
| 13 | 账号设置 | 个人资料、密码与双重验证 |
| 14 | 组织与成员 | 组织信息、成员邀请与列表、成员启停和消费配额 |
| 15 | 组织用量 | 组织总用量与消费、成员分布和按成员查询 |

账号入口按已确认规则提供登录、注册和找回密码；注册承接个人、创建组织和邀请加入组织的流程。组织和财务信息的可见范围遵循现有角色权限。

概览按用户要求移除最近调用。日期选择统一影响区间统计，当前余额或配额保持当前值。查询只选日历日期，保留今天、昨天、近 7/14/30 天、本周、本月、上月和自定义；删除近 24 小时与时分输入。细节见 [首页效果与统计总览修订](./前端设计/首页效果与统计总览修订.md)。
