# 独立客户前端开发路线图

状态：已定稿，按里程碑实施 · 最近更新：2026-09-28

当前进度：Proactiv 整站视觉与完整官网内容已实现，工程门禁和本地开发/生产预览访问检查通过；M5 正式运行与浏览器验收继续单独记录。

依据：[需求设计](./需求设计.md) · [页面清单](./页面清单.md) · [技术设计](./技术设计.md) · [架构设计](./架构设计.md)

## 项目目标

基于现有 Sub2API 做独立官网和客户控制台，覆盖已确认的十四个页面。首版完成余额充值、密钥、按天查询的用量和组织业务，公开状态监控包含可用率、当前响应速度、近期可用性记录。这里的 M 编号属于新前端，与根目录原项目路线图分别管理。

## 里程碑与架构

<a id="m0"></a>
### M0 工程基础

对应 [页面与共享界面](./架构设计.md#layer-ui)、[请求与数据转换](./架构设计.md#layer-data)。先建立依赖、主题、基础控件和两套页面外壳，再开始业务页面。

<a id="m1"></a>
### M1 官网与公开信息

对应 [客户业务模块](./架构设计.md#layer-business)、[后端复用](./架构设计.md#layer-backend)。公开价格和监控沿用已有接口与业务开关，状态历史只展示已有近期可用性记录。

<a id="m2"></a>
### M2 账号与密钥

对应 [客户业务模块](./架构设计.md#layer-business)、[请求与数据转换](./架构设计.md#layer-data)。建立会话与身份边界，供后续客户数据查询复用。

<a id="m3"></a>
### M3 个人工作台与资金

对应 [客户业务模块](./架构设计.md#layer-business)、[后端复用](./架构设计.md#layer-backend)。统一日期范围和计费口径，再联调总览、明细和订单。

<a id="m4"></a>
### M4 团队业务

对应 [客户业务模块](./架构设计.md#layer-business)、[请求与数据转换](./架构设计.md#layer-data)。复用已建立的身份与统计能力，接入组织成员、配额和组织用量。

<a id="m5"></a>
### M5 联调上线

对应 [部署与交付](./架构设计.md#layer-delivery)。执行整站验收与部署，具体配置、结果和回退步骤写入模块文档。
