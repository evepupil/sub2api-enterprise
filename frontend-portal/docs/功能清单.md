# 首版功能清单

状态：已定稿（已确认需求的索引） · 最近更新：2026-09-27

来源：[需求设计](./需求设计.md) · [页面清单](./页面清单.md) · [路线图](./roadmap.md)

本表整理已确认的范围，沿用需求 A–L 编号；未新增功能。

| 编号 | 功能 | 范围 | 状态 |
|---|---|---|---|
| A | 官网 | 当前认可的首页与服务介绍 | 要 |
| B | 账号 | 注册、登录、找回密码、个人资料及已有双重验证 | 要 |
| C | 模型目录 | 厂家与代号、搜索筛选、四项美元价格 | 要 |
| D | 密钥 | 创建、编辑、停用、删除、范围、额度、有效期与用量 | 要 |
| E | 用量 | 总览、分布、趋势与明细；日期预选和自定义日期范围 | 要 |
| F | 余额与订单 | 余额充值、订单和到账查询 | 要 |
| F-套餐 | 套餐 | 套餐购买 | 以后做 |
| G | 组织 | 创建或加入、邀请、成员状态、消费配额与组织用量 | 要 |
| H | 帮助 | 接入文档、常见问题、公告和已有客服入口 | 要 |
| I | 提醒 | 余额、配额与服务主动通知 | 以后做 |
| J | 试用 | 在线模型试用 | 以后做 |
| K | 企业采购 | 发票、合同和企业身份扩展 | 以后做 |
| L | 状态 | 近七天可用率、当前速度、近期可用性记录 | 要 |
| C-详情 | 独立模型详情 | 卡片承载已确定信息，不建详情页 | 不要 |
| E-时分 | 时分查询 | 只选日期，不做滚动近 24 小时或时分范围 | 不要 |
| L-速度历史 | 速度历史 | 历史仅展示可用性，不扩展后端 | 不要 |

M0 提供以上页面共享的工程、主题和基础控件；产品功能从 M1 开始接入。
