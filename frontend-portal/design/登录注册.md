# 登录 `/login`、注册 `/register`、文档 `/docs`、404 —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。
> 登录注册文案放进 `src/messages/{zh,en}/auth.json`，文档与 404 放进 `src/messages/{zh,en}/misc.json`（已有的 `meta` 键原样保留）。中文照本文件，英文给了的照抄、没给的按专业克制的语气对译。

照 Aceternity 模板的 `/login`、`/signup`：没有顶栏页脚，左半屏表单、右半屏浅灰展示区。和模板不同的三处：注册表单顶部多一个「个人注册 / 创建组织」分段切换（登录不区分账号类型，个人与组织成员都用邮箱和密码登录）；GitHub 按钮换成谷歌按钮（占位）；右半屏的头像换成模型厂商标志。

后端一律不接：提交时只做前端校验，校验通过后按钮进入加载态 1.2 秒再恢复，不跳转、不弹提示、不写任何「暂未开放」之类的文字。谷歌按钮点击不做任何事。

页面布局由页面文件负责（地基已写）：`<div className="grid min-h-dvh lg:grid-cols-2">{左表单区块}<AuthShowcase /></div>`。

本页节奏：左白底表单，右浅灰 surface 底加虚线框。
本页核心动作：填表、提交（注册时先选个人注册或创建组织）。
最重要的区块：**A1 登录表单**。

注册类型存网址：`useUrlState('account', ['personal', 'organization'] as const, 'personal')`，只有注册页用；登录页与注册页互相跳转不带参数。

邀请码由站点配置 `REGISTRATION.invitationCodeRequired`（`src/lib/site.ts`）控制：开启时注册页显示邀请码且必填，关闭时不显示。现在写死为开启，接后端后改读公开设置里的「邀请码注册」开关（`invitation_code_enabled`）。

## A1 登录表单 `src/blocks/auth/login-panel.tsx`（`'use client'`）

**外层**：`<section id="login" className="flex min-h-dvh flex-col px-6 py-8 sm:px-12 lg:px-16 xl:px-24">`，内层 `<div className="mx-auto flex w-full max-w-md flex-1 flex-col">`。

**元素**：

1. 顶部一行 `flex items-center justify-between`：`<Brand />` + `<div className="flex items-center gap-1"><LanguageSwitcher /><ThemeToggle /></div>`。
2. 表单主体 `<div className="flex flex-1 flex-col justify-center py-12">`：
   1. 标题 `<h1 className="text-2xl font-semibold tracking-tight text-foreground">{t('login.title')}</h1>`
   2. 表单 `<form noValidate onSubmit className="mt-8 space-y-5" data-login-form>`（不区分账号类型）：
      - 邮箱：`<Field label={t('fields.email')} htmlFor="email" error={errors.email}><Input id="email" type="email" data-login-email autoComplete="email" placeholder="name@company.com" … /></Field>`
      - 密码：`<Field label={t('fields.password')} htmlFor="password" error={errors.password} trailing={<a href="#" className="text-sm text-muted-foreground hover:text-foreground">{t('login.forgot')}</a>}>`，输入框外包 `relative`：`<Input id="password" type={show ? 'text' : 'password'} data-login-password autoComplete="current-password" className="pr-10" … />` + 右侧按钮 `<button type="button" data-password-toggle aria-label={show ? t('fields.hidePassword') : t('fields.showPassword')} className="absolute inset-y-0 right-0 flex w-10 items-center justify-center text-subtle-foreground hover:text-foreground">`（图标 `Eye` / `EyeOff` `size-4`）。
      - 提交 `<Button type="submit" block loading={submitting} data-login-submit>{t('login.submit')}</Button>`
   3. 注册链接 `mt-4 text-center text-sm text-muted-foreground`：「{t('login.noAccount')}」+ `<Link href="/register" data-to-register className="font-medium text-foreground hover:underline">{t('login.toRegister')}</Link>`
   4. 分隔线 `my-8 flex items-center gap-4 text-xs text-subtle-foreground`：`<span className="h-px flex-1 bg-border" />{t('divider')}<span className="h-px flex-1 bg-border" />`
   5. 谷歌按钮 `<Button type="button" variant="secondary" block data-google-login>`：`<img src="/brands/google.svg" alt="" aria-hidden width={16} height={16} />` + `{t('login.google')}`
   6. 条款 `mt-8 text-center text-xs leading-5 text-subtle-foreground`：用 `t.rich('login.terms', { terms: (c) => <a href="#" className="underline underline-offset-4 hover:text-foreground">{c}</a>, privacy: … })`。

**交互**（状态：`values: { email: string; password: string }`、`errors: Partial<Record<'email' | 'password', string>>`、`show: boolean`、`submitting: boolean`）：
- 所有输入框受控。
- 提交时校验，规则按顺序：
  - 邮箱为空 → `fields.errors.emailRequired`；不符合 `/^[^\s@]+@[^\s@]+\.[^\s@]+$/` → `fields.errors.emailInvalid`
  - 密码为空 → `fields.errors.passwordRequired`；少于 8 位 → `fields.errors.passwordShort`
  每个字段只报它的第一条错误，所有出错字段同时标红；焦点放到第一个出错的输入框，对应输入框 `aria-invalid="true"`、`aria-describedby` 指向错误文字；没有错误时 `submitting` 置真，1200ms 后恢复（定时器卸载时清掉）。
- 输入时清掉该字段的错误。

**状态**：默认、输入中、出错（红框 + 红字）、提交中（按钮转圈、禁用）。邮箱超长时输入框内部滚动，不撑宽。

**响应式**：`lg` 以下右侧展示区隐藏，表单占满屏宽，左右内边距 24px。

**文案**（`auth`，中文 / 英文）：
- `login.title` 登录账号 / Log in to your account；`login.forgot` 忘记密码？/ Forgot password?；`login.submit` 登录 / Log in；`login.noAccount` 还没有账号？/ Don't have an account?；`login.toRegister` 注册 / Sign up；`login.google` 使用 Google 账号登录 / Continue with Google；`login.terms` 登录即表示你同意<terms>服务条款</terms>和<privacy>隐私政策</privacy> / By logging in you agree to our <terms>Terms of Service</terms> and <privacy>Privacy Policy</privacy>
- `divider` 或使用以下方式 / Or continue with
- `fields.email` 邮箱 / Email；`fields.password` 密码 / Password；`fields.showPassword` 显示密码 / Show password；`fields.hidePassword` 隐藏密码 / Hide password
- `fields.errors.emailRequired` 请输入邮箱 / Enter your email；`emailInvalid` 邮箱格式不正确 / Enter a valid email address；`passwordRequired` 请输入密码 / Enter your password；`passwordShort` 密码至少 8 位 / Use at least 8 characters

## A2 注册表单 `src/blocks/auth/register-panel.tsx`（`'use client'`）

**外层、顶部一行、主体结构**同 A1，`<section id="register" …>`。

**元素**（和 A1 的差异）：
1. 标题 `t('register.title')`。
2. 注册类型切换 `<SegmentedControl name="account" className="mt-6 [&>button]:flex-1 [&>button]:justify-center" value={account} onChange={切换并清空错误} ariaLabel={t('account.label')} options={[{ value: 'personal', label: t('account.registerPersonal') }, { value: 'organization', label: t('account.registerOrganization') }]} />`（两项平分宽度）。
3. 表单 `data-register-form`，字段顺序：
   - 仅组织：组织名称 `data-register-org-name`（`fields.orgName`，placeholder `fields.orgNamePlaceholder`，`autoComplete="organization"`）
   - 邮箱 `data-register-email`（个人 `fields.email`，组织 `fields.adminEmail`）
   - 密码 `data-register-password`（`autoComplete="new-password"`，带显示切换，`hint` 为 `fields.passwordHint`）
   - 仅在 `REGISTRATION.invitationCodeRequired` 为真时：邀请码 `data-register-invite`（`fields.invite`，必填，没有「选填」字样和提示文字；`aria-invalid`、`aria-describedby` 同其他字段）
   - 提交按钮 `data-register-submit`：个人 `t('register.submitPersonal')`（注册），组织 `t('register.submitOrganization')`（创建组织）
4. 登录链接：「{t('register.hasAccount')}」+ `<Link href="/login" data-to-login>`{t('register.toLogin')}`</Link>`。
5. 分隔线、谷歌按钮（`t('register.google')`，`data-google-register`）、条款（`t.rich('register.terms', …)`）同 A1。

**交互**：同 A1；切换注册类型时清空错误（输入值保留），组织名称框随之出现 / 消失。校验顺序：组织身份下组织名称为空 → `fields.errors.orgNameRequired`；邮箱、密码规则同 A1；显示邀请码时为空 → `fields.errors.inviteRequired`。焦点顺序：组织名称 → 邮箱 → 密码 → 邀请码。

**文案**（`auth`）：`register.title` 创建账号 / Create your account；`account.registerPersonal` 个人注册 / Personal；`account.registerOrganization` 创建组织 / New organization；`fields.orgName` 组织名称 / Organization name；`fields.orgNamePlaceholder` 例如 Acme AI / e.g. Acme AI；`fields.adminEmail` 管理员邮箱 / Admin email；`fields.passwordHint` 至少 8 位 / At least 8 characters；`account.label` 账号类型 / Account type；`fields.invite` 邀请码 / Invite code；`fields.errors.orgNameRequired` 请输入组织名称 / Enter an organization name；`fields.errors.inviteRequired` 请输入邀请码 / Enter your invite code；`register.submitPersonal` 注册 / Sign up；`register.submitOrganization` 创建组织 / Create organization；`register.hasAccount` 已有账号？/ Already have an account?；`register.toLogin` 登录 / Log in；`register.google` 使用 Google 账号注册 / Sign up with Google；`register.terms` 注册即表示你同意<terms>服务条款</terms>和<privacy>隐私政策</privacy> / By signing up you agree to our <terms>Terms of Service</terms> and <privacy>Privacy Policy</privacy>

## 本页交互检查会找的东西

| 位置 | 操作 | 断言 |
|---|---|---|
| 登录 | 打开 `/login` | 没有 `[data-site-header]`；有 `[data-login-email]`、`[data-login-password]`、`[data-google-login]`；没有 `[data-segmented="account"]`、`[data-login-org]`；`[data-to-register]` href 以 `/register` 结尾 |
| 校验 | 直接点 `[data-login-submit]` | 出现 2 个 `[role="alert"]`，第一个文字「请输入邮箱」 |
| 邮箱格式 | 填邮箱 `abc`、密码 `12345678` 后提交 | 只有 1 个 `[role="alert"]`，文字「邮箱格式不正确」 |
| 通过 | 邮箱改成 `a@b.co` 后提交 | 没有 `[role="alert"]`；`[data-login-submit]` 带 `aria-busy="true"` |
| 密码显示 | 点 `[data-password-toggle]` | `[data-login-password]` 的 `type` 变成 `text` |
| 注册校验 | 打开 `/register` 直接点 `[data-register-submit]` | 有 `[data-register-invite]`；`[role="alert"]` 依次为「请输入邮箱」「请输入密码」「请输入邀请码」 |
| 注册通过 | 填邮箱 `a@b.co`、密码 `12345678`、邀请码 `INV-2026` 后提交 | 没有 `[role="alert"]`；`[data-register-submit]` 带 `aria-busy="true"`；`[data-to-login]` href 以 `/login` 结尾 |
| 创建组织 | 打开 `/register?account=organization` | 有 `[data-register-org-name]`、`[data-register-invite]`；`[data-register-submit]` 文字「创建组织」 |
| 文档 | 打开 `/docs` | `h1` 为「文档」；有 `[data-site-header]` |
| 404 | 打开 `/no-such-page` | 文字包含 `404` 与「页面不存在」；`[data-not-found-home]` 存在 |
