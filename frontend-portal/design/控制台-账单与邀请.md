## B 账单 `src/blocks/console/billing/billing-page.tsx`（导出 `BillingPage`，可拆 `billing-*.tsx`）

**外层**：`<ConsolePage id="billing" title={t('meta.title')}>`。

**页内状态**：`ledger: LedgerEntry[]`（初始 `LEDGER`；兑换、充值成功后在本地加一笔正数流水并用 `buildLedger` 重算余额）、`alert`（初始 `BALANCE_ALERT` 的副本）与它的草稿、交易筛选 `txnFilter: TxnFilter`（默认 `{ range: DEFAULT_RANGE, type: 'all', minUsd: null, maxUsd: null, query: '' }`）、充值弹窗状态。

**数据**：`summary = billingSummary(ledger, presetRange('last30d'))`；`low = isLowBalance(summary.balanceUsd, alert.thresholdUsd)`；`rows = filterTransactions(ledger, txnFilter)`。

### B1 余额 `<Panel id="balance">`

1. `low` 时最上面一条提醒 `role="status"`、`data-low-balance`：`rounded-xl border border-warning/30 bg-warning-soft px-4 py-3 text-sm text-warning`，`TriangleAlert` 图标 +「余额低于提醒阈值 {threshold}，请及时充值，以免影响调用。」。
2. 一行 `flex flex-col gap-4 sm:flex-row sm:items-end sm:justify-between`：左边「可用余额」小标签、余额 `text-4xl font-semibold tracking-tight tabular-nums`（`data-balance`；`low` 时 `text-warning`）、下面一行 `text-sm text-muted-foreground`「按近 30 天日均 {avg} 计算，约可用 {days} 天」（没有消费时整行不显示）；右边「充值」`<Button size="lg" data-recharge>`（`Plus` 图标）。
3. `mt-6 grid gap-4 border-t border-border pt-5 sm:grid-cols-3`，三格（小标签 + `text-lg font-medium tabular-nums`），标签前缀「近 30 天」：充值 `summary.rechargedUsd`；赠送与兑换 `summary.bonusUsd`（`text-success`，前面加「+」）；消费 `summary.consumedUsd`（前面加「-」）。

### B2 兑换码与余额提醒

`grid gap-6 lg:grid-cols-2`：

- `<Panel id="redeem" title="兑换码">`：`flex gap-2`：`<Input id="redeem-code" data-redeem-input placeholder="例如 CODU-XXXX-XXXX" className="font-mono uppercase" aria-label="兑换码" />` + 「兑换」`<Button data-redeem-submit>`。校验：空 →「请输入兑换码」；不符合 `/^[A-Z0-9]{2,}(-[A-Z0-9]{2,}){1,4}$/`（先转大写去空格）→「兑换码格式不正确」。通过后加载 1 秒，成功：本地加一笔 `{ type: 'redeem', amountUsd: 10, note: 兑换码 {code} }` 的流水（`id` 用 `txn_` + 随机串，`ts` 用 `CONSOLE_NOW`），清空输入框，输入框下方显示 `text-sm text-success`「已到账 US$10.00」（`data-redeem-result`，3 秒后消失）。错误用 `Field` 的错误样式（`role="alert"`）。
- `<Panel id="balance-alert" title="余额提醒">`：
  - 提醒阈值：`Field label="提醒阈值" htmlFor="alert-threshold"`，`$` 前缀的数字输入（0–100000）；
  - 邮件提醒：一行左边「邮件提醒」+ 当前邮箱（`CURRENT_USER.email`，`text-subtle-foreground`），右边 `<Switch name="alert-email" />`；
  - Webhook：一行左边「Webhook」，右边 `<Switch name="alert-webhook" />`；开启时下面出现地址输入 `id="alert-webhook-url"`（必须以 `https://` 开头，错误「请输入 https 开头的地址」）；
  - 底部右侧「保存」`<Button data-alert-save>`：没有改动时禁用，保存加载 800ms，成功后按钮旁边短暂显示 `Check` +「已保存」2 秒。保存后阈值立刻影响 B1 的提醒条。

### B3 交易记录

`<Panel id="transactions" title="交易记录" actions={<DateRangePicker value={txnFilter.range} … />} bodyClassName="p-0">`：

1. 筛选行 `grid gap-3 border-b border-border px-5 pb-5 sm:grid-cols-2 lg:grid-cols-4`：类型 `<Select name="txn-type">` 全部 / 充值 / 赠送 / 兑换 / 消费 / 退还；金额范围（两个数字输入 `最小` `最大`，中间「–」，按金额绝对值筛，`id="txn-min"`、`txn-max`）；流水 ID `<SearchInput id="txn-search" placeholder="txn_…" />`。
2. 表格（不再套 `TableShell` 的外框：直接 `div.relative.overflow-x-auto` + `<Table minWidth={760}>`），每行 `data-txn-row={id}`：时间（`formatDateTimeShort`）；金额（`formatSignedUsd`，正数 `text-success`，负数 `text-foreground`，右对齐）；类型（Badge：充值 `info`、赠送 `success`、兑换 `success`、消费 `neutral`、退还 `warning`）+ 方式（支付宝 / 微信支付 / 银行卡，没有时不写）；说明（`note[locale]`，`truncate max-w-80`）；余额（`formatUsd(balanceUsd)`，右对齐）。
3. 底部 `border-t border-border px-5 py-3` 放 `<Pagination />`（`usePagination(rows, 筛选条件字符串)`，外层 `data-table="transactions"` 加在表格外层 div 上，供检查找总数）。
4. 没有结果：`<EmptyState id="transactions" icon={Receipt} title="没有符合条件的流水" bordered={false} />`。

### B4 充值弹窗 `<Dialog id="recharge" title="充值" footer={取消 + 去支付}>`

- 金额：`grid grid-cols-2 gap-2 sm:grid-cols-4` 的四个档位按钮（`RECHARGE_PRESETS`，`data-recharge-amount={n}`，选中 `border-foreground bg-muted`）+ 下面「自定义金额」数字输入 `id="recharge-custom"`（`RECHARGE_LIMITS` 范围，错误「请输入 {min} 到 {max} 之间的金额」）。
- 赠送：金额满足档位时一行 `text-sm text-success`「赠送 {bonus}」（`rechargeBonus`）；下面一行 `text-xs text-subtle-foreground`「满 US$200 赠送 5%，满 US$500 赠送 10%」（由 `RECHARGE_BONUS_TIERS` 拼出，不写死）。
- 支付方式：三张单选卡 `grid gap-2 sm:grid-cols-3`（`role="radiogroup"`，每张 `role="radio"`、`data-pay-method={m}`）：支付宝 / 微信支付 / 银行卡；默认支付宝。
- 合计：「到账 {amount + bonus}」`text-base font-semibold`。
- 「去支付」`data-recharge-submit`：加载 1.2 秒，成功后关闭弹窗，本地加一笔充值流水（`method` 为所选方式）和一笔赠送流水（有赠送时）。

**文案**（`consoleBilling`）：按上面中文逐条建键（`balance.*`、`stats.*`、`redeem.*`、`alert.*`、`txn.*`、`types.*`、`methods.*`、`recharge.*`、`errors.*`、`empty`），英文对译。

## I 邀请返利 `src/blocks/console/invite/invite-page.tsx`（导出 `InvitePage`，可拆 `invite-*.tsx`）

**外层**：`<ConsolePage id="invite" title={t('meta.title')}>`。

**数据**：`INVITE_PROGRAM`、`INVITEES`、`stats = inviteStats(INVITEES)`。

### I1 邀请链接 `<Panel id="invite-link">`

1. 小标签「你的邀请链接」；一行 `flex gap-2`：只读输入框（`font-mono text-xs`，值 `INVITE_PROGRAM.link`，`data-invite-link`）+ `CopyButton name="invite-link"`（带边框，`size-10`）+ 「分享」下拉按钮（secondary，`Share2` 图标，`data-invite-share`）：菜单项「复制邀请链接」「复制邀请码 {code}」「生成分享文案」（复制一段文案：「我在用 {SITE.name} 调用 Claude、GPT、Gemini 等模型，用我的链接注册首充额外送 5%：{link}」），复制成功后菜单项文字变「已复制」。
2. 规则 `mt-4 space-y-1.5 text-sm text-muted-foreground`，三行，粗体前缀 `font-medium text-foreground`：
   - 「邀请人：」被邀请人注册后 {window} 天内每次充值，你获得充值额 {rate} 的返利。
   - 「被邀请人：」首次充值额外获得 {bonus} 赠送。
   - 「到账：」返利先冻结 {freeze} 天，到期后自动转入余额。
   （百分比与天数都从 `INVITE_PROGRAM` 取，`formatPercent(rate, 0)`。）
3. 数字格 `mt-6 grid gap-4 border-t border-border pt-5 sm:grid-cols-2 lg:grid-cols-4`（四个 `StatCard size="sm"` 或同样式的格）：`rebate-total` 累计返利；`rebate-released` 已到账；`rebate-frozen` 冻结中；`invited` 邀请人数（值 `stats.invited`，sub「其中 {n} 人已充值」）。

### I2 邀请记录 `<Panel id="invitees" title="邀请记录" bodyClassName="p-0">`

表格 `<Table minWidth={680}>`，每行 `data-invitee-row={id}`：用户（已打码邮箱，`font-mono text-xs`）；注册时间；窗口内充值（`formatUsd`）；返利（`formatUsd`）；状态（未充值 `neutral` / 冻结中 `warning` / 已到账 `success`）。没有记录时 `<EmptyState id="invitees" icon={Gift} title="还没有邀请" bordered={false} />`。

**文案**（`consoleInvite`）：按上面中文逐条建键，英文对译（「邀请人：」→ "You:"，「被邀请人：」→ "Your friend:"，「到账：」→ "Payout:"）。

## 本页交互检查会找的东西

| 页面 | 操作 | 断言 |
|---|---|---|
| 账单 | 打开 `/console/billing` | `[data-balance]` 为 `US$129.68`；没有 `[data-low-balance]`；`[data-table="transactions"] [data-total]` 含 `31` |
| 账单 | 类型选「充值」（`[data-select="txn-type"]` → `[data-option="recharge"]`） | 总数含 `1` |
| 账单 | 直接点 `[data-redeem-submit]` | 出现 `[role="alert"]`「请输入兑换码」 |
| 账单 | 兑换码填 `CODU-TEST-2026` 后点兑换，等 1.5 秒 | `[data-balance]` 为 `US$139.68`；出现 `[data-redeem-result]` |
| 账单 | 阈值改成 `200` 后点 `[data-alert-save]`，等 1.2 秒 | 出现 `[data-low-balance]` |
| 账单 | 点 `[data-recharge]` | 出现 `[data-dialog="recharge"]`，有 4 个 `[data-recharge-amount]` |
| 邀请 | 打开 `/console/invite` | `[data-invitee-row]` 有 4 行；`[data-stat="rebate-total"]` 含 `US$20.00` |
