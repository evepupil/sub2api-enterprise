# 首页 `/` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。
> 中文文案写在本文件里，原样放进 `src/messages/zh/<命名空间>.json`；英文给了的照抄，没给的按同义、专业、克制的语气对译放进 `src/messages/en/<命名空间>.json`，两份键完全一致。

## H1 首屏 `src/blocks/home/hero.tsx`（服务端组件，载入动画用纯 CSS）

**外层**：`<section id="hero" className="relative overflow-hidden pt-20 pb-16 md:pt-32 md:pb-20">`，第一个子元素 `<GridBeams />`，然后 `<Container className="relative flex flex-col items-center text-center">`。

**元素**（从上到下，四组依次淡入）：

1. 公告胶囊：`<Link href="/catalog?type=image" data-hero-badge className="group inline-flex max-w-full items-center gap-2 rounded-full border border-border bg-card px-4 py-1.5 text-sm font-medium text-foreground shadow-pill transition-colors hover:bg-muted">`，里面 `<span className="truncate">{t('badge')}</span>` + `<ChevronRight className="size-4 shrink-0 text-muted-foreground transition-transform group-hover:translate-x-0.5" />`。
2. 标题：`<h1 className="mt-8 max-w-6xl text-balance text-[40px] font-semibold leading-[1.1] tracking-tight text-foreground sm:text-6xl md:text-7xl lg:text-8xl lg:leading-none">{t('titleLine1')}<br className="hidden sm:block" /> {t('titleLine2')}</h1>`（`<br>` 后面那个空格保留，手机上两行连成一句时中间有空格）。
3. 副标题：`<p className="mx-auto mt-6 max-w-3xl text-balance text-lg text-muted-foreground md:text-xl">{count === null ? t.rich('subtitleNoCount', { br }) : t.rich('subtitle', { count, br })}</p>`（桌面在「按量计费，」后换行，避免中文词中间断行）。`count` 由页面传入：后台的模型数（`siteModelCount`），读不到时换成不带数字的一句。
4. 按钮行：`<div className="mt-10 flex flex-col items-center gap-4 sm:flex-row sm:gap-6">`
   - 主按钮 `<Link href="/register" data-hero-primary className={buttonClass({ size: 'lg' })}>{t('primaryCta')}</Link>`
   - 次按钮 `<Link href="/pricing" data-hero-secondary className={buttonClass({ variant: 'link', className: 'text-base' })}>{t('secondaryCta')}<ArrowRight /></Link>`

**数据**：模型数来自后台（2026-10-05 起，页面 `getSiteCatalog()` 读好，每次打开都用 60 秒缓存里的数据现做）。

**交互**：载入动画——四组各包一层 `<div className="animate-fade-up" style={{ animationDelay: 序号 × 80ms }}>`（纯 CSS，HTML 一到就播放，不等水合；「减少动态效果」时样式表关掉动画）。只在首屏，没有滚动触发。

**状态**：静态内容，无空态。公告文字过长时单行截断（`truncate`），胶囊不撑破屏幕。

**响应式**：手机标题 40px、两行合成一段自然换行；按钮上下堆叠、居中；`sm` 起按钮并排。
