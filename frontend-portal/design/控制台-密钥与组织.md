## K API 密钥 `src/blocks/console/keys/keys-page.tsx`（导出 `KeysPage`，可拆 `keys-*.tsx`）

**外层**：`<ConsolePage id="keys" title={t('meta.title')} actions={刷新（secondary，data-refresh，转 600ms）+ 创建密钥（primary，Plus 图标，data-create-key）}>`。

**页内状态**：`keys: KeyRow[]`（初始由 `API_KEYS` 映射，带上 `keyUsage(id)`；新建的密钥用量为 0）、`query`、`status: KeyStatus | 'all'`、`revealed: Set<string>`（显示完整密钥的行）、各弹窗的开关与草稿。

### K1 筛选

`flex flex-col gap-3 sm:flex-row sm:items-center`：`<SearchInput id="key-search" data-key-search placeholder="搜索名称或密钥末尾" className="sm:w-72" />` + `<Select name="key-status" className="sm:w-40">`：全部状态 / 启用 / 已暂停 / 已过期。数据用 `searchKeys(keys, query, status)`。

### K2 密钥表

`<TableShell id="keys" footer={<Pagination />}>` → `<Table minWidth={1100}>`，每行 `data-key-row={id}`，列：

| 列 | 内容 |
|---|---|
| 名称 | 名称（`font-medium truncate max-w-48`）+ 下一行「创建于 {日期}」`text-xs text-subtle-foreground` |
| 密钥 | `font-mono text-xs`：默认 `maskKey(secret)`，显示时完整密钥（`break-all`）；后面 `Eye` / `EyeOff` 图标按钮（`data-reveal={id}`，`aria-label` 显示密钥 / 隐藏密钥）和 `CopyButton name="key-secret"`（复制完整密钥） |
| 通道 | `<Badge tone="outline">{通道名} {formatRatio(ratio)}</Badge>` |
| 状态 | 启用 `success`「启用」；已暂停 `warning`「已暂停」；已过期 `neutral`「已过期」；`data-key-status={status}` |
| 用量 | 两行小字：「近 30 天 {次数} 次 · {金额}」「今日 {次数} 次 · {金额}」 |
| 额度 | 不限：`Infinity` 图标 +「不限」；有上限：「{已用} / {上限}」+ 下面一条 `h-1.5 rounded-full bg-muted` 的进度条（已用 = `keyUsage(id).totalCostUsd`，满了 `bg-danger-graphic`，否则 `bg-primary`） |
| 有效期 | 「永久」或日期；已过期的日期 `text-danger` |
| 操作（`sticky="right"`） | 「接入」小按钮（secondary，`Terminal` 图标，`data-key-usage={id}`）打开接入示例弹窗；编辑（`Pencil`，`data-key-edit`）；暂停 / 启用（`Pause` / `Play`，`data-key-toggle`，已过期的禁用）；删除（`Trash2`，`data-key-delete`）。图标按钮都是 `size-8`，有 `aria-label` 与 `title` |

**空状态**：一个密钥都没有：`<EmptyState id="keys" icon={KeyRound} title="还没有 API 密钥" action={创建密钥} />`；筛选没结果：标题「没有符合条件的密钥」，操作「清除筛选」。

### K3 创建密钥弹窗 `<Dialog id="create-key" title="创建 API 密钥">`

字段（`Field`）：

- 名称 `id="key-name"`：必填，最多 32 字；错误「请输入名称」/「名称最多 32 个字」。
- 通道：`<SegmentedControl name="key-group">`，选项只有 `ORGANIZATION.groups`（共享通道 ×0.15 / 专用通道 ×0.3），默认 `CURRENT_USER.defaultGroup`。
- 额度：`<SegmentedControl name="key-quota-mode">` 不限 / 自定义；自定义时下面出现金额输入框 `id="key-quota"`（`type="number"`，前缀 `$`，1–100000），错误「请输入 1 到 100000 之间的金额」。
- 有效期：`<Select name="key-expiry">` 永久 / 30 天 / 90 天 / 1 年（到期日 = `TODAY` 加天数）。

底部：取消 + 创建（`data-create-submit`，提交加载 800ms）。成功后弹窗内容换成结果：「密钥已创建」标题、一行说明「完整密钥只显示这一次，请立即复制保存。」（安全提示，必须有）、完整密钥代码框 + `CopyButton name="new-key"` + 「完成」按钮；关闭后新密钥（状态启用、用量 0）加在列表最前。完整密钥用 `crypto.getRandomValues` 生成：`sk-nx-` + 40 位字母数字。

### K4 编辑弹窗 `<Dialog id="edit-key" title="编辑密钥">`

名称、额度（同创建）、有效期（永久 / 保持原日期 / 30 天 / 90 天 / 1 年），通道只读显示（换通道要新建密钥）。保存后更新该行。

### K5 接入示例弹窗 `<Dialog id="key-usage" size="lg" title="接入 {密钥名}">`

`<SegmentedControl name="key-snippet">`：Claude Code / Codex CLI / curl；下面一个代码框（`pre`，`bg-muted rounded-xl p-4 font-mono text-xs overflow-x-auto`）+ `CopyButton name="key-snippet"`。代码里的地址用 `SITE.apiBase`，密钥用该行完整密钥：

- Claude Code：`export ANTHROPIC_BASE_URL={apiBase}` / `export ANTHROPIC_AUTH_TOKEN={key}` / `claude`
- Codex CLI：`~/.codex/config.toml` 里 `model_provider = "nexus"` 与 `[model_providers.nexus]` 的 `name`、`base_url = "{apiBase}/v1"`、`env_key = "NEXUS_API_KEY"`，再一行 `export NEXUS_API_KEY={key}`
- curl：`curl {apiBase}/v1/chat/completions -H "Authorization: Bearer {key}" -H "Content-Type: application/json" -d '{"model":"gpt-6-sol","messages":[{"role":"user","content":"Hello"}]}'`

### K6 删除确认

`<ConfirmDialog id="delete-key" title="删除密钥「{名称}」？" description="删除后使用这个密钥的请求会立即失败，且无法恢复。" confirmLabel="删除" />`，确认后从列表移除。暂停不需要确认，直接切换状态。

**文案**（`consoleKeys`）：按上面中文逐条建键（`actions.*`、`filters.*`、`table.*`、`status.*`、`create.*`、`edit.*`、`usage.*`、`delete.*`、`errors.*`、`empty.*`），英文对译。

## O 组织 `src/blocks/console/organization/organization-page.tsx`（导出 `OrganizationPage`，可拆 `organization-*.tsx`）

**外层**：`<ConsolePage id="organization" title={t('meta.title')} actions={邀请成员（primary，UserPlus 图标，data-invite-member）}>`。

**页内状态**：`members: OrgMember[]`（初始 `ORG_MEMBERS`）、`invitations: OrgInvitation[]`（初始 `ORG_INVITATIONS`）、`query`、弹窗状态。

### O1 组织信息与概况

1. `<Panel id="org-info">`：一行 `flex flex-wrap items-center gap-x-8 gap-y-3`：组织名（`text-lg font-semibold`，`ORGANIZATION.name[locale]`）；「组织 ID」`font-mono text-sm` + `CopyButton name="org-id"`；「创建于 {日期}」；「你的角色」`<Badge tone="dark">管理员</Badge>`。
2. 数字卡 `grid gap-4 sm:grid-cols-2 xl:grid-cols-4`（`orgSummary(members)`）：`members` 成员（值「{启用}/{全部}」，sub「启用 / 全部」）；`month-used` 本月消费（`formatUsd`）；`quota-total` 成员配额合计（`formatUsd`，sub「每月，不含不限额成员」）；`groups` 可用通道（值「{n} 个」，sub 通道名用顿号连接）。

### O2 成员表

标题行：`<h2 className="text-base font-semibold">成员</h2>` + `<SearchInput id="member-search" data-member-search placeholder="搜索姓名或邮箱" className="sm:w-64" />`。

`<TableShell id="members">` → `<Table minWidth={960}>`，每行 `data-member-row={id}`：

| 列 | 内容 |
|---|---|
| 成员 | 首字头像圆（`size-8 bg-muted`）+ 姓名 / 邮箱两行 |
| 角色 | 管理员 `dark`；成员 `outline` |
| 本月配额 | 不限：「不限」；有上限：「{已用} / {上限}」+ 进度条（`quotaRatio`；≥ 1 时 `bg-danger-graphic` 并在后面加 `<Badge tone="danger">已用完</Badge>`，≥ 0.8 `bg-warning-graphic`，否则 `bg-primary`） |
| 密钥 | 数量 |
| 状态 | 启用 `success` / 已停用 `neutral` |
| 加入时间 | 日期 |
| 操作（`sticky="right"`） | 调整配额（`data-member-quota`，打开弹窗）；停用 / 启用（`data-member-toggle`）；移除（`data-member-remove`，ConfirmDialog）。管理员本人那行只能调整配额，其余按钮禁用 |

调整配额弹窗 `<Dialog id="member-quota" title="调整 {姓名} 的每月配额">`：`<SegmentedControl name="quota-mode">` 不限 / 自定义 + 金额输入（1–100000），保存后更新。移除确认：「移除成员「{姓名}」？」说明「移除后对方的密钥会立即停用。」。

搜索没结果：表格内 `<EmptyState id="members" icon={Users} title="没有符合条件的成员" bordered={false} />`。

### O3 邀请码

标题行 `<h2>邀请码</h2>`。`<TableShell id="invitations">` → `<Table minWidth={720}>`，每行 `data-invitation-row={code}`：邀请码（`font-mono` + `CopyButton name="invite-code"`）、创建时间、有效期至、状态（有效 `success` / 已使用 `neutral` / 已过期 `neutral`）、使用者（邮箱或「—」）、操作（有效的显示「作废」按钮 `data-invitation-revoke`，作废后状态变已过期）。

邀请成员弹窗 `<Dialog id="invite-member" title="邀请成员">`：有效期 `<SegmentedControl name="invite-expiry">` 7 天 / 30 天；「生成邀请码」按钮（`data-invite-generate`）生成 `ORG-XXXX-XXXX`（`crypto.getRandomValues`，大写字母数字），生成后显示邀请码与邀请链接（`{INVITE 注册地址}`：`https://nexus-api.example/register?org={code}`）各带复制按钮，并把它加到邀请码表格最前；「完成」关闭。

## 本页交互检查会找的东西

| 页面 | 操作 | 断言 |
|---|---|---|
| 密钥 | 打开 `/console/keys` | `[data-key-row]` 有 5 行；`[data-table="keys"] [data-total]` 含 `5` |
| 密钥 | 搜索框填 `claude` | 只剩 `[data-key-row="key-claude-code"]` |
| 密钥 | 状态选「已暂停」 | 只剩 `[data-key-row="key-labeling"]` |
| 密钥 | 点 `[data-create-key]`，直接点 `[data-create-submit]` | 出现 `[role="alert"]`「请输入名称」 |
| 密钥 | 名称填「新密钥」后提交，等 1.5 秒，点「完成」 | `[data-key-row]` 变 6 行 |
| 密钥 | 点 `key-prod` 行的 `[data-key-toggle]` | 该行 `[data-key-status]` 为 `paused` |
| 密钥 | 点 `key-test` 行的 `[data-key-delete]`，再点 `[data-confirm]` | 没有 `[data-key-row="key-test"]` |
| 组织 | 打开 `/console/organization` | `[data-member-row]` 有 5 行；`[data-stat="members"] [data-stat-value]` 为 `4/5` |
| 组织 | 点 `[data-invite-member]` → `[data-invite-generate]` | `[data-invitation-row]` 变 4 行 |
