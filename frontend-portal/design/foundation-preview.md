# M0 组件与外壳预览页

依据：[站点规格](../DESIGN.md) · [M0](../docs/roadmap.md#m0)

## 1. 页面结构

顶部为独立的预览工具栏，高64px，白底下边框，左侧“界面预览”与“示例数据”标签；右侧三个原生按钮切换“组件”“官网外壳”“控制台外壳”。视图状态在内存，不写 URL、localStorage 或调用 API；手机换行展示工具栏，不挤出屏幕。

正文最大1408px，桌面留白64px、平板32px、手机16px。背景和表面使用已确认中性色。组件页按2列卡片布局（xl及以上），移动端单列；每张卡片内容留白24px，标题20px，无机械副标题。

## 2. 组件视图

六个区块：

1. 按钮：default“保存”、outline“取消”、ghost“查看更多”、destructive“删除”，再展示loading“保存中”和disabled“不可操作”；非业务动作不弹成功通知。
2. 表单：带标签“密钥名称”的输入，placeholder“例如：工作项目”；“使用分组”选择器含“标准通道”“团队通道”；错误态输入“名称不能为空”；真实选择器可切换，错误例始终注明输入错误。
3. 浮层：“创建密钥”打开带名称字段的 Dialog，标题“创建密钥”，描述“此操作只保存在当前预览”；“保存到预览”保存到本地数组并关闭；空名称显示关联错误；取消和关闭不改数据。
4. 日历：“选择日期”打开 Popover，显示双月范围 Calendar（手机单月）；初始2026-09-20至2026-09-26，不含时分；点选更新本地日期展示，无业务预选计算，不做范围查询。
5. 表格：密钥样例3行，列“名称”“状态”“已用金额”“到期日”；名称包含“工作项目”“个人工具”和一条足够长的中文名称。状态使用可用/已停用的文字标签。金额分别$24.80/$3.16/$0.00；不出现真实凭证。
6. 状态：“加载”“空数据”“错误”三个按钮切换同一数据容器。加载用3行骨架，空态“暂无调用记录”，错误“用量暂时无法加载”+“重试”，重试恢复表格。内容高度稳定，消息对辅助技术可读。

交互标记：data-testid 对应 `preview-view-*`、`create-preview-key`、`key-name`、`save-preview-key`、`preview-feedback`、`date-range-trigger`、`state-loading`、`state-empty`、`state-error`、`retry-preview`；标记服务验收，不作为纯外观单测理由。

## 3. 官网外壳视图

PublicShell 导航64px、品牌左、导航中、操作右。桌面四个入口，手机菜单图标44px触控，使用同一 Dialog 原语侧向展示导航；点击项切换本地 activePath 并关闭菜单。

内部 PageHeader 显示当前导航对应名称，配一张可读的样例表格区块展示布局边界。本阶段不制作 M1 的首页和模型卡片，不加入新产品文案。

## 4. 控制台外壳视图

桌面216px侧栏白底右边框，顶部品牌与accountLabel“个人账户”；内容留白32px。手机取消固定侧栏，顶部44px菜单按钮用Dialog打开导航。测试切换个人/组织管理员/成员的 Select 放在预览工具栏，不能植入产品外壳。

主内容显示 PageHeader“概览”，日期范围按钮与4个示例汇总：请求2000、Token 12.86M、消费$84.5605、平均耗时12.80s；下面使用已有表格与状态区展示宽度与长文本。M0不引入图表库或实现统计业务。

导航点击在预览内部切换当前项与页面标题，内容一直标为样例。任意身份切换后若当前项不可见，回到概览。导航当前项只允许一个；member不显示付款、组织成员管理与组织用量入口。

## 5. 必须检查的状态

- 宽屏与390px手机，长表格在容器内滚动，页面不被撑宽。
- Dialog打开、空表单错误、保存到预览、关闭和焦点归还。
- Select弹层、Popover日历、键盘Esc、手机菜单开合和导航关闭。
- 三类反馈、禁用与加载按钮、长名称、键盘焦点。
- 页面里所有可点击按钮都有清楚行为，预览不发网络请求。
- 官网模型入口固定 `/catalog`，当前导航项有且仅有一个 `aria-current="page"`；手机与桌面一致。

离线产物使用与Next预览同一个 FoundationPreview 源码，脚本、样式内嵌，使用本机字体；CSS由当前Tailwind源编译，不另写一套模拟样式。
