## M 模型 `src/blocks/console/models/models-page.tsx`（导出 `ConsoleModelsPage`，可拆 `models-*.tsx`）

**外层**：`<ConsolePage id="models" title={t('meta.title')}>`。

2026-10-04 起模型页接后端：分组、模型、实付价、官方价来自后端模型广场（经官网接口 `/api/portal/console/models`，见技术设计 18.3），展示名、厂商、协议、上下文、「新」标记来自官网目录（按模型名对，对不上的见 M4）。

**页内状态**：`scope: 'all' | 'favorites'`（默认 all）、筛选 `type: TypeFilter`、`provider: ProviderId | 'all'`、`context: ContextFilter`、`protocol: Protocol | 'all'`、`query: string`、`sort: SortKey`（默认 `'latest'`）、`currency: LiveCurrency`（默认 `'usd'`）、`reloadKey`（重试时加一）。收藏 `useFavoriteModels()`（`src/lib/console/live/models-favorites.ts`，存在浏览器本地存储 `console-model-favorites`）。

**数据**：`useConsoleModels(reloadKey)`（`src/lib/console/live/models-client.ts`）→ `{ channels, rechargeMultiplier }`；`allRows = allModelRows(channels)`（所有分组的模型摊成一张表，每行是一个分组里的一个模型）、`filtered = filterRows(allRows, 筛选条件)`（`src/lib/console/live/models-view.ts`），`scope === 'favorites'` 时再只留收藏的；分页 `usePagination(rows, paginationKey(范围, 筛选条件))`。

**状态**：首次加载显示占位块（`data-models-loading`）；取不到时 `<EmptyState id="models-error" icon={TriangleAlert}>`，标题「模型列表暂时加载不出来」（太频繁时「查询太频繁，请稍后再试」），操作「重试」（`data-models-retry`）；账号没有任何可用分组（或后台没开模型广场）时 `<EmptyState id="models-none" icon={Layers} title="暂无可用模型" />`。

### M1 范围标签

`<SegmentedControl name="model-scope" value={scope} options=[{ all, 全部, count: 表的总行数 }, { favorites, 收藏, count: 收藏了的模型所占的行数 }] />`。

### M2 筛选栏

`<div className="grid gap-3 sm:grid-cols-2 lg:grid-cols-5">`，每项 `FilterField`：

- 类型 `<Select name="model-type">`：全部 / 文本 / 生图（`TYPE_FILTERS`）
- 厂商 `<Select name="model-provider">`：全部 + 表里出现过的厂商（`providersIn(allRows)`，顺序同 `PROVIDERS`，选项文字是厂商名）
- 上下文 `<Select name="model-context">`：全部 / ≥ 200K / ≥ 1M（`CONTEXT_FILTERS`）
- 协议 `<Select name="model-protocol">`：全部 + `PROTOCOLS`（文字 `PROTOCOL_LABELS[p]`）
- 搜索 `<SearchInput id="model-search" data-model-search placeholder="模型名、厂商或分组" />`（匹配调用名、展示名、厂商名、分组名）

### M3 排序

`flex flex-col gap-3 lg:flex-row lg:items-center lg:justify-between`：

- 左：`<SegmentedControl name="model-sort" size="sm">`：默认 / 价格从低到高 / 价格从高到低 / 上下文长度（`SORT_KEYS`；默认是后台模型广场的顺序）。
- 没有币种切换（2026-10-08 用户定，价格只写美元，充值 1 元 = 1 美元）。不再有分组下拉（2026-10-04 用户要求所有分组一张表，分组写在表里）。

### M4 模型表

`<TableShell id="console-models" footer={<Pagination />}>` → `<Table minWidth={1200}>`；每行 `<Tr data-model-row="{分组 ID}:{模型名}">`，同一个模型在几个分组里就有几行，挨着放、倍率低的在前；列：

| 列 | 内容 |
|---|---|
| 模型（`sticky="left"`） | 星标按钮（`Star` 图标，收藏时填充 `fill-current text-warning-graphic`，`aria-pressed`，`aria-label`「收藏」/「取消收藏」，`data-favorite={id}`）+ `ProviderLogo size={18}`（猜不出厂商时是同尺寸的灰点）+ 两行：名称（`font-medium`，新模型后面 `<Badge tone="info">新</Badge>`）、调用名（`font-mono text-xs text-subtle-foreground`，名称就是调用名时不写这行）；`min-w-60` |
| 分组 | 共享组件 `<GroupWithRate name rate />`（`src/components/console/group-rate.tsx`，日志页也用）：分组名（`max-w-40 truncate`，悬停 `title` 看全名）+ 倍率徽标 `data-group-rate={倍率}`，文字 `ratioLabel(倍率)`（×0.15、×1.0），颜色按档：低于 ×0.2 `success`、低于 ×0.5 `info`、低于 ×1 `warning`、正好 ×1 `neutral`、高于 ×1 `danger` |
| 价格（右对齐） | 金额 = 后端单价 × 这一行分组的生效倍率，用 `formatLiveMoney` 写成美元。按 Token：「{输入} / {输出}」，下面小字「每百万 Token」，分组开了长上下文分档计费且模型有分档时再一行「超过 {阈值}：{输入} / {输出}」；按张：「{单价} / 张」（有多档时「{最低价} / 张起」）；按次：「{单价} / 次」（多档「/ 次起」）；后端没给价「—」。下面逐行列时段：「高峰 {HH:MM–HH:MM} ×{倍率}」「{时段} ×{倍率}」「工作日 {时段} ×{倍率}」。`data-model-price={id}` |
| 官方价 | 按 Token 计费且有官方价时：官方价「{输入} / {输出}」（`text-xs text-subtle-foreground`，`data-model-official`，实付比官方便宜时加删除线；2026-10-08 起不写「几折」，倍率看分组列）；按张、按次或没有官方价：「—」 |
| 类型 | `<Badge tone="outline">` 文本 / 生图（目录里没有的按计费方式：按张计费算生图） |
| 厂商 | 厂商名；猜不出时「—」 |
| 协议 | 协议徽标竖排（`flex flex-col items-start gap-1`，`Badge tone="outline"`，`font-mono text-[11px]`）；目录里没有的按后端平台推（openai：OpenAI Chat、OpenAI Responses，生图 OpenAI Images；anthropic：Anthropic Messages；gemini：Gemini API），推不出「—」 |
| 上下文 | `formatContext` 或「—」 |
| 操作（`sticky="right"`，对话开关关着时整列不显示，2026-10-07 起首发关着） | 文本模型：`<Link href={{ pathname: '/console/chat', query: { model: id } }} className={buttonClass({ size: 'sm' })} data-try={id}>试一试</Link>`；生图模型：「—」 |

**空状态**：没有结果时 `<EmptyState id="console-models" icon={Layers} title="没有符合条件的模型" bordered={false} action={清除筛选} />`；收藏页没有收藏时标题换成「还没有收藏的模型」，不给操作。

**文案**（`consoleModels`）：`scope.all` 全部 / All、`scope.favorites` 收藏 / Favorites、`scope.label` 模型范围 / Scope；`filters.type` 类型 / Type、`filters.provider` 厂商 / Provider、`filters.context` 上下文 / Context、`filters.protocol` 协议 / Protocol、`filters.search` 搜索 / Search、`filters.searchPlaceholder` 模型名、厂商或分组 / Model, provider or channel、`filters.all` 全部 / All、`filters.text` 文本 / Text、`filters.image` 生图 / Image、`filters.ctx200k` ≥ 200K、`filters.ctx1m` ≥ 1M、`filters.clear` 清除筛选 / Clear filters；`sort.label` 排序 / Sort、`sort.default` 默认 / Default、`sort.priceAsc` 价格从低到高 / Price: low to high、`sort.priceDesc` 价格从高到低 / Price: high to low、`sort.context` 上下文长度 / Context length；表头 `table.model` 模型 / Model、`table.channel` 分组 / Channel、`table.price` 价格 / Price、`table.official` 官方价 / Official price、`table.type` 类型 / Type、`table.provider` 厂商 / Provider、`table.protocols` 协议 / Protocols、`table.context` 上下文 / Context；`table.perMTokens` 每百万 Token / per 1M tokens、`table.longContext` 超过 {threshold}：{input} / {output} / Over {threshold}: {input} / {output}、`table.perImage` {price} / 张 / {price} / image、`table.perImageFrom` {price} / 张起 / from {price} / image、`table.perRequest` {price} / 次 / {price} / request、`table.perRequestFrom` {price} / 次起 / from {price} / request、`table.peak` 高峰 {window} ×{multiplier} / Peak {window} ×{multiplier}、`table.timeWindow` {window} ×{multiplier}、`table.timeWindowWeekdays` 工作日 {window} ×{multiplier} / Weekdays {window} ×{multiplier}、`table.try` 试一试 / Try it、`table.favorite` 收藏 / Favorite、`table.unfavorite` 取消收藏 / Remove favorite；`empty` 没有符合条件的模型 / No matching models、`emptyFavorites` 还没有收藏的模型 / No favorites yet、`noModels` 暂无可用模型 / No models available、`error.unavailable` 模型列表暂时加载不出来 / Models couldn't be loaded、`error.tooMany` 查询太频繁，请稍后再试 / Too many requests. ## C 对话 `src/blocks/console/chat/chat-page.tsx`（导出 `ChatPage`，可拆 `chat-*.tsx`）

**外层**：`<ConsolePage id="chat" title={t('meta.title')} actions={新对话按钮}>`；新对话 `<Button variant="secondary" data-new-chat>`（`SquarePen` 图标）：清空消息、停止正在输出的回复。

**页内状态**：`model`：用 `useUrlState('model', CHAT_MODEL_IDS, DEFAULT_CHAT_MODEL)`（`@/lib/use-url-state`，模型页「试一试」会带 `?model=`）；`keyId`（默认第一个状态为 active 的密钥）；`messages: ChatMessage[]`（默认 `CHAT_SAMPLE`）；`draft: string`；`streaming: { id: string; full: string; shown: number } | null`；`replyIndex: number`（轮流取 `CHAT_REPLIES`）。

### C1 工具条

`<Panel>` 外不套，直接一行 `flex flex-wrap items-end gap-3`：

- 模型 `FilterField` + `<Select name="chat-model" className="w-64">`，选项 `CHAT_MODEL_IDS`（文字 `getModel(id).name`）
- 密钥 `FilterField` + `<Select name="chat-key" className="w-56">`，选项状态为 active 的密钥名称
- 所选密钥的分组：`<Badge tone="outline">{分组名} {formatRatio(ratio)}</Badge>`，再一段小字「输入 {输入价} · 输出 {输出价} / 百万 Token」（`textPrice(getModel(model), key.group)`，`formatMoney(…, 'usd')`）

### C2 对话区

`<section data-chat className="flex min-h-[60vh] flex-col rounded-2xl border border-border bg-card shadow-card">`：

1. 消息列表 `flex-1 space-y-5 overflow-y-auto p-5`（最大高度 `max-h-[60vh]`，新消息出现时滚到底），`aria-live="polite"`：
   - 用户：右对齐气泡 `max-w-[80%] rounded-2xl rounded-br-md bg-primary px-4 py-2.5 text-sm text-primary-foreground whitespace-pre-wrap break-words`，`data-chat-message="user"`。
   - 助手：左侧 `Bot` 小圆头像 + 内容；上方一行模型调用名 `font-mono text-xs text-subtle-foreground`；正文 `rounded-2xl rounded-bl-md bg-muted px-4 py-2.5 text-sm`；悬停时右下角出现 `CopyButton`（`name="chat-copy"`）；`data-chat-message="assistant"`；正在输出时正文末尾一个闪烁的光标块 `inline-block h-4 w-1.5 animate-pulse bg-foreground/60 align-middle`。
   - 没有消息时：列表位置居中显示 `Sparkles` 图标圈 +「开始一段对话」（只要标题），`data-empty="chat"`。
2. 输入区 `border-t border-border p-4`：`<textarea id="chat-input" data-chat-input rows={3} maxLength={CHAT_INPUT_MAX}>`（样式同 `Input`，但多行、`resize-none`），占位「输入消息，Enter 发送，Shift + Enter 换行」，`aria-label`「消息」；下方一行：左边字数「{n} / {max}」（`text-xs text-subtle-foreground tabular-nums`），右边按钮：输出中显示「停止」`<Button variant="secondary" data-chat-stop>`，否则「发送」`<Button data-chat-send>`（`Send` 图标，草稿为空时禁用）。

**交互**：

- 发送：把草稿（去首尾空白）作为用户消息加到末尾、清空输入框；随后加一条空的助手消息，内容取 `CHAT_REPLIES[replyIndex % 长度][locale]`，用 `setInterval` 每 24ms 多显示 2 个字，显示完结束（卸载、停止、新对话时清掉定时器）。
- Enter 发送、Shift + Enter 换行（输入法组合中 `isComposing` 不发送）。
- 停止：立刻结束，保留已显示的部分。
- 换模型或换密钥不清空对话；之后的回复上方显示新模型名。

**文案**（`consoleChat`）：`newChat` 新对话 / New chat、`model` 模型 / Model、`key` API 密钥 / API key、`pricing` 输入 {input} · 输出 {output} / 百万 Token / Input {input} · Output {output} per 1M tokens、`empty` 开始一段对话 / Start a conversation、`input` 消息 / Message、`placeholder` 输入消息，Enter 发送，Shift + Enter 换行 / Type a message. Enter to send, Shift + Enter for a new line、`count` {count} / {max}、`send` 发送 / Send、`stop` 停止 / Stop、`copy` 复制回复 / Copy reply、`you` 你 / You。
