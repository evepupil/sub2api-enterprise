# 通道 `/channels` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。
> 文案放进 `src/messages/zh/groups.json` 与 `src/messages/en/groups.json`（命名空间沿用 groups），中文照本文件，英文给了的照抄、没给的按专业克制的语气对译。

本页原名「分组与倍率」，2026-10-03 起改叫「通道」：三档服务改名共享通道、专用通道、企业通道（一个通道就是后端的一个分组），页面**只比权益、不展示倍率**。文件名与代码目录（`design/分组.md`、`src/blocks/groups/`、文案命名空间 `groups`、数据里的 edition / personal / pro / enterprise）沿用旧名，页面上一律叫「通道」。

这一页照 Aceternity 模板的 `/pricing` 页做：模板是订阅套餐，我们不是订阅，所以「月付 / 年付」切换去掉，套餐卡换成三种通道，「$12/mo」的价格位换成可用率目标「99.5%」，企业通道按钮是联系销售（模板 Enterprise 卡的「Contact Us」同理），逐行对比表比较三种通道的权益。

本页节奏：页首（白底 + 网格光线，居中标题）→ 通道卡（白底，三张并排，中间专用通道深蓝重点卡）→ 特权对比（白底，逐行对比表）→ 常见问题（白底）→ 厂商标志（白底）→ 页脚。

本页核心动作：看三种通道的权益差别，点「查看定价」去价格页看对应通道的单价。

本页最重要的区块：**G2 通道卡**，要和模板价格页的套餐卡几乎一样（左对齐的名称、超大数字位、灰色说明、圆点对勾列表、底部整宽按钮、深蓝渐变重点卡配白色按钮）。允许写得最长。

页内状态：无。本页不做通道切换，三种通道直接并排。

## G2 通道卡 `src/blocks/groups/group-cards.tsx` + `group-cards-card.tsx`（服务端组件）

**外层**：`<section id="group-cards" className="pb-20 md:pb-28">` → `<Container>` → `<div className="mx-auto grid max-w-md gap-6 lg:max-w-6xl lg:grid-cols-3 lg:gap-4">`（默认拉伸等高，按钮靠底对齐）。

**数据**：`EDITIONS` 三张，顺序固定：共享通道、专用通道（重点卡）、企业通道。每张卡另传上一档通道 `previous={EDITIONS[index - 1]}`（共享通道没有）。

**每张卡** `<article data-group-card={edition.id} data-featured={edition.featured ? 'true' : 'false'} className={…}>`，类名对象映射：
- 普通卡：`relative flex h-full flex-col rounded-2xl p-6 md:p-8`（模板的普通卡没有边框和底色，就是白底上的文字）
- 重点卡：`relative flex h-full flex-col overflow-hidden rounded-2xl bg-gradient-to-b from-navy to-navy-2 p-6 text-navy-foreground shadow-featured md:p-8`，第一个子元素颗粒层 `<div aria-hidden className="pointer-events-none absolute inset-0 bg-noise opacity-[0.12] mix-blend-overlay" />`，其余内容都加 `relative`。

卡片内容从上到下：
1. 名称行 `flex items-center justify-between gap-2`：名称 `text-base font-semibold`（普通 `text-foreground`，重点 `text-white`），重点卡右侧 `<Badge tone="inverse">{t('cards.popular')}</Badge>`。
2. 可用率目标 `mt-6 flex items-baseline gap-2`：`<span data-group-sla={edition.id} className="text-4xl font-semibold tracking-tight tabular-nums md:text-5xl">{slaTarget.toFixed(1)}%</span>`（普通 `text-foreground`，重点 `text-white`），后面跟 `text-sm`「{t('cards.slaLabel')}」（可用率目标），普通 `text-muted-foreground`、重点 `text-navy-muted`。**不显示倍率。**
3. 说明 `mt-4 min-h-10 text-sm`（普通 `text-muted-foreground`，重点 `text-navy-muted`）：`localize(edition.summary, locale)`。
4. 特权列表 `<CheckList className="mt-8" tone={edition.featured ? 'inverse' : 'default'} items={…} />`，条目依次：
   1. 有上一档时：`t('cards.includes', { edition: 上一档名称 })`（包含共享通道全部特权）
   2. 倍率不为 null：`t('cards.rpm', { value: edition.rpm.toLocaleString('en-US') })`（单密钥每分钟 600 次请求）；为 null（企业通道）：`t('cards.customLimits')`（并发与限额按合同约定）
   3. `t('cards.support', { hours: edition.supportHours })`（工单 12 小时内响应）
   4. 之后接 `GROUP_HIGHLIGHTS[edition.id]` 每条 `localize(item)`（共享通道：全部文本与生图模型、故障自动切换；专用通道：高峰期优先调度、对公转账与发票；企业通道：可用率赔付、专属客户经理、可选私有化部署）
5. 按钮 `mt-auto pt-8`：
   - `cta === 'pricing'`：`<Link href={{ pathname: '/pricing', query: 共享通道 ? {} : { edition: id } }} data-group-cta={edition.id} className={buttonClass({ variant: edition.featured ? 'inverse' : 'primary', block: true })}>{t('cards.use')}</Link>`（查看定价，跳到价格页并选中该通道）
   - `cta === 'contact'`：`<a href="#" data-group-cta={edition.id} className={buttonClass({ variant: 'secondary', block: true })}>{common.actions.contactSales}</a>`（占位链接）

**交互**：无；卡片本身没有悬停位移（模板也没有）。

**状态**：说明两行以内（`min-h-10` 保证三张对齐）。

**响应式**：大屏以下一列并收窄到 `max-w-md` 居中，`lg` 三列；手机上重点卡不加额外外边距。

**文案**（`groups.cards`）：`popular` 最常用 / Most popular；`slaLabel` 可用率目标 / availability target；`includes` 包含{edition}全部特权 / Everything in {edition}, plus；`rpm` 单密钥每分钟 {value} 次请求 / {value} requests per minute per key；`customLimits` 并发与限额按合同约定 / Concurrency and limits by contract；`support` 工单 {hours} 小时内响应 / Support response within {hours} h；`use` 查看定价 / View pricing。

## G3 特权对比 `src/blocks/groups/privilege-table.tsx`（服务端组件，高亮重点通道那一列）

**外层**：`<section id="compare" className="py-20 md:py-28">` → `<Container>`。

**元素**：
1. `<SectionHeading title={t('compare.title')} />`（只要标题）。
2. `<div className="relative mt-12 overflow-x-auto">`（`relative` 不能省：对勾格里读屏用的隐藏文字是绝对定位，容器不定位就裁不住，会把手机页面撑宽）→ `<table data-privilege-table className="w-full min-w-[640px] border-collapse text-sm">`：
   - 表头一行：第一格空 `w-2/5`；三格是三种通道，`<th data-edition-col={id} data-selected={id === 重点通道 ? 'true' : 'false'} className={…}>`：`px-4 pb-4 pt-5 text-center text-base font-semibold text-foreground`，重点通道（`featured` 的专用通道，与通道卡深色卡一致）加 `rounded-t-xl bg-muted`。
   - 表体：`PRIVILEGE_ROWS` 11 行（可用率目标、单密钥每分钟请求数、并发上限、故障自动切换、优先调度、组织成员上限、用量明细导出、对公转账与发票、可用率赔付、专属客户经理、工单响应），**没有倍率行**；每行 `<tr data-privilege-row={row.id} className="border-t border-border">`：标签格 `py-4 pr-4 text-foreground`（`localize(row.label)`）；三个值格 `px-4 py-4 text-center`，重点通道那一列加 `bg-muted`（最后一行再加 `rounded-b-xl`）：
     - `true`：`<Check className="mx-auto size-4 text-foreground" aria-hidden />` + `<span className="sr-only">{t('compare.included')}</span>`
     - `false`：`<Minus className="mx-auto size-4 text-subtle-foreground" aria-hidden />` + `<span className="sr-only">{t('compare.excluded')}</span>`
     - 文字（Localized）：`<span className="tabular-nums text-muted-foreground">{localize(value)}</span>`
3. 表格下方 `mt-8 flex justify-center`：`<Link href="/pricing" className={buttonClass({ variant: 'secondary' })}>{common.actions.viewPricing}<ArrowRight /></Link>`。

**数据**：`PRIVILEGE_ROWS`、`EDITIONS`、`localize`。

**交互**：无。

**状态**：无。

**响应式**：表格最小宽度 640，手机上横向滚动。

**文案**（`groups.compare`）：`title` 通道对比 / Compare channels；`included` 包含 / Included；`excluded` 不包含 / Not included。

## G4 常见问题 `src/blocks/groups/groups-faq.tsx`（服务端组件，内用共享 `FaqList`）

**外层**：`<section id="faq" className="border-t border-border py-20 md:py-28">` → `<Container className="grid gap-10 lg:grid-cols-[1fr_2fr]">`。

**元素**：左栏 `<h2 className="text-3xl font-medium tracking-tight text-foreground md:text-4xl">{t('faq.title')}</h2>`；右栏 `<FaqList items={…} />`，5 条：
1. 三种通道有什么区别？ / 共享通道多人共用资源，适合个人开发与日常调用；专用通道使用优选资源并优先调度，适合团队和生产环境；企业通道为企业单独开设，可用率按合同约定。
2. 一个账号能同时用多个通道吗？ / 能。每个 API 密钥绑定一个通道，同一账号可以为不同用途创建多个密钥。
3. 价格会调整吗？ / 价格调整会提前在价格页公示，已经产生的消费不受影响。
4. 组织成员能自己选通道吗？ / 成员只能在组织可用的通道范围内创建密钥。
5. 企业通道怎么开通？ / 联系销售，按合同约定资源、价格与可用率。

**文案**（`groups.faq`）：`title` 常见问题 / FAQ；`items.q1`…`q5`、`items.a1`…`a5`（英文对译）。
