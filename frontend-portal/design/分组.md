# 分组 `/groups` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。
> 文案放进 `src/messages/zh/groups.json` 与 `src/messages/en/groups.json`（已有的 `meta` 键原样保留），中文照本文件，英文给了的照抄、没给的按专业克制的语气对译。

这一页照 Aceternity 模板的 `/pricing` 页做：模板是订阅套餐，我们不是订阅，所以「月付 / 年付」切换去掉，套餐卡换成三个版本（一个版本就是一个分组），「$12/mo」换成分组倍率「×0.3」，企业版的价格位写「定制」、按钮是联系销售（模板 Enterprise 卡的「Contact Us」同理），逐行对比表比较三个版本。

本页节奏：页首（白底 + 网格光线，居中标题）→ 分组卡（白底，三张并排，中间专业版深蓝重点卡）→ 倍率说明（浅灰 surface 底，左公式右示例表）→ 特权对比（白底，逐行对比表）→ 常见问题（白底）→ 厂商标志（白底）→ 页脚。

本页核心动作：看三个版本的倍率和特权。

本页最重要的区块：**G2 分组卡**，要和模板价格页的套餐卡几乎一样（左对齐的名称、超大价格位、灰色说明、圆点对勾列表、底部整宽按钮、深蓝渐变重点卡配白色按钮）。允许写得最长。

页内状态：无。本页不做版本切换，三个版本直接并排。

## G2 分组卡 `src/blocks/groups/group-cards.tsx` + `group-cards-card.tsx`（服务端组件）

**外层**：`<section id="group-cards" className="pb-20 md:pb-28">` → `<Container>` → `<div className="mx-auto grid max-w-md gap-6 lg:max-w-6xl lg:grid-cols-3 lg:gap-4">`（默认拉伸等高，按钮靠底对齐）。

**数据**：`EDITIONS` 三张，顺序固定：个人版、专业版（重点卡）、企业版。每张卡另传上一档版本 `previous={EDITIONS[index - 1]}`（个人版没有）。

**每张卡** `<article data-group-card={edition.id} data-featured={edition.featured ? 'true' : 'false'} className={…}>`，类名对象映射：
- 普通卡：`relative flex h-full flex-col rounded-2xl p-6 md:p-8`（模板的普通卡没有边框和底色，就是白底上的文字）
- 重点卡：`relative flex h-full flex-col overflow-hidden rounded-2xl bg-gradient-to-b from-navy to-navy-2 p-6 text-navy-foreground shadow-featured md:p-8`，第一个子元素颗粒层 `<div aria-hidden className="pointer-events-none absolute inset-0 bg-noise opacity-[0.12] mix-blend-overlay" />`，其余内容都加 `relative`。

卡片内容从上到下：
1. 名称行 `flex items-center justify-between gap-2`：名称 `text-base font-semibold`（普通 `text-foreground`，重点 `text-white`），重点卡右侧 `<Badge tone="inverse">{t('cards.popular')}</Badge>`。
2. 倍率 `mt-6 flex items-baseline gap-2`：`<span data-group-ratio={edition.id} className="text-4xl font-semibold tracking-tight tabular-nums md:text-5xl">{formatRatio(edition.ratio, locale)}</span>`（普通 `text-foreground`，重点 `text-white`）；倍率不是 null 时后面跟 `text-sm`「{t('cards.ratioSuffix')}」（倍率），普通 `text-muted-foreground`、重点 `text-navy-muted`；企业版倍率是 null，显示「定制」、不跟后缀。
3. 说明 `mt-4 min-h-10 text-sm`（普通 `text-muted-foreground`，重点 `text-navy-muted`）：`localize(edition.summary, locale)`。
4. 特权列表 `<CheckList className="mt-8" tone={edition.featured ? 'inverse' : 'default'} items={…} />`，条目依次：
   1. 有上一档时：`t('cards.includes', { edition: 上一档名称 })`（包含个人版全部特权）
   2. `localize(edition.channel)`（渠道类型）
   3. `t('cards.sla', { value: edition.slaTarget.toFixed(1) })`（可用率目标 99.5%）
   4. 倍率不为 null：`t('cards.rpm', { value: edition.rpm.toLocaleString('en-US') })`（单密钥每分钟 600 次请求）；为 null（企业版）：`t('cards.customLimits')`（并发与限额按合同约定）
   5. `t('cards.support', { hours: edition.supportHours })`（工单 12 小时内响应）
   6. 之后接 `GROUP_HIGHLIGHTS[edition.id]` 每条 `localize(item)`（个人版：全部文本与生图模型、故障自动切换；专业版：高峰期优先调度、对公转账与发票；企业版：可用率赔付、专属客户经理、可选私有化部署）
5. 按钮 `mt-auto pt-8`：
   - `cta === 'register'`：`<Link href="/register" data-group-cta={edition.id} className={buttonClass({ variant: edition.featured ? 'inverse' : 'primary', block: true })}>{t('cards.use')}</Link>`
   - `cta === 'contact'`：`<a href="#" data-group-cta={edition.id} className={buttonClass({ variant: 'secondary', block: true })}>{common.actions.contactSales}</a>`（占位链接）

**交互**：无；卡片本身没有悬停位移（模板也没有）。

**状态**：说明两行以内（`min-h-10` 保证三张对齐）。

**响应式**：大屏以下一列并收窄到 `max-w-md` 居中，`lg` 三列；手机上重点卡不加额外外边距。

**文案**（`groups.cards`）：`popular` 最常用 / Most popular；`ratioSuffix` 倍率 / ratio；`includes` 包含{edition}全部特权 / Everything in {edition}, plus；`sla` 可用率目标 {value}% / {value}% availability target；`rpm` 单密钥每分钟 {value} 次请求 / {value} requests per minute per key；`customLimits` 并发与限额按合同约定 / Concurrency and limits by contract；`support` 工单 {hours} 小时内响应 / Support response within {hours} h；`use` 开始使用 / Get started。

## G3 倍率说明 `src/blocks/groups/ratio-explainer.tsx` + `ratio-explainer-examples.tsx`（服务端组件）

**外层**：`<section id="ratio" className="bg-surface py-20 md:py-28">` → `<Container className="grid grid-cols-1 gap-10 lg:grid-cols-2 lg:items-center">`。

**左栏**：
1. `<SectionHeading align="left" title={t('ratio.title')} subtitle={t('ratio.subtitle')} />`
2. 公式卡 `mt-8 rounded-2xl border border-border bg-card p-6 shadow-card`：一行 `flex flex-wrap items-center gap-x-3 gap-y-2 text-lg font-medium text-foreground md:text-xl`：「实际扣费」`=`「官方价」`×`「分组倍率」，其中 `=` 和 `×` 用 `text-subtle-foreground`；下面 `mt-3 text-sm text-muted-foreground`：「{t('ratio.baseNote')}」。

**右栏**：示例表 `<div data-ratio-examples className="overflow-hidden rounded-2xl border border-border bg-card shadow-card">` → 标题行 `border-b border-border px-5 py-4`：`text-sm font-semibold text-foreground`「{t('ratio.examplesTitle')}」（计算示例）。→ `<div className="overflow-x-auto">` 表格 `w-full min-w-[560px] text-sm`，表头 `bg-surface text-xs text-subtle-foreground`：示例、官方价、三个版本（每格两行：版本名 `text-foreground` + 倍率 `font-mono`，`data-ratio-col={edition.id}`），后四列右对齐。

三个示例模型各一行 `<tr data-ratio-row={model.id} className="border-t border-border">`：`gpt-6-sol`、`claude-sonnet-5-5` 看输入单价，`gemini-3.1-flash-image` 看估算每张价。
- 示例：模型名 + 下一行 `text-xs text-subtle-foreground` 价格项（`t('ratio.input')` 或 `t('ratio.perImage')`）。
- 官方价：`textPriceAt(model, 1).input` 或 `imagePriceAt(model, 1)` 的每张价，`formatMoney(..., 'usd')`（生图前面加「≈ 」），`text-muted-foreground`。
- 三个版本 `data-ratio-result={edition.id}`：用同一组函数按 `edition.ratio` 换算，`font-medium text-foreground`；企业版倍率为 null，显示 `formatRatio(null)`「定制」。

**数据**：`EDITIONS`、`MODELS`、`textPriceAt`、`imagePriceAt`、`formatMoney`、`formatRatio`、`localize`。

**交互**：无。

**响应式**：手机上下堆叠，表格横向滚动。

**文案**（`groups.ratio`）：`title` 倍率怎么算 / How ratios work；`subtitle` 同一个模型在不同分组里的价格，只差一个倍率。/ The same model costs differently across groups only by its ratio.；`billed` 实际扣费 / Billed price；`base` 官方价 / Official price；`ratio` 分组倍率 / Group ratio；`baseNote` 官方价即模型厂商公布的标准价格。/ The official price is the list price published by the model provider.；`examplesTitle` 计算示例 / Examples；`example` 示例 / Example；`official` 官方价 / Official；`input` 输入 · 每百万 Token / Input · per 1M tokens；`perImage` 每张 / Per image。

## G4 特权对比 `src/blocks/groups/privilege-table.tsx`（服务端组件，高亮重点版本那一列）

**元素**：
1. `<SectionHeading title={t('compare.title')} />`（只要标题）。
2. `<div className="relative mt-12 overflow-x-auto">`（`relative` 不能省：对勾格里读屏用的隐藏文字是绝对定位，容器不定位就裁不住，会把手机页面撑宽）→ `<table data-privilege-table className="w-full min-w-[640px] border-collapse text-sm">`：
   - 表头一行：第一格空 `w-2/5`；三格是三个版本，`<th data-edition-col={id} data-selected={id === 重点版本 ? 'true' : 'false'} className={…}>`：`px-4 pb-4 pt-5 text-center text-base font-semibold text-foreground`，重点版本（`featured` 的专业版，与分组卡深色卡一致）加 `rounded-t-xl bg-muted`。
   - 表体：`PRIVILEGE_ROWS` 13 行（分组倍率、可用率目标、渠道类型、单密钥每分钟请求数、并发上限、故障自动切换、优先调度、组织成员上限、用量明细导出、对公转账与发票、可用率赔付、专属客户经理、工单响应），每行 `<tr data-privilege-row={row.id} className="border-t border-border">`：标签格 `py-4 pr-4 text-foreground`（`localize(row.label)`）；三个值格 `px-4 py-4 text-center`，重点版本那一列加 `bg-muted`（最后一行再加 `rounded-b-xl`）：

     - `false`：`<Minus className="mx-auto size-4 text-subtle-foreground" aria-hidden />` + `<span className="sr-only">{t('compare.excluded')}</span>`
     - 文字（Localized）：`<span className="tabular-nums text-muted-foreground">{localize(value)}</span>`
3. 表格下方 `mt-8 flex justify-center`：`<Link href="/pricing" className={buttonClass({ variant: 'secondary' })}>{common.actions.viewPricing}<ArrowRight /></Link>`。

**数据**：`PRIVILEGE_ROWS`、`EDITIONS`、`localize`。

**状态**：无。

**文案**（`groups.compare`）：`title` 版本特权对比 / Compare editions；`included` 包含 / Included；`excluded` 不包含 / Not included。

## G5 常见问题 `src/blocks/groups/groups-faq.tsx`（服务端组件，内用共享 `FaqList`）

**外层**：`<section id="faq" className="border-t border-border py-20 md:py-28">` → `<Container className="grid gap-10 lg:grid-cols-[1fr_2fr]">`。

**元素**：左栏 `<h2 className="text-3xl font-medium tracking-tight text-foreground md:text-4xl">{t('faq.title')}</h2>`；右栏 `<FaqList items={…} />`，5 条：
1. 版本和分组是什么关系？ / 一个版本就是一个分组。API 密钥绑定哪个分组，就使用该版本的渠道、可用率目标和倍率。
2. 一个账号能同时用多个分组吗？ / 能。每个 API 密钥单独绑定分组，同一账号可以为不同用途创建多个密钥。
3. 倍率会调整吗？ / 倍率调整会提前在本页公示，已经产生的消费不受影响。
4. 组织成员能自己选分组吗？ / 成员只能在组织管理员授权的分组范围内创建密钥。
5. 企业版怎么开通？ / 联系销售，按合同约定渠道、倍率与可用率。

**文案**（`groups.faq`）：`title` 常见问题 / FAQ；`items.q1`…`q5`、`items.a1`…`a5`（英文对译）。
