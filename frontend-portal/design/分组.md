# 分组 `/groups` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。
> 文案放进 `src/messages/zh/groups.json` 与 `src/messages/en/groups.json`（已有的 `meta` 键原样保留），中文照本文件，英文给了的照抄、没给的按专业克制的语气对译。

这一页照 Aceternity 模板的 `/pricing` 页做：模板是订阅套餐，我们不是订阅，所以「月付 / 年付」切换换成「个人版 / 专业版 / 企业版」切换，「$12/mo」换成分组倍率「×1.6」，套餐特权换成分组特权，逐行对比表比较三个版本。

本页节奏：页首（白底 + 网格光线，居中标题、版本切换、版本指标）→ 分组卡（白底，四张并排，第三张深蓝重点卡）→ 倍率说明（浅灰 surface 底，左公式右示例表）→ 特权对比（白底，逐行对比表）→ 常见问题（白底）→ 厂商标志（白底）→ 页脚。

本页核心动作：切换版本，看四个分组的倍率和特权。

本页最重要的区块：**G2 分组卡**，要和模板价格页的四张套餐卡几乎一样（左对齐的名称、超大价格位、灰色说明、圆点对勾列表、底部整宽按钮、第三张深蓝渐变重点卡配白色按钮）。允许写得最长。

页内状态：版本 `useEdition()`（网址 `?edition=`），G1 切换，G2、G3、G4 读取。

**外层**：`<PageHero id="groups-hero" title={t('hero.title')} subtitle={t('hero.subtitle')}>`，children：`<EditionSwitcher />`、`<EditionSummary />`。

**文案**（`groups.hero`）：`title` 分组与倍率 / Groups and ratios；`subtitle` 每个 API 密钥绑定一个分组。实际扣费 = 模型基础价 × 分组倍率，不收订阅费。/ Every API key is bound to a group. Billed price = base model price × group ratio, with no subscription fees.

## G2 分组卡 `src/blocks/groups/group-cards.tsx`（`'use client'`；卡片可拆 `group-cards-card.tsx`）

**外层**：`<section id="group-cards" className="pb-20 md:pb-28">` → `<Container>` → `<div className="grid gap-6 md:grid-cols-2 lg:grid-cols-4 lg:gap-4">`（默认拉伸等高，按钮靠底对齐）。

**数据**：`const groups = groupsFor(edition)`，四张，顺序固定：通用、生图、Claude 专线（重点卡）、第四张（个人版和专业版是「高速通道」，企业版是「专属定制」）。`const ed = getEdition(edition)`。

**每张卡** `<article data-group-card={group.id} data-featured={group.featured ? 'true' : 'false'} className={…}>`，类名对象映射：
- 普通卡：`relative flex h-full flex-col rounded-2xl p-6 md:p-8`（模板的普通卡没有边框和底色，就是白底上的文字）
- 重点卡：`relative flex h-full flex-col overflow-hidden rounded-2xl bg-gradient-to-b from-navy to-navy-2 p-6 text-navy-foreground shadow-featured md:p-8`，第一个子元素颗粒层 `<div aria-hidden className="pointer-events-none absolute inset-0 bg-noise opacity-[0.12] mix-blend-overlay" />`，其余内容都加 `relative`。

卡片内容从上到下：
1. 名称行 `flex items-center justify-between gap-2`：名称 `text-base font-semibold`（普通 `text-foreground`，重点 `text-white`），重点卡右侧 `<Badge tone="inverse">{t('cards.popular')}</Badge>`。
2. 倍率 `mt-6 flex items-baseline gap-2`：`<span data-group-ratio={group.id} className="text-4xl font-semibold tracking-tight tabular-nums md:text-5xl">{formatRatio(group.ratio, locale)}</span>`（普通 `text-foreground`，重点 `text-white`）；倍率不是 null 时后面跟 `text-sm`「{t('cards.ratioSuffix')}」（倍率），普通 `text-muted-foreground`、重点 `text-navy-muted`。
3. 说明 `mt-4 min-h-10 text-sm`（普通 `text-muted-foreground`，重点 `text-navy-muted`）：`localize(group.description, locale)`。
4. 特权列表 `<CheckList className="mt-8" tone={group.featured ? 'inverse' : 'default'} items={…} />`，条目依次：
   1. `localize(group.scope)`（可用模型范围）
   2. `localize(ed.channel)`（渠道类型）
   3. `t('cards.sla', { value: ed.slaTarget.toFixed(1) })`（可用率目标 99.5%）
   4. 倍率不为 null：`t('cards.rpm', { value: ed.rpm.toLocaleString('en-US') })`（单密钥每分钟 600 次请求）；为 null（专属定制）：`t('cards.customLimits')`（限额按合同约定）
   5. `t('cards.support', { hours: ed.supportHours })`（工单 12 小时内响应）
   6. 之后接 `group.extras` 每条 `localize(extra)`
5. 按钮 `mt-auto pt-8`：
   - `cta === 'register'`：`<Link href="/register" data-group-cta={group.id} className={buttonClass({ variant: group.featured ? 'inverse' : 'primary', block: true })}>{t('cards.use')}</Link>`
   - `cta === 'contact'`：`<a href="#" data-group-cta={group.id} className={buttonClass({ variant: 'secondary', block: true })}>{common.actions.contactSales}</a>`

**交互**：切版本时四张卡的倍率、指标、第四张卡的种类一起变；卡片本身没有悬停位移（模板也没有）。

**状态**：倍率为 null 显示「定制」；说明两行以内（`min-h-10` 保证四张对齐）。

**响应式**：手机一列，`md` 两列，`lg` 四列；手机上重点卡不加额外外边距。

**文案**（`groups.cards`）：`popular` 最常用 / Most popular；`ratioSuffix` 倍率 / ratio；`sla` 可用率目标 {value}% / {value}% availability target；`rpm` 单密钥每分钟 {value} 次请求 / {value} requests per minute per key；`customLimits` 并发与限额按合同约定 / Concurrency and limits by contract；`support` 工单 {hours} 小时内响应 / Support response within {hours} h；`use` 使用此分组 / Use this group。

## G3 倍率说明 `src/blocks/groups/ratio-explainer.tsx`（`'use client'`）

**外层**：`<section id="ratio" className="bg-surface py-20 md:py-28">` → `<Container className="grid gap-10 lg:grid-cols-2 lg:items-center">`。

**左栏**：
1. `<SectionHeading align="left" title={t('ratio.title')} subtitle={t('ratio.subtitle')} />`
2. 公式卡 `mt-8 rounded-2xl border border-border bg-card p-6 shadow-card`：一行 `flex flex-wrap items-center gap-x-3 gap-y-2 text-lg font-medium text-foreground md:text-xl`：「实际扣费」`=`「模型基础价」`×`「分组倍率」，其中 `=` 和 `×` 用 `text-subtle-foreground`；下面 `mt-3 text-sm text-muted-foreground`：「{t('ratio.baseNote')}」（基础价即个人版通用分组 ×1.0 的价格）。

**右栏**：示例表 `<div data-ratio-examples className="overflow-hidden rounded-2xl border border-border bg-card shadow-card">` → 标题行 `flex items-center justify-between border-b border-border px-5 py-4`：左 `text-sm font-semibold text-foreground`「{t('ratio.examplesTitle')}」（{版本名}的分组示例），右当前版本名 `<Badge tone="dark">`。→ `<div className="overflow-x-auto">` 表格 `w-full min-w-[520px] text-sm`，表头 `bg-surface text-xs text-subtle-foreground`：分组、示例、基础价、倍率、实际价格（后三列右对齐）。

每个**倍率不为 null** 的分组一行（`groupsFor(edition).filter(g => g.ratio !== null)`，个人版和专业版 4 行、企业版 3 行），`<tr data-ratio-row={group.kind} className="border-t border-border">`：
- 分组：`localize(group.name)`
- 示例（按分组种类固定取一个模型和一个价格项）：general → `gpt-6-sol` 的输入单价；image → `gemini-3.1-flash-image` 的估算每张价；claude → `claude-sonnet-5-5` 的输入单价；priority → `gpt-6-sol` 的输入单价。显示「模型名 · {t('ratio.input')} / {t('ratio.perImage')}」。
- 基础价：个人版通用（生图用个人版生图）分组的价格 = `textPrice(model, 'personal').input` 或 `imagePrice(model, 'personal').estimatedPerImage`，`formatMoney(..., 'usd')`（生图前面加「≈ 」）。
- 倍率：`formatRatio(group.ratio, locale)`。
- 实际价格 `data-ratio-result`：`formatMoney(基础价 × group.ratio, 'usd')`，`font-medium text-foreground`（生图加「≈ 」）。

**数据**：`groupsFor`、`getEdition`、`MODELS`、`textPrice`、`imagePrice`、`formatMoney`、`formatRatio`、`localize`。

**交互**：跟随版本变化。

**状态**：企业版第四个分组是定制，不出现在示例表里。

**响应式**：手机上下堆叠，表格横向滚动。

**文案**（`groups.ratio`）：`title` 倍率怎么算 / How ratios work；`subtitle` 同一个模型在不同分组里的价格，只差一个倍率。/ The same model costs differently across groups only by its ratio.；`billed` 实际扣费 / Billed price；`base` 模型基础价 / Base model price；`ratio` 分组倍率 / Group ratio；`baseNote` 基础价即个人版通用分组（×1.0）下的价格。/ The base price is the Personal General group (×1.0) price.；`examplesTitle` {edition}的分组示例 / {edition} group examples；`group` 分组 / Group；`example` 示例 / Example；`input` 输入 / input；`perImage` 每张 / per image；`result` 实际价格 / Billed。

## G5 常见问题 `src/blocks/groups/groups-faq.tsx`（服务端组件，内用共享 `FaqList`）

**外层**：`<section id="faq" className="border-t border-border py-20 md:py-28">` → `<Container className="grid gap-10 lg:grid-cols-[1fr_2fr]">`。

**元素**：左栏 `<h2 className="text-3xl font-medium tracking-tight text-foreground md:text-4xl">{t('faq.title')}</h2>`；右栏 `<FaqList items={…} />`，5 条：
1. 分组和版本是什么关系？ / 版本决定渠道质量与可用率目标，分组决定可用的模型和倍率；每个版本下各有四个分组。
2. 一个账号能用多个分组吗？ / 能。每个 API 密钥绑定一个分组，同一账号可以为不同用途创建多个密钥。
3. 倍率会调整吗？ / 倍率调整会提前在本页公示，已经产生的消费不受影响。
4. 组织成员能自己选分组吗？ / 成员只能在组织管理员授权的分组范围内创建密钥。
5. 专属定制分组怎么开通？ / 联系销售，按合同约定渠道、倍率与可用率。

**文案**（`groups.faq`）：`title` 常见问题 / FAQ；`items.q1`…`q5`、`items.a1`…`a5`（英文对译）。
