# 价格 `/pricing` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。
> 文案放进 `src/messages/zh/pricing.json` 与 `src/messages/en/pricing.json`（已有的 `meta` 键原样保留），中文照本文件，英文给了的照抄、没给的按专业克制的语气对译。

本页节奏：页首（白底 + 网格光线，标题与币种切换）→ 价目表（白底，两张大表：文本、生图）→ 企业通道联系客服卡 → 计费说明（白底，两列小卡）→ 常见问题（浅灰 surface 底）→ 页脚。

本页核心动作：切换币种，查某个模型在各分组的单价。

本页最重要的区块：**P2 价目表**，信息照 onehop.ai 价格页（按厂商分段、输入 / 输出 / 缓存 / 上下文、超长上下文档、生图按张或按 Token；2026-10-06 起每个模型在各后台分组各占一行），视觉照 Aceternity 模板价格页的对比表（细横线、居中对齐、白底大圆角容器）。允许写得最长，允许拆 `pricing-tables-*.tsx`。

页内状态：币种 `useCurrency()`（网址 `?currency=`，默认 usd）。P1 负责切换，P2 负责显示，两者通过网址同步，互不 import。2026-10-06 起按后台分组展示，没有通道切换。

## P3 计费说明 `src/blocks/pricing/pricing-notes.tsx`（服务端组件）

**外层**：`<section id="notes" className="pb-20 md:pb-28">` → `<Container>`。

**元素**：

2. `<ul className="mt-6 grid gap-4 md:grid-cols-2">`，6 条，每条 `<li data-note={key} className="flex gap-3 rounded-2xl border border-border bg-card p-5 text-sm leading-6 text-muted-foreground">`：左边图标 `size-4 mt-1 shrink-0 text-foreground`，右边文字。

| key | 图标 | 中文 |
|---|---|---|
| `unit` | `Coins` | 文本模型按百万 Token 计费，输入、输出、缓存读取分别计价；生图按张或按百万输出 Token 计费。 |
| `estimate` | `Image` | 带「≈」的每张价按 1024×1024 估算（约 {tokens} 个输出 Token），实际随尺寸与质量浮动。 |
| `longContext` | `Layers` | 单次请求的输入超过模型标注的上下文档位时，整次请求按超长上下文单价计费。 |
| `edit` | `ImagePlus` | 图生图与局部编辑会额外计入输入图片的 Token，通常占比很小。 |
| `currency` | `Wallet` | 人民币价格按 1 美元 = ¥{rate} 换算，和充值到账的比例一致，钱包始终按美元扣费。 |
| `editions` | `Route` | 页面单价即该分组的实际扣费单价，企业通道按合同定价；各通道的区别见通道页。 |

## P4 常见问题 `src/blocks/pricing/pricing-faq.tsx`（服务端组件，内用共享 `FaqList`）

**外层**：`<section id="faq" className="bg-surface py-20 md:py-28">` → `<Container className="grid gap-10 lg:grid-cols-[1fr_2fr]">`。

**元素**：

2. 右栏：`<FaqList items={[...]} />`，6 条（q / a）：
   1. 页面上的价格就是实际扣费吗？ / 是。页面显示的就是各分组的实际单价，每一笔扣费都能在控制台查到明细。
   2. 三种通道的价格为什么不同？ / 通道对应不同的资源质量：共享通道多人共用资源，专用通道是独立自营号池，高可用、低延迟、不降智，企业通道为企业单独开设。
   3. 有订阅费或最低消费吗？ / 没有。按实际用量从余额扣费，不收月费。
   4. 生图失败会扣费吗？ / 上游返回失败的请求不扣费，生成成功后按张或按 Token 计费。
   5. 可以开发票吗？ / 可以开发票，但不是增值税发票；不支持对公转账。（2026-10-06 用户更正）
   6. 人民币价格怎么算？ / 按页面标注的固定汇率换算，仅供参考，实际按美元扣费。

**交互**：手风琴，同时只展开一条（共享组件）。
