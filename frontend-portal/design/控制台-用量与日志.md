## U 用量 `src/blocks/console/usage/usage-page.tsx`（导出 `UsagePage`，可拆 `usage-*.tsx`）

**外层**：`<ConsolePage id="usage" title={t('meta.title')} actions={…}>`。

2026-10-03 起用量页接后端，显示登录账号自己的真实用量（后端接口见技术设计 18.2，模块说明见 `docs/模块设计/客户控制台-用量与日志.md`）。下面的区块、文案与交互不变，只是数据来源换成后端。

**页内状态**：`selected: DateRange | null`（没选过时用「最近 30 天」）、`metric: UsageMetric`（默认 `'tokens'`）、`reloadKey: number`（刷新按钮加一）。

**今天与范围**：`clock = useLiveClock()`（`src/lib/console/live/use-live-clock.ts`，挂载后才有，北京时间的今天与当前小时）；`since = usageSince(user.createdAt, today)`（「全部」从账号创建日算起，最长 1100 天）；预设范围按 `presetRange(preset, today, since)` 每次重算（跨天自动更新），自定义范围原样保留。

**数据**（`useUsageOverview(from, to, detail, reloadKey)`，`src/lib/console/live/use-usage-overview.ts`）：
- 所选范围的明细：`detail = true`，一天按小时、多天按天；合计 → `summary = summaryFromOverview(...)`，按天合计 → 活跃统计，三个维度的拆分 → 三张明细图。
- 热力图：`heatmapRange(today)`（53 周前那周的周一到今天），`detail = false`，只要每天合计 → `heat = heatmap(totals, today)`。
- `stats = activityStats(合并后的每天合计, 数据自己的范围)`；`days = 数据自己的范围的天数`。数字卡、活跃统计、明细图都按「数据自己的范围」算：换范围时新数据到之前，旧数据和旧范围对得上。
- 换范围只重取明细，切指标不重取，刷新两份都重取；登录失效时整页跳登录页。

**状态**：
- 首次加载：数字卡、活动四格的数字位置和热力图、三张图都换成同尺寸的占位块（共享 `Skeleton`，`data-skeleton`），标签照常显示。

**响应式**：手机上数字卡一列、`sm` 两列、`xl` 四列；热力图在面板里横向滚动；明细图宽度跟随面板。

## L 日志 `src/blocks/console/logs/logs-page.tsx`（导出 `LogsPage`，可拆 `logs-*.tsx`）

2026-10-04 起日志页接后端：只显示登录账号自己计费成功的调用（用户确认，不显示失败请求，也不按请求 ID 搜索），从新到旧，后端分页（技术设计 18.4）。信息参照用户给的参考截图（去掉渠道、用户两列），版式按控制台自己的风格。

**外层**：`<ConsolePage id="logs" title={t('meta.title')} actions={<RefreshButton onRefresh={重取} />}>`。

**页内状态**：`selection: LogSelection`（`{ range: DateRange | null, keyId: number | null, model: string | null, type: 'all' | 'text' | 'image', stream: 'all' | 'stream' | 'nonStream' }`，range 为空时用最近 30 天）、`page`（默认 1）、`pageSize`（默认 20，分页组件的 10 / 20 / 50）、`reloadKey`、`detail: LogRow | null`、`exporting`、`exportFailed`。

**今天与范围**：同用量页（`useLiveClock`、`usageSince`），预设范围跟着今天走。

**数据**：`useLoadable`（`src/lib/console/live/logs-client.ts`）取两份：一页日志 `fetchLogs(筛选 + 分页)`、筛选选项 `fetchLogOptions(from, to)`（账号的密钥、这段时间用过的模型）。任何筛选变化回到第 1 页；刷新两份都重取；换条件时旧数据变浅（`opacity-60`、`aria-busy`）。

**状态**：首次加载占位块（`data-logs-loading`）；出错 `<EmptyState id="logs-error" icon={TriangleAlert}>`，标题「日志暂时加载不出来」（太频繁「查询太频繁，请稍后再试」），操作「重试」（`data-logs-retry`）；没有结果见 L2。
