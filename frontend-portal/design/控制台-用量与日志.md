## U 用量 `src/blocks/console/usage/usage-page.tsx`（导出 `UsagePage`，可拆 `usage-*.tsx`）

**外层**：`<ConsolePage id="usage" title={t('meta.title')} actions={…}>`。

2026-10-03 起用量页接后端，显示登录账号自己的真实用量（后端接口见技术设计 18.2，模块说明见 `docs/模块设计/客户控制台-用量与日志.md`）。下面的区块、文案与交互不变，只是数据来源换成后端。

**页内状态**：`selected: DateRange | null`（没选过时用「最近 30 天」）、`metric: UsageMetric`（默认 `'tokens'`）、`reloadKey: number`（刷新按钮加一）。

**今天与范围**：`clock = useLiveClock()`（`src/lib/console/live/use-live-clock.ts`，挂载后才有，北京时间的今天与当前小时）；`since = usageSince(user.createdAt, today)`（「全部」从账号创建日算起，最长 1100 天）；预设范围按 `presetRange(preset, today, since)` 每次重算（跨天自动更新），自定义范围原样保留。

**数据**（`useUsageOverview(from, to, detail, reloadKey)`，`src/lib/console/live/use-usage-overview.ts`）：
- 所选范围的明细：`detail = true`，一天按小时、多天按天；合计 → `summary = summaryFromOverview(...)`，按天合计 → 活跃统计，三个维度的拆分 → 三张明细图。
- 热力图：`heatmapRange(today)`（53 周前那周的周一到今天），`detail = false`，只要每天合计 → `heat = heatmap(totals, today)`。
- `stats = activityStats(合并后的每天合计, 数据自己的范围)`；`days = 数据自己的范围的天数`。数字卡、活跃统计、明细图都按「数据自己的范围」算：换范围时新数据到之前，旧数据和旧范围对得上。
- 换范围只重取明细，切指标不重取，刷新两份都重取；登录失效时整页跳登录页。

### U0 标题行操作

`<DateRangePicker value={range} onChange={setSelected} today={today} since={since} />`（还不知道今天时先按默认范围显示，标题行不跳动）+ 共享的 `<RefreshButton onRefresh={重取} />`（`data-refresh`，高 40、小圆角，与日期范围按钮齐平）：`RefreshCw` 图标 +「刷新」；点击后转 600ms，期间按钮禁用。

### U1 数字卡

`<div className="grid gap-4 sm:grid-cols-2 xl:grid-cols-4">`，四张 `StatCard`：

| id | label | aside | value | sub |
|---|---|---|---|---|
| `tokens` | Token | 缓存命中 {percent}（`formatPercent(summary.cacheHitRate)`） | `formatCompact(summary.totalTokens)` | {input} 输入 · {cache} 缓存 · {output} 输出（都用 `formatCompact`） |
| `requests` | 请求 | — | `formatInteger(summary.requests)`（计费成功的请求） | 成功 {percent}（`formatPercent(summary.successRate, 2)`；成功率 = 成功 ÷（成功 + 失败），拿不到失败数或没有请求时整行不显示） |
| `latency` | 平均耗时 | — | `formatDuration(summary.avgLatencyMs)` | 首字 {ttft}（`formatDuration(summary.avgTtftMs)`；没有记录首字耗时的请求时整行不显示） |
| `cost` | 消费 | 约 {amount}/月（`formatUsd(monthlyRunRate(summary.costUsd, days))`） | `formatUsd(summary.costUsd)`（本期计费） | 本期计费（固定文字，不写生图张数） |

### U2 活动

`<Panel id="activity" title="活动">`，主体 `grid gap-6 xl:grid-cols-[minmax(0,1fr)_340px] xl:items-start`：

- 左：`<ActivityHeatmap data={heat} … />`：`monthLabel={(m) => formatMonthLabel(m, locale)}`；`cellTitle`：有调用时「{day} · {tokens} Token · {cost}」，没有调用时「{day} · 无调用」；`ariaLabel`「最近一年的每日用量」；`lessLabel`「少」、`moreLabel`「多」；`weekdayLabels` 周一 / 周三 / 周五（英文 Mon / Wed / Fri）。
- 右：`grid grid-cols-2 gap-3`，四张 `StatCard size="sm"`：
  - `active-days` 活跃天数：`stats.activeDays`
  - `streak` 最长连续：「{n} 天」
  - `range-cost` 本期消费：`formatUsd(stats.costUsd)`
  - `top-day` 最活跃日：`formatDayLabel(stats.mostActive.day, locale)`，sub「{tokens} Token · {cost}」；没有活跃日时值为「—」、不写 sub。

热力图固定看最近一年；右侧四格跟着时间范围变。

### U3 用量明细

1. 标题行 `flex flex-wrap items-center justify-between gap-3`：`<h2 className="text-base font-semibold">用量明细</h2>` + `<SegmentedControl name="usage-metric" size="sm" value={metric} onChange={setMetric} ariaLabel="明细指标" options=[Token, 请求数, 费用] />`。
2. 三个 `Panel`，每个里面一张 `StackedBarChart`，顺序：
   - `<Panel id="by-model" title="按模型">` → `breakdownFromPoints(overview.series.model, range, metric)`，系列名就是调用时的模型名，图 `id="by-model"`。
   - 下面一行 `grid gap-6 xl:grid-cols-2`：`<Panel id="by-key" title="按 API 密钥">`（系列名是后端给的密钥名，没有名字时写 `#ID`，图 `id="by-key"`）和 `<Panel id="by-group" title="按通道">`（系列名是后端的通道名，没有通道的请求写「未分组」，图 `id="by-group"`）。
   - 系列 `id === OTHER_SERIES` 时名字「其他」、颜色 `OTHER_COLOR`；其余按顺序 `seriesColor(i)`。
   - 柱子标签：按小时（范围只有一天）时 `axis = formatHour(hour)`，`full = {formatDayLabel(day)} {formatHour(hour)}`；按天时 `axis = formatDayLabel(day)`，`full = day`（YYYY-MM-DD）。
   - `formatValue`：tokens → `formatCompact`；requests → `formatInteger`（按小时拆分会有小数，先四舍五入）；cost → `formatUsd`。`formatAxis` 同 `formatValue`（cost 的纵轴用 `formatUsd`）。
   - `ariaLabel`「按模型的每日用量」这类；`totalLabel`「总计」；`emptyLabel`「所选时间内没有调用」。
   - 「按模型」高 260，另外两张高 220。

**状态**：
- 首次加载：数字卡、活动四格的数字位置和热力图、三张图都换成同尺寸的占位块（共享 `Skeleton`，`data-skeleton`），标签照常显示。
- 换范围、刷新：先留着旧数据，内容区 `[data-usage-content]` 变浅（`opacity-60`）并带 `aria-busy="true"`，新数据到了恢复。
- 出错：整页内容换成 `<EmptyState id="usage-error" icon={TriangleAlert} …>`，标题「用量暂时加载不出来」（太频繁时「查询太频繁，请稍后再试」），操作 `<Button variant="secondary" data-usage-retry>重试</Button>`。
- 范围内没有调用：四张数字卡显示 0 / US$0.00（请求卡不显示成功率），图表显示空状态文字，活动右侧四格显示 0 与「—」。

**响应式**：手机上数字卡一列、`sm` 两列、`xl` 四列；热力图在面板里横向滚动；明细图宽度跟随面板。

**文案**（`consoleUsage`，中文 / 英文）：`stats.tokens` Token / Tokens；`stats.cacheHit` 缓存命中 {percent} / {percent} cache hits；`stats.tokenParts` {input} 输入 · {cache} 缓存 · {output} 输出 / {input} in · {cache} cached · {output} out；`stats.requests` 请求 / Requests；`stats.success` 成功 {percent} / {percent} succeeded；`stats.latency` 平均耗时 / Avg latency；`stats.ttft` 首字 {value} / {value} to first token；`stats.cost` 消费 / Spend；`stats.runRate` 约 {amount}/月 / ≈ {amount}/mo；`stats.images` 生图 {count} 张 / {count} images；`refresh` 刷新 / Refresh；`activity.title` 活动 / Activity；`activity.aria` 最近一年的每日用量 / Daily usage over the past year；`activity.cell` {day} · {tokens} Token · {cost} / {day} · {tokens} tokens · {cost}；`activity.idle` {day} · 无调用 / {day} · no requests；`activity.less` 少 / Less；`activity.more` 多 / More；`activity.mon`/`wed`/`fri` 周一 / 周三 / 周五（Mon / Wed / Fri）；`activity.activeDays` 活跃天数 / Active days；`activity.streak` 最长连续 / Longest streak；`activity.streakValue` {count} 天 / {count} days；`activity.rangeCost` 本期消费 / Spend in range；`activity.topDay` 最活跃日 / Busiest day；`activity.topDaySub` {tokens} Token · {cost} / {tokens} tokens · {cost}；`detail.title` 用量明细 / Breakdown；`detail.metric` 明细指标 / Metric；`detail.tokens` Token / Tokens；`detail.requests` 请求数 / Requests；`detail.cost` 费用 / Cost；`detail.byModel` 按模型 / By model；`detail.byKey` 按 API 密钥 / By API key；`detail.byGroup` 按通道 / By channel；`detail.ariaModel` / `ariaKey` / `ariaGroup` 按模型 / 按 API 密钥 / 按通道的用量（By model / By API key / By channel）；`detail.total` 总计 / Total；`detail.other` 其他 / Other；`detail.empty` 所选时间内没有调用 / No requests in this range；`detail.noGroup` 未分组 / No channel；`error.unavailable` 用量暂时加载不出来 / Usage couldn't be loaded；`error.tooMany` 查询太频繁，请稍后再试 / Too many requests. ## L 日志 `src/blocks/console/logs/logs-page.tsx`（导出 `LogsPage`，可拆 `logs-*.tsx`）

**外层**：`<ConsolePage id="logs" title={t('meta.title')} actions={刷新按钮（同 U0，data-refresh）}>`。

**页内状态**：`filter: LogFilter`（默认 `{ range: DEFAULT_RANGE, keyId: 'all', modelId: 'all', status: 'all', type: 'all', stream: 'all', query: '' }`）、`detail: RequestLog | null`（抽屉里看的那条）、`refreshing`。

**数据**：`rows = filterLogs(REQUEST_LOGS, filter)`；`pager = usePagination(rows, JSON.stringify(filter))`；`dirty` = 筛选条件不等于默认值。

### L1 筛选栏 `<Panel id="log-filters">`

- 第一行 `grid gap-3 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-6`，每项 `FilterField`：
  - 时间：`<DateRangePicker align="start" className="w-full" />`
  - API 密钥：`<Select name="log-key">`，选项「全部」+ `API_KEYS` 的名称
  - 模型：`<Select name="log-model">`，选项「全部」+ `USED_MODEL_IDS`（显示 `getModel(id).name`）
  - 状态：`<Select name="log-status">`：全部 / 成功 / 失败
  - 类型：`<Select name="log-type">`：全部 / 文本 / 生图
  - 流式：`<Select name="log-stream">`：全部 / 流式 / 非流式
- 第二行 `mt-3 flex flex-col gap-3 sm:flex-row sm:items-end`：
  - `FilterField label="请求 ID" htmlFor="log-search"`（`className="min-w-0 flex-1"`）里放 `<SearchInput id="log-search" data-log-search placeholder="按请求 ID 搜索" />`
  - `dirty` 时显示「清除筛选」`<Button variant="ghost" data-clear-filters>`
  - 「导出 CSV」`<Button variant="secondary" data-export>`（`Download` 图标）：把当前筛选结果 `logsToCsv(rows)` 存成 `logs-{TODAY}.csv` 下载（`Blob` + 临时 `<a download>`，下载后 `URL.revokeObjectURL`）；没有结果时禁用。

### L2 请求表

`<TableShell id="logs" footer={<Pagination … />}>` → `<Table minWidth={1040}>`，列：

| 列 | 内容 |
|---|---|
| 时间 `UTC+8` | 两行：`formatDateTime(ts)` 拆成日期（`text-foreground`）与时间（`text-xs text-subtle-foreground`），`whitespace-nowrap tabular-nums` |
| 模型 | `ProviderLogo size={16}` + 按钮（文字是模型调用名，`font-mono text-sm underline decoration-dotted underline-offset-4`，`data-log-open={log.id}`），点了打开详情抽屉 |
| Token | 文本：`ArrowDown` 输入（未命中缓存）· `ArrowUp` 输出 · `Database` 缓存（缓存为 0 时不显示），图标 `size-3.5`，每段带 `title`（输入 / 输出 / 缓存读取）；生图：「{n} 张」 |
| 成本 | `formatUsd(costUsd)`，右对齐 |
| 耗时 | `formatDuration(durationMs)`，有首字耗时时后面小字「首字 {ttft}」 |
| 通道 | `<Badge tone="outline">{通道名}</Badge>` |
| 状态 | 成功：`success-graphic` 小圆点 +「成功」；失败：`<Badge tone="danger">{错误名}</Badge>` |
| 操作 | `sticky="right"`：`EllipsisVertical` 图标按钮（`aria-label="更多操作"`，`data-log-menu={log.id}`）打开下拉：复制请求 ID、复制为 curl（`curlFor(log)`）、查看详情；复制用 `useCopy`，复制成功后该菜单项文字变「已复制」 |

**空状态**：没有结果时表格主体换成 `<EmptyState id="logs" icon={ScrollText} title="没有符合条件的请求" bordered={false} action={清除筛选按钮} />`，不显示表头和分页。

### L3 详情抽屉

`<Sheet id="log-detail" open={detail !== null} title={请求 ID（font-mono）} …>`，内容 `px-5 py-4 space-y-6`：

1. 定义列表 `dl`，每行 `grid grid-cols-[7rem_minmax(0,1fr)] gap-3 py-2 text-sm`（标签 `text-subtle-foreground`，值 `break-all`）：时间、请求 ID（带 `CopyButton name="log-id"`）、API 密钥（名称）、通道、模型、类型、流式（是 / 否）、状态（成功 / 失败 + HTTP 状态码 + 错误名）、结束原因、输入 Token、缓存读取 Token、输出 Token、图片（生图才显示）、成本、总耗时、首字耗时（没有时「—」）、调用方（`client`，`font-mono`）。
2. 「请求示例」小标题 + 代码块 `<pre className="overflow-x-auto rounded-xl bg-muted p-4 font-mono text-xs leading-5">{curlFor(detail)}</pre>`，右上角 `CopyButton name="log-curl"`。

**错误名**：`upstream_timeout` 上游超时 / Upstream timeout；`rate_limited` 触发限流 / Rate limited；`context_length_exceeded` 超出上下文长度 / Context too long。**结束原因**：`stop` 正常结束 / Completed；`length` 达到长度上限 / Hit max tokens；`tool_calls` 工具调用 / Tool call；`error` 出错 / Error。

**文案**（`consoleLogs`）：`refresh`、`filters.time` 时间 / Time、`filters.key` API 密钥 / API key、`filters.model` 模型 / Model、`filters.status` 状态 / Status、`filters.type` 类型 / Type、`filters.stream` 流式 / Streaming、`filters.requestId` 请求 ID / Request ID、`filters.search` 按请求 ID 搜索 / Search by request ID、`filters.all` 全部 / All、`filters.success` 成功 / Succeeded、`filters.error` 失败 / Failed、`filters.text` 文本 / Text、`filters.image` 生图 / Image、`filters.streamOn` 流式 / Streaming、`filters.streamOff` 非流式 / Non-streaming、`filters.clear` 清除筛选 / Clear filters、`export` 导出 CSV / Export CSV；表头 `table.time` 时间 / Time、`table.tz` UTC+8、`table.model` 模型 / Model、`table.tokens` Token / Tokens、`table.cost` 成本 / Cost、`table.duration` 耗时 / Duration、`table.group` 通道 / Channel、`table.status` 状态 / Status；`table.input` 输入 / Input、`table.output` 输出 / Output、`table.cache` 缓存读取 / Cache read、`table.images` {count} 张 / {count} images、`table.ttft` 首字 {value} / TTFT {value}、`table.success` 成功 / Succeeded、`table.more` 更多操作 / More actions；菜单 `menu.copyId` 复制请求 ID / Copy request ID、`menu.copyCurl` 复制为 curl / Copy as curl、`menu.detail` 查看详情 / View details、`menu.copied` 已复制 / Copied；`empty` 没有符合条件的请求 / No matching requests；详情 `detail.*`（上面定义列表的每个标签）、`detail.example` 请求示例 / Example request、`detail.yes` 是 / Yes、`detail.no` 否 / No；`errors.*`、`finish.*` 见上。
