# 模型 `/models` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。
> 文案放进 `src/messages/zh/models.json` 与 `src/messages/en/models.json`（已有的 `meta` 键原样保留），中文照本文件，英文给了的照抄、没给的按专业克制的语气对译。

本页节奏：页首（白底 + 网格光线，居中标题、版本切换、版本指标）→ 模型浏览器（白底，左筛选栏 + 右工具条与三列模型卡）→ 页脚。

本页核心动作：切换版本、搜索、按厂商/协议/上下文筛选。

本页最重要的区块：**M2 模型浏览器**，信息组织照 onehop.ai 模型页，视觉照 Aceternity 模板（白卡、柔影、黑色分段控件）。允许写得最长，允许拆子组件 `models-explorer-*.tsx`（状态放在 `models-explorer.tsx` 主文件，往下传）。

## M1 页首 `src/blocks/models/models-hero.tsx`（服务端组件）

**外层**：直接返回共享组件 `<PageHero id="models-hero" title={t('hero.title')} subtitle={t('hero.subtitle', { count: MODELS.length })}>`，children 依次是 `<EditionSwitcher />` 和 `<EditionSummary />`（都是共享组件，读写网址 `?edition=`）。

**元素**：标题、副标题、版本分段控件（个人版 / 专业版 / 企业版）、版本指标一行（可用率目标、渠道、单密钥每分钟请求、分组倍率；企业版倍率显示「定制」）。

**数据**：`MODELS.length`（30）；版本数据由共享组件读取。

**交互**：点版本 → 网址变 `?edition=pro`，同页 M2 的价格、折扣、可用率立刻跟着变。

**状态**：无。

**响应式**：共享组件已处理；手机上版本指标自动折行。

**文案**（`models.hero`）：`title` 所有模型，一个 API 调用 / Every model, one API；`subtitle` 用一个密钥、一个地址、一张账单，调用 OpenAI、Anthropic、Gemini 协议下的 {count} 个模型。/ One key, one base URL and one bill for {count} models across the OpenAI, Anthropic and Gemini protocols.

## M2 模型浏览器 `src/blocks/models/models-explorer.tsx`（`'use client'`）

**外层**：`<section id="explorer" className="pb-20 md:pb-28">` → `<Container>` → `<div className="grid gap-8 lg:grid-cols-[240px_minmax(0,1fr)]">`（右栏用 `minmax(0,1fr)` 防止被撑宽）。

### 状态（全部存网址，刷新和分享都保留）

| 状态 | 钩子 | 网址键 | 取值 | 默认 |
|---|---|---|---|---|
| 版本 | `useEdition()` | `edition` | personal / pro / enterprise | personal |
| 类型 | `useUrlState('type', TYPE_FILTERS, 'all')` | `type` | all / text / image | all |
| 厂商 | `useUrlList('provider', PROVIDERS.map(p => p.id))` | `provider` | 逗号分隔 | 空（不限） |
| 协议 | `useUrlList('protocol', PROTOCOLS)` | `protocol` | 逗号分隔 | 空（不限） |
| 上下文 | `useUrlState('context', CONTEXT_FILTERS, 'all')` | `context` | all / 200k / 1m | all |
| 搜索 | `useUrlText('q')` | `q` | 任意文字 | 空 |
| 排序 | `useUrlState('sort', SORT_KEYS, 'latest')` | `sort` | latest / price-asc / price-desc / context | latest |

结果：`const list = filterModels(MODELS, { type, providers, protocols, context, query, sort }, edition)`；数量：`facetCounts(MODELS, type)`。首页公告胶囊链接到 `/models?type=image`，打开时类型直接是「生图」。

搜索框：输入框用本地 `useState` 受控，每次输入同时写网址；网址里的 `q` 变化（例如点「清除筛选」）时，在渲染中比较上次同步的值并直接更新本地值（React 推荐的「随外部值调整状态」写法；不要在 `useEffect` 里 `setState`，会被 lint 规则拦下）。

### 左栏：筛选 `<aside data-filters className="space-y-8 lg:sticky lg:top-24 lg:self-start">`

手机（`lg` 以下）：筛选栏默认收起，工具条最前面多一个按钮 `<button data-filter-toggle className={buttonClass({ variant: 'secondary', size: 'sm' })}><SlidersHorizontal />{t('filters.toggle')}</button>`，点开后筛选栏在工具条下方展开（`hidden` / `block` 用对象映射切换，`lg:block` 始终显示）。

三组，每组标题 `mb-3 text-xs font-medium uppercase tracking-wide text-subtle-foreground`：

1. 上下文长度（`t('filters.context')`）：三个小胶囊 `flex flex-wrap gap-2`，每个 `<button type="button" data-context={value} aria-pressed={选中}>`，类名 `rounded-full border px-3 py-1 text-xs font-medium transition-colors`，选中 `border-primary bg-primary text-primary-foreground`，未选中 `border-border bg-card text-muted-foreground hover:text-foreground`。文字：全部 / ≥ 200K / ≥ 1M（`t('filters.contextAll')`、`≥ 200K`、`≥ 1M`，后两个是固定写法，可直接写在组件常量里）。
2. 厂商（`t('filters.providers')`）：`PROVIDERS` 八行，每行 `<label data-provider={id} className="flex cursor-pointer items-center gap-3 rounded-md px-2 py-1.5 text-sm text-foreground hover:bg-muted">`：原生复选框 `<input type="checkbox" className="size-4 accent-[var(--foreground)]" checked onChange />`（受控）+ `<ProviderLogo provider size={16} />` + 厂商名 `flex-1 truncate` + 数量 `text-xs tabular-nums text-subtle-foreground`（`facetCounts(...).providers[id]`）。数量为 0 的行变淡 `opacity-50`，仍可勾选。
3. 支持协议（`t('filters.protocols')`）：`PROTOCOLS` 五行，同上结构，没有标志，名字取 `PROTOCOL_LABELS[p]`，`data-protocol={p}`。

有任何筛选条件（厂商、协议非空，上下文不是 all，或搜索非空）时，三组下面出现 `<button type="button" data-clear-filters className={buttonClass({ variant: 'link', size: 'sm', className: 'text-muted-foreground' })}>{t('filters.clear')}</button>`：清空厂商、协议、搜索，上下文回 all（类型、排序、版本不动）。

### 右栏 `<div className="min-w-0 space-y-6">`

1. 工具条 `<div className="flex flex-col gap-4 md:flex-row md:items-center md:justify-between">`：
   - 左：数量 `<p className="text-sm text-muted-foreground"><span data-result-count className="font-semibold tabular-nums text-foreground">{list.length}</span> {t('toolbar.models')}</p>`（中文「个模型」，英文「models」）。
   - 右 `flex items-center gap-2`：
     - 搜索框：`<div className="relative w-full md:w-72">` + `Search` 图标 `pointer-events-none absolute left-3 top-1/2 size-4 -translate-y-1/2 text-subtle-foreground` + `<Input data-model-search type="search" className="pl-9" placeholder={t('toolbar.search')} aria-label={t('toolbar.search')} value onChange />`。
     - 排序下拉：`DropdownMenu`，触发按钮 `data-sort-trigger`，类名 `buttonClass({ variant: 'secondary', size: 'md' })`，内容 `ArrowUpDown` + 当前排序名 + `ChevronDown size-3.5`；菜单 `DropdownMenuRadioGroup value={sort}`，四项 `DropdownMenuRadioItem value={key} data-sort={key}`：最新上线 / 价格从低到高 / 价格从高到低 / 上下文最长（`t('sort.latest')` 等）。
2. 类型切换：`<SegmentedControl name="type" value={type} onChange={setType} ariaLabel={t('types.label')} options={[{ value: 'all', label: t('types.all'), count: 30 }, { value: 'text', label: t('types.text'), count: 23 }, { value: 'image', label: t('types.image'), count: 7 }]} />`（数量来自 `facetCounts(MODELS, type).types`，不要写死）。
3. 模型卡网格 `<div data-model-grid className="grid gap-4 sm:grid-cols-2 xl:grid-cols-3">`，按 `list` 顺序渲染模型卡（子组件 `models-explorer-card.tsx`，`'use client'`，参数 `{ model: Model; edition: EditionId; locale: AppLocale }`）。
4. 空状态（`list.length === 0` 时代替网格）：`<div data-empty-state className="flex flex-col items-center rounded-2xl border border-dashed border-border-strong px-6 py-20 text-center">`：`Search` 图标放在 `flex size-12 items-center justify-center rounded-full bg-muted` 里 → `mt-4 text-base font-medium text-foreground`「{t('empty.title')}」→ `mt-6` 按钮 `<button data-empty-clear className={buttonClass({ variant: 'secondary' })}>{t('filters.clear')}</button>`（同「清除筛选」，另外把类型也重置为 all）。

### 模型卡 `models-explorer-card.tsx`

`<article data-model-card={model.id} className="group flex h-full flex-col rounded-2xl border border-border bg-card p-5 shadow-card transition-transform duration-200 hover:-translate-y-0.5">`

1. 第一行 `flex items-center gap-2`：`<ProviderLogo provider size={18} />` + 厂商名 `truncate text-sm text-muted-foreground` + （`isNewModel` 时）`<Badge tone="info">{t('card.new')}</Badge>` + 弹性空白 + （生图时）`<Badge tone="outline">{t('card.image')}</Badge>`。
2. 模型名 `mt-3 truncate text-base font-semibold text-foreground`。
3. 调用名行 `mt-1 flex items-center gap-1.5`：`<code className="min-w-0 truncate font-mono text-xs text-subtle-foreground">{model.id}</code>` + 复制按钮 `<button type="button" data-copy-id={model.id} aria-label={t('card.copy')} className="shrink-0 rounded p-1 text-subtle-foreground hover:bg-muted hover:text-foreground">`（图标 `Copy size-3.5`，点击 `navigator.clipboard.writeText(model.id)` 后 1.5 秒内换成 `Check size-3.5 text-success`；剪贴板不可用时静默不报错；定时器卸载时清掉）。
4. 描述 `mt-3 line-clamp-2 min-h-10 text-sm text-muted-foreground`（`localize(model.description, locale)`）。
5. 协议标签 `mt-4 flex flex-wrap gap-1.5`：每个协议 `<Badge tone="outline">{PROTOCOL_LABELS[p]}</Badge>`。
6. 价格区 `mt-4 flex items-end justify-between gap-3 border-t border-border pt-4`：
   - 左 `min-w-0`：小标签 `text-xs text-subtle-foreground` + 价格 `mt-0.5 text-sm font-medium tabular-nums text-foreground`（`data-card-price`）：
     - 文本：标签 `t('card.inputOutput')`「输入 / 输出」，价格 `${formatMoney(input,'usd')} / ${formatMoney(output,'usd')}` + 后缀 `<span className="text-xs font-normal text-subtle-foreground"> {common.units.perMTokens}</span>`
     - 按张生图：标签 `t('card.perImage')`「每张」，价格 `${formatMoney(from,'usd')} {common.units.from}`
     - 按 Token 生图：标签 `t('card.estimate')`「约每张」，价格 `≈ ${formatMoney(estimatedPerImage,'usd')}`
     - 企业版（倍率按合同定制，`editionRatio(edition) === null`）：标签按类型取「输入 / 输出」或「每张」，价格写 `formatRatio(null, locale)`「定制」
   - 右 `flex shrink-0 flex-col items-end gap-1.5`：`<DiscountBadge discount={editionDiscount(edition)} locale={locale} />`（个人版 1.5折、专业版 3折、企业版不显示） + 文本模型的上下文 `text-xs tabular-nums text-muted-foreground`「{formatContext} {t('card.context')}」（中文「上下文」，英文「context」）。
7. 可用率 `mt-4`：第一行 `flex items-center justify-between text-xs`：左 `text-subtle-foreground`「{t('card.uptime')}」（近 24 小时可用率），右 `<span data-uptime className={…}>{percent.toFixed(2)}%</span>`，颜色对象映射：≥ 99.5 `text-success font-medium`、≥ 98 `text-warning font-medium`、其余 `text-danger font-medium`。第二行状态条 `mt-2 flex gap-0.5`，24 格（`uptimeFor(model.id, edition).slots`），每格 `h-5 flex-1 rounded-[2px]`，颜色对象映射：up `bg-success-graphic`、degraded `bg-warning-graphic`、down `bg-danger-graphic`；状态条加 `role="img"` 和 `aria-label`（「近 24 小时可用率 {percent}%」）。
8. 底部链接 `mt-4`：`<Link href={{ pathname: '/pricing', query: edition === 'personal' ? {} : { edition }, hash: \`model-${model.id}\` }} data-card-pricing className="inline-flex items-center gap-1 text-sm font-medium text-foreground hover:underline">{t('card.pricing')}<ArrowRight className="size-3.5" /></Link>`（中文「查看价格」）。

**数据**：`MODELS`、`PROVIDERS`、`PROTOCOLS`、`PROTOCOL_LABELS`、`TYPE_FILTERS`、`CONTEXT_FILTERS`、`SORT_KEYS`、`filterModels`、`facetCounts`、`textPrice`、`imagePrice`、`editionDiscount`、`editionRatio`、`formatRatio`、`formatMoney`、`formatContext`、`isNewModel`、`uptimeFor`、`getProvider`、`localize`（`@/lib/catalog`）；`useEdition`（`@/lib/use-catalog-state`）；`useUrlState`、`useUrlList`、`useUrlText`（`@/lib/use-url-state`）。模型页一律用美元，不读币种。

**交互**：
- 勾选厂商、协议是多选，再点一次取消；上下文是单选。任何条件变化都立刻刷新结果和数量，不需要「应用」按钮。
- 切类型时厂商、协议的数量跟着变（`facetCounts(MODELS, type)`）。
- 排序下拉选中项右侧有对勾。
- 版本切换（M1）后，卡片价格、折扣标、可用率全部跟着当前版本变。

**状态**：
- 空结果：显示空状态块（文字「没有符合条件的模型」），隐藏网格。
- 水合前：网址参数还没读到，按默认条件渲染全部 30 个，水合后自动按网址条件刷新（不显示加载态）。
- 长文本：厂商名、模型名、调用名 `truncate`，描述两行截断。
- 复制失败：不提示。

**响应式**：
- `lg` 以下：左栏收进「筛选」按钮；工具条上下堆叠，搜索框占满一行；模型卡 `sm` 两列、手机一列。
- `xl` 起三列。
- 右栏是网格子项，已用 `minmax(0,1fr)` 和 `min-w-0` 防止手机横向溢出。

**文案**（`models.*`，中文 / 英文）：
- `filters.toggle` 筛选 / Filters；`filters.context` 上下文长度 / Context length；`filters.contextAll` 全部 / All；`filters.providers` 厂商 / Providers；`filters.protocols` 支持协议 / Protocols；`filters.clear` 清除筛选 / Clear filters
- `toolbar.models` 个模型 / models；`toolbar.search` 搜索模型名、调用名或厂商 / Search by name, model ID or provider
- `sort.label` 排序 / Sort；`sort.latest` 最新上线 / Newest；`sort.price-asc` 价格从低到高 / Price: low to high；`sort.price-desc` 价格从高到低 / Price: high to low；`sort.context` 上下文最长 / Longest context（键名里的连字符照写，或改成 `priceAsc` / `priceDesc`，二选一并保持中英一致）
- `types.label` 模型类型 / Model type；`types.all` 全部 / All；`types.text` 文本 / Text；`types.image` 生图 / Image
- `empty.title` 没有符合条件的模型 / No models match these filters
- `card.new` 新 / New；`card.image` 生图 / Image；`card.copy` 复制调用名 / Copy model ID；`card.inputOutput` 输入 / 输出 / Input / Output；`card.perImage` 每张 / Per image；`card.estimate` 约每张 / Est. per image；`card.context` 上下文 / context；`card.uptime` 近 24 小时可用率 / 24h availability；`card.uptimeLabel` 近 24 小时可用率 {percent}% / 24h availability {percent}%；`card.pricing` 查看价格 / View pricing

## 本页交互检查会找的东西

期望值全部来自 `tests/catalog.test.ts`。

| 位置 | 操作 | 断言 |
