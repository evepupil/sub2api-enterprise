# 模型 `/catalog` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。
> 文案放进 `src/messages/zh/models.json` 与 `src/messages/en/models.json`（已有的 `meta` 键原样保留），中文照本文件，英文给了的照抄、没给的按专业克制的语气对译。

本页节奏：页首（白底 + 网格光线，居中标题与副标题）→ 模型浏览器（白底，左筛选栏 + 右工具条与三列模型卡）→ 页脚。

本页核心动作：搜索（也搜分组名）、按厂商/上下文筛选。

数据（2026-10-05 起）：模型、价格、可用率都来自后台，页面文件 `src/app/[locale]/(site)/catalog/page.tsx` 在服务端用 `getSiteCatalog()`（`src/lib/server/site-catalog.ts`）读好，整理成各分组摊平的模型列表（`SiteCatalog`：每个分组里的每个模型一条，`src/lib/catalog/live.ts`）传给 M2；页面每次打开都用官网服务器缓存（60 秒）里的数据现做（`export const dynamic = 'force-dynamic'`，不在构建时预先生成：构建时通常连不上后台，预先生成会让部署后的第一位访客看到空页面）。按后台分组展示、不做通道切换（2026-10-06 用户定：通道只是对外的说法，分组名里写明属于哪个通道）。后台读不到时不拿示例数据充数。

本页最重要的区块：**M2 模型浏览器**，信息组织照 onehop.ai 模型页，视觉照 Aceternity 模板（白卡、柔影、黑色分段控件）。允许写得最长，允许拆子组件 `models-explorer-*.tsx`（状态放在 `models-explorer.tsx` 主文件，往下传）。

## M1 页首 `src/blocks/models/models-hero.tsx`（服务端组件）

**外层**：直接返回共享组件 `<PageHero id="models-hero" title={t('hero.title')} subtitle={count === null ? t('hero.subtitleNoCount') : t('hero.subtitle', { count })}>`（`count` 由页面传入：`siteModelCount(catalog)`，同一个模型在几个分组里只算一个），不带 children（2026-10-06 去掉了通道切换与通道指标）。

**元素**：标题、副标题。

**数据**：模型数来自后台，读不到时副标题换成不带数字的一句。

**交互**：无。

**状态**：无。

**响应式**：共享组件已处理。

**文案**（`models.hero`）：`title` 所有模型，一个 API 调用 / Every model, one API；`subtitle` 用一个密钥、一个地址、一张账单，调用 OpenAI、Anthropic、Gemini 协议下的 {count} 个模型。/ One key, one base URL and one bill for {count} models across the OpenAI, Anthropic and Gemini protocols.；`subtitleNoCount` 用一个密钥、一个地址、一张账单，调用 OpenAI、Anthropic、Gemini 协议下的主流模型。/ One key, one base URL and one bill for leading models across the OpenAI, Anthropic and Gemini protocols.

## M2 模型浏览器 `src/blocks/models/models-explorer.tsx`（`'use client'`）

**外层**：`<section id="explorer" className="pb-20 md:pb-28">` → `<Container>` → `<div className="grid gap-8 lg:grid-cols-[240px_minmax(0,1fr)]">`（右栏用 `minmax(0,1fr)` 防止被撑宽）。

### 状态（全部存网址，刷新和分享都保留）

| 状态 | 钩子 | 网址键 | 取值 | 默认 |
|---|---|---|---|---|
| 类型 | `useUrlState('type', TYPE_FILTERS, 'all')` | `type` | all / text / image | all |
| 厂商 | `useUrlList('provider', PROVIDERS.map(p => p.id))` | `provider` | 逗号分隔 | 空（不限） |
| 上下文 | `useUrlState('context', CONTEXT_FILTERS, 'all')` | `context` | all / 200k / 1m | all |
| 搜索 | `useUrlText('q')` | `q` | 任意文字 | 空 |
| 排序 | `useUrlState('sort', SORT_KEYS, 'latest')` | `sort` | latest / price-asc / price-desc / context | latest |

参数：`{ catalog: SiteCatalog }`，`models = catalog ?? []`（每个分组里的每个模型一条）。结果：`filterSiteModels(models, { type, providers, context, query, sort })`（同一个模型的几条挨着、便宜的分组在前；关键词也搜分组名）；数量：`siteFacetCounts(models, type)`（按不重复的模型算）；厂商选项：`providersOf(models)`（只列出现过的）。后台读不到或没有模型（`catalog` 为 `null` 或空）时，整个 M2 换成 `<div data-models-unavailable>` 一句「{t('empty.unavailable')}」。首页公告胶囊链接到 `/catalog?type=image`，打开时类型直接是「生图」。

搜索框：输入框用本地 `useState` 受控，每次输入同时写网址；网址里的 `q` 变化（例如点「清除筛选」）时，在渲染中比较上次同步的值并直接更新本地值（React 推荐的「随外部值调整状态」写法；不要在 `useEffect` 里 `setState`，会被 lint 规则拦下）。

### 左栏：筛选 `<aside data-filters className="space-y-8 lg:sticky lg:top-24 lg:self-start">`

手机（`lg` 以下）：筛选栏默认收起，工具条最前面多一个按钮 `<button data-filter-toggle className={buttonClass({ variant: 'secondary', size: 'sm' })}><SlidersHorizontal />{t('filters.toggle')}</button>`，点开后筛选栏在工具条下方展开（`hidden` / `block` 用对象映射切换，`lg:block` 始终显示）。

两组，每组标题 `mb-3 text-xs font-medium uppercase tracking-wide text-subtle-foreground`：

1. 上下文长度（`t('filters.context')`）：三个小胶囊 `flex flex-wrap gap-2`，每个 `<button type="button" data-context={value} aria-pressed={选中}>`，类名 `rounded-full border px-3 py-1 text-xs font-medium transition-colors`，选中 `border-primary bg-primary text-primary-foreground`，未选中 `border-border bg-card text-muted-foreground hover:text-foreground`。文字：全部 / ≥ 200K / ≥ 1M（`t('filters.contextAll')`、`≥ 200K`、`≥ 1M`，后两个是固定写法，可直接写在组件常量里）。
2. 厂商（`t('filters.providers')`）：`providersOf(models)` 每个一行，每行 `<label data-provider={id} className="flex cursor-pointer items-center gap-3 rounded-md px-2 py-1.5 text-sm text-foreground hover:bg-muted">`：原生复选框 `<input type="checkbox" className="size-4 accent-[var(--foreground)]" checked onChange />`（受控）+ `<ProviderLogo provider size={16} />` + 厂商名 `flex-1 truncate` + 数量 `text-xs tabular-nums text-subtle-foreground`（`siteFacetCounts(...).providers[id]`，没有为 0）。数量为 0 的行变淡 `opacity-50`，仍可勾选。

有任何筛选条件（厂商非空，上下文不是 all，或搜索非空）时，两组下面出现 `<button type="button" data-clear-filters className={buttonClass({ variant: 'link', size: 'sm', className: 'text-muted-foreground' })}>{t('filters.clear')}</button>`：清空厂商、搜索，上下文回 all（类型、排序不动）。2026-10-05 去掉了「支持协议」筛选（协议资料不再维护）。

### 右栏 `<div className="min-w-0 space-y-6">`

1. 工具条 `<div className="flex flex-col gap-4 md:flex-row md:items-center md:justify-between">`：
   - 左：数量 `<p className="text-sm text-muted-foreground"><span data-result-count className="font-semibold tabular-nums text-foreground">{distinctModelCount(list)}</span> {t('toolbar.models')}</p>`（不重复的模型数，同一个模型的几张卡只算一个；中文「个模型」，英文「models」）。
   - 右 `flex items-center gap-2`：
     - 搜索框：`<div className="relative w-full md:w-72">` + `Search` 图标 `pointer-events-none absolute left-3 top-1/2 size-4 -translate-y-1/2 text-subtle-foreground` + `<Input data-model-search type="search" className="pl-9" placeholder={t('toolbar.search')} aria-label={t('toolbar.search')} value onChange />`。
     - 排序下拉：`DropdownMenu`，触发按钮 `data-sort-trigger`，类名 `buttonClass({ variant: 'secondary', size: 'md' })`，内容 `ArrowUpDown` + 当前排序名 + `ChevronDown size-3.5`；菜单 `DropdownMenuRadioGroup value={sort}`，四项 `DropdownMenuRadioItem value={key} data-sort={key}`：最新上线 / 价格从低到高 / 价格从高到低 / 上下文最长（`t('sort.latest')` 等）。
2. 类型切换：`<SegmentedControl name="type" value={type} onChange={setType} ariaLabel={t('types.label')} options={[{ value: 'all', label: t('types.all'), count }, …]} />`（数量来自 `siteFacetCounts(models, type).types`，不要写死）。
3. 模型卡网格 `<div data-model-grid className="grid gap-4 sm:grid-cols-2 xl:grid-cols-3">`，按 `list` 顺序渲染模型卡（子组件 `models-explorer-card.tsx`，`'use client'`，参数 `{ model: SiteModel; locale: AppLocale }`，`key={model.key}`）。一张卡是某个分组里的一个模型，同一个模型在几个分组里就有几张。
4. 空状态（`list.length === 0` 时代替网格）：`<div data-empty-state className="flex flex-col items-center rounded-2xl border border-dashed border-border-strong px-6 py-20 text-center">`：`Search` 图标放在 `flex size-12 items-center justify-center rounded-full bg-muted` 里 → `mt-4 text-base font-medium text-foreground`「{t('empty.title')}」→ `mt-6` 按钮 `<button data-empty-clear className={buttonClass({ variant: 'secondary' })}>{t('filters.clear')}</button>`（同「清除筛选」，另外把类型也重置为 all）。

### 模型卡 `models-explorer-card.tsx`

`<article data-model-card={model.id} data-group={model.group.name} className="group flex h-full flex-col rounded-2xl border border-border bg-card p-5 shadow-card transition-transform duration-200 hover:-translate-y-0.5">`

1. 第一行 `flex min-h-5 items-center gap-2`：（认得厂商时）`<ProviderLogo provider size={18} />` + 厂商名 `truncate text-sm text-muted-foreground` + （`model.isNew` 时）`<Badge tone="info">{t('card.new')}</Badge>` + 弹性空白 + （生图时）`<Badge tone="outline">{t('card.image')}</Badge>`。
2. 模型名 `mt-3 truncate text-base font-semibold text-foreground`（官网目录里有的用展示名，没有的就是调用名）。
3. 调用名行 `mt-1 flex items-center gap-1.5`：`<code className="min-w-0 truncate font-mono text-xs text-subtle-foreground">{model.id}</code>` + 复制按钮 `<button type="button" data-copy-id={model.id} aria-label={t('card.copy')} …>`（图标 `Copy size-3.5`，复制后 1.5 秒内换成 `Check size-3.5 text-success`；剪贴板不可用时静默；定时器卸载时清掉）。
4. 可用率（`models-health.tsx`，后台给这个分组的这个模型建了渠道监测项时才有（监测项分组标签 = 分组名、名称 = 模型名），`<div data-model-health className="mt-4 space-y-3">`；2026-10-05 用户要求照 sub2api 的渠道状态卡，替换掉原来的描述与协议标签）：
   - 两格 `grid grid-cols-2 gap-2`，每格 `rounded-lg bg-muted/60 px-3 py-2`：小字标签 `t('card.latency')`「对话延迟」/ `t('card.ping')`「端点 PING」+ 数字 `text-sm font-semibold tabular-nums`（`data-latency="chat"` / `"ping"`）带小字 `ms`；没有数据写「—」。
   - 一行 `flex items-center justify-between text-xs`：左「{t('card.availability')}」（可用性 · 近 7 天），右 `<span data-availability>{availability.toFixed(2)}%</span>`，颜色对象映射：≥ 99.5 `text-success`、≥ 98 `text-warning`、其余 `text-danger`。
   - 近 N 次记录：小字「{t('card.probes', { count })}」+ 一排细条 `mt-1.5 flex h-5 gap-px`（`role="img"`、`data-probes={count}`、`aria-label={t('card.probesLabel', { count, up })}`），每次探测一根 `flex-1 rounded-[1px]`，颜色对象映射：正常 `bg-success-graphic`、变慢 `bg-warning-graphic`、不可用 `bg-danger-graphic`、无数据 `bg-muted`，从早到晚、最多 60 根。
5. 底部 `mt-auto pt-4`（卡片等高时价格区贴底）：价格区 `flex items-end justify-between gap-3 border-t border-border pt-4`：
   - 左 `min-w-0`：分组名 `<p data-card-group className="truncate text-xs font-medium text-foreground" title={分组名}>` + 小标签 `mt-1 text-xs text-subtle-foreground` + 价格 `mt-0.5 text-sm font-medium tabular-nums text-foreground`（`data-card-price`），都是这个分组的实付价（后台单价 × 分组倍率）：
     - 按 Token：标签「输入 / 输出」，价格 `输入价 / 输出价` + 后缀 `{common.units.perMTokens}`（缺一项写「—」）
     - 按张：标签「每张」，价格写单价，分辨率有多档时加「起」
     - 按次：标签 `t('card.perRequest')`「每次」，价格同上
   - 右 `flex shrink-0 flex-col items-end gap-1.5`：`<DiscountBadge discount={model.discount} />`（实付 ÷ 官方价，小于 1 才显示）+ 上下文（目录里有才显示）「{formatContext} {t('card.context')}」。
6. 底部链接 `mt-4`：链到 `/pricing#model-{分组编号}-{调用名}`（价目表里这个分组那一行，`priceRowId(model)`），`data-card-pricing`，「{t('card.pricing')}」+ `ArrowRight`。

**数据**：`SiteCatalog`、`SiteModel`、`filterSiteModels`、`siteFacetCounts`、`providersOf`、`distinctModelCount`、`priceRowId`（`@/lib/catalog/live`）；`PROVIDERS`、`TYPE_FILTERS`、`CONTEXT_FILTERS`、`SORT_KEYS`、`formatMoney`、`formatContext`、`getProvider`（`@/lib/catalog`）；`useUrlState`、`useUrlList`、`useUrlText`（`@/lib/use-url-state`）。模型页一律用美元，不读币种。

**交互**：
- 勾选厂商是多选，再点一次取消；上下文是单选。任何条件变化都立刻刷新结果和数量，不需要「应用」按钮。
- 切类型时厂商的数量跟着变（`siteFacetCounts(models, type)`）。
- 排序下拉选中项右侧有对勾。
- 同一个模型在几个分组里就有几张卡，挨着放、便宜的分组在前；搜分组名（如「高性能」）只剩那个分组的卡。

**状态**：
- 空结果：显示空状态块（文字「没有符合条件的模型」），隐藏网格。
- 水合前：网址参数还没读到，按默认条件渲染，水合后自动按网址条件刷新（不显示加载态）。
- 后台读不到：整块换成「暂时没有可展示的模型」；某个模型没建监测项：卡片没有可用率一块。
- 长文本：厂商名、模型名、调用名 `truncate`。
- 复制失败：不提示。

**响应式**：
- `lg` 以下：左栏收进「筛选」按钮；工具条上下堆叠，搜索框占满一行；模型卡 `sm` 两列、手机一列。
- `xl` 起三列。
- 右栏是网格子项，已用 `minmax(0,1fr)` 和 `min-w-0` 防止手机横向溢出。

**文案**（`models.*`，中文 / 英文）：
- `filters.toggle` 筛选 / Filters；`filters.context` 上下文长度 / Context length；`filters.contextAll` 全部 / All；`filters.providers` 厂商 / Providers；`filters.clear` 清除筛选 / Clear filters
- `toolbar.models` 个模型 / models；`toolbar.search` 搜索模型名、调用名、厂商或分组 / Search models, providers or groups
- `sort.label` 排序 / Sort；`sort.latest` 最新上线 / Newest；`sort.price-asc` 价格从低到高 / Price: low to high；`sort.price-desc` 价格从高到低 / Price: high to low；`sort.context` 上下文最长 / Longest context（键名里的连字符照写，或改成 `priceAsc` / `priceDesc`，二选一并保持中英一致）
- `types.label` 模型类型 / Model type；`types.all` 全部 / All；`types.text` 文本 / Text；`types.image` 生图 / Image
- `empty.title` 没有符合条件的模型 / No models match these filters；`empty.unavailable` 暂时没有可展示的模型 / No models to show right now
- `card.new` 新 / New；`card.image` 生图 / Image；`card.copy` 复制调用名 / Copy model ID；`card.inputOutput` 输入 / 输出 / Input / Output；`card.perImage` 每张 / Per image；`card.perRequest` 每次 / Per request；`card.context` 上下文 / context；`card.latency` 对话延迟 / Chat latency；`card.ping` 端点 PING / Endpoint ping；`card.availability` 可用性 · 近 7 天 / Availability · 7 days；`card.probes` 近 {count} 次记录 / Last {count} checks；`card.probesLabel` 近 {count} 次探测，{up} 次正常 / {up} of the last {count} checks passed；`card.pricing` 查看价格 / View pricing
