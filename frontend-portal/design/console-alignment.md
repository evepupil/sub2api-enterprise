# 控制台示意图对齐修正

对应：[M0](../docs/roadmap.md#m0)、[M2](../docs/roadmap.md#m2)、[M3](../docs/roadmap.md#m3)、[M5](../docs/roadmap.md#m5)。依据用户于 2026-09-27 再次给出的控制台图片，以及[已确认总览图](../docs/前端设计/示意图/09-A统计总览修订.png)。沿用现有浅灰白、黑色操作、图表配色和业务接口。

## 修正目标

图中的组织顺序是：左侧品牌和账户身份、业务导航、左下账号设置；右侧页头和余额、单行日期工具栏、四张带图标的统计卡、两列分布与趋势。当前功能代码需要落实这个布局，不能只复现功能项。

## 侧栏与页头

- 桌面侧栏沿用 216px 白色背景，固定在当前视口内，主内容较长时底部入口不会被推到整页末端。品牌下面用用户图标加“个人账户”“组织管理员”或“组织成员”，不显示昵称、邮箱或测试组织名字。
- 主导航按已有权限显示概览、密钥管理、用量明细、余额与订单，以及管理员的组织入口。概览用 House 图标。账号设置从主导航分离，固定在左下；帮助作为同一底部区域的辅助入口。账号设置是最下方的导航行。
- 已登录外壳不再额外放一颗独立“退出登录”按钮；账号设置页保留退出操作，登录异常状态仍提供退出重新登录。
- 手机抽屉使用同样的导航分组，保留关闭、焦点管理和正常路由行为；面板贴齐右边，不带错误的横向居中位移。
- 主内容桌面水平留白 24px、顶部 16px，手机保持 16px；用既有间距工具类。标题上方提供紧凑“控制台 / 当前页”路径。标题和余额/充值仍在同一页头区。

## 总览

- 总览区块之间改为 16px，删除“统计范围”这一独立卡标题。日期工具栏只有一行：时间范围、预选下拉、日历日期按钮；右侧粒度选择。手机自然换行。
- 日期控件增加 `presentation?: 'combined' | 'split'`，默认保留合并模式给已有调用；总览使用 split。预选和日历操作复用现有状态与日期规则，仍只有日历日期，不能增加时分和近24小时。预选含自定义入口，自定义仍在弹层统一应用。
- 四张卡片依次为总请求数、总 Token、总消费、平均耗时。每张标题左侧有 16px 单色 Lucide 图标，依次用 MessagesSquare、Database、CircleDollarSign、Clock3。大屏四列、窄屏两列、手机一列，数据来自原接口。
- 统一 `components/console/metric-card.tsx`：`MetricCard({label:string,value:string,icon:LucideIcon,children?:ReactNode})`。标题 14px、数值 24px，使用已有字号和间距；四卡拉齐高度。组织用量的四卡也复用，避免另一套样式再次漂移。
- Token 卡保留输入、输出、缓存写入、缓存读取四项真实分项；请求量正常分组，较大 Token 可用 K/M 缩写，表格/提示仍可读完整含义，不改任何实际计费或聚合数据。
- 模型、分组、接口三卡继续为左环图右表格，桌面两列布局，间距 16px。环图中心显示所选维度合计及 Token/USD，小尺寸不能出现巨大的空白。切换按钮合成紧凑分段组“按 Token / 按消费”。
- 环图复用 `DonutChart`，只新增可选的中心主文本与副文本展示参数；不要在图表组件重新定义业务计算。分布卡依据已有行数据计算当前维度合计。总消费为零时保持数值/表格，不出现“暂无可绘制的分布”这类实现用语。
- 分布表第一列分别为模型、分组、接口，其后请求、Token、消费。保留图例色点、长名称处理和真实金额；不要让共享宽表格的 680px 最小宽度套到这种卡内小表。

## 文案与真实性

清理正式控制台中的实现说明、测试标签及重复描述。“本地验收账号”来自本地测试用户昵称，外壳应展示业务身份；不得靠给任意用户姓名做字符串替换来掩盖数据。账号设置仍显示其真实可编辑资料。

保留确实影响决定的信息：额度 0/不限额、同步会重置已用、危险操作后果、付款币种与到账金额、日期时区、失败与重试。不得删除这些规则来缩短页面。不得把示意图中的余额/模型统计写进真实业务页面。

## 验收

先对照用户图与现有素材逐项核对，再检查真实桌面、手机、下拉和日历状态。无浏览器连接时不宣称截图或交互已通过；已询问用户是否明确允许 Playwright 驱动 Edge。纯视觉修改不新增单测，运行现有格式、静态分析、类型、核心测试与构建。相关共享界面、用量、账号及设计文档同步更新。
