# 主题切换

对应 [M0](../docs/roadmap.md#m0) 与 [工程与共享界面](../docs/模块设计/工程与共享界面.md)。2026-09-28。

提供浅色、深色、跟随系统三个选项；未选择时保持 Proactiv 深色。官网顶部、登录页顶部、控制台桌面侧栏底部和手机顶栏使用同一个切换控件。复用现有按钮和 Radix 气泡层，不增加控件库。

选择只保存于浏览器，以 `portal.theme` 为键；刷新和站内跳转后恢复，同源标签页同步。“跟随系统”监听系统配色变化，显式浅色/深色不受系统变化影响。存储不可用时仍允许本次页面切换。无账号请求或后端改动。

主题状态放在 `src/features/theme/`：偏好规则、浏览器连接、外部状态存储、首次绘制前脚本、React 订阅和控件按职责分文件。根页面只允许主题属性与服务端默认值不同；控件的首次服务端/浏览器内容保持一致，接管后显示实际选择。

颜色继续由 `styles/tokens.css` 管理，默认深色加 `data-theme="light"` 浅色覆盖。浅色保留青蓝品牌色，另配置语义文字、表面、边框、反馈、图表与阴影，尺寸和布局一致。单色厂家标志随主题反色，彩色标志保留原色。

主题先应用到页面，再通知订阅者。ECharts 在主题变化时读取新颜色并更新已有实例；异步加载完成后也读取最新主题。Stripe 只更新外观，不重建付款组件、不清空已填内容。控件、弹窗和首页图形直接继承 CSS 颜色。

验证：偏好恢复、存储异常、系统变化、跨标签同步、订阅释放、服务端快照及首次绘制脚本的回归测试；完整工程门禁。纯配色不写单测，浏览器实际截图/点击与单测分别记录。
